## 서비스 체인 검증

```text
아이 행동 → STT → LLM 판단 → DB 상태 변경 → UI 반영
```

각 단계별 PASS/FAIL을 아래에 기록한다(하나라도 확인 못 했으면 `NOT TESTED`,
실패로 확인됐으면 `FAIL` — 임의로 다음 단계를 추정해 채우지 않는다).

| 단계 | 판정 | 근거 |
|---|---|---|
| 아이 행동(STT 인식) | | |

| UI 반영(게이지/다음 질문) | | |
