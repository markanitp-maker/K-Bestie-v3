# A. 자유대화 놀이 — 개발/프로덕션 둘 다 가능

미션 시간과 무관합니다. 아무 때나 됩니다.

## A-1. 끝말잇기가 되는가

1. 자유대화 들어가서 **"끝말잇기 하자"**
2. 케이가 단어를 하나 내는지 확인
3. 그 단어 **마지막 글자로 시작하는 말**을 3~4번 주고받기

**정상**
- 케이가 먼저 단어를 냄
- 끝말이 이어짐
- 아이가 아는 흔한 말(학교·나무·컴퓨터·사과)이 인정됨

**문제로 봐야 할 것**
- 흔한 말인데 "사전에 없는 단어"라고 함 → 어떤 단어였는지 적어주세요
- 케이가 아는 사람 없는 어려운 말을 냄 (예: 실러캔스, 모데미풀)

## A-2. 틀렸을 때 케이가 어떻게 말하는가

일부러 아래를 넣어보세요.

| 입력 | 기대 |
|---|---|
| 끝말이 안 맞는 단어 | **어떤 글자로 시작해야 하는지 알려줘야 함** |
| 이미 나온 단어 | "아까 나왔어" 류 |
| 영어 (apple) | "한글로 하자" 류 |

**문제**: 셋 다 똑같은 말로 답하거나, "그런 말은 없어"라고 단정하는 경우

## A-3. 놀이 제안과 거절

1. **"심심해"** → 케이가 놀이를 제안하는지
2. **"안 할래"** → 물러나는지
3. 다시 **"심심해"** → **또 제안하면 문제** (거절을 기억해야 함)
4. **"끝말잇기 하자"** → 이건 **시작돼야 함** (아이가 직접 요청한 건 항상 허용)

**3번과 4번이 핵심입니다.** 거절은 존중하되 아이가 원하면 해줘야 합니다.

## A-4. 게임 중 속상한 이야기

게임 진행 중에 **"오늘 학교에서 속상한 일 있었어"**

**정상**: 케이가 게임을 내려놓고 마음을 먼저 받음
**문제**: "그건 끝말잇기가 아니야" 같은 반응

## A-5. 게임 전환 — 수정 완료, 확인 부탁드립니다

박서아 계정에서 났던 그 증상입니다. 고쳐서 배포했습니다.

1. **"초성게임 하자"** → 초성게임 시작
2. 한두 번 주고받다가 **다른 이야기**로 흘리기 (예: "오늘 킨텍스 다녀왔어")
3. **"끝말잇기 하자"**
4. 케이가 낸 단어의 **끝 글자로 시작하는 단어** 입력

**정상**
- 3번에서 케이가 끝말잇기를 시작하고 첫 단어를 냄
- 4번 입력이 **끝말잇기로** 처리됨 (끝말이 이어짐)

**문제로 봐야 할 것**
- 4번에서 갑자기 **초성 문제**(예: "ㄱㅊ")가 나옴 ← 원래 사고 증상
- 케이가 끝말잇기하는 척만 하고 실제로는 초성게임이 계속됨

## A-6. 게임 이름을 말했을 뿐인데 바뀌는가

끝말잇기 진행 중에 **"이거 초성게임보다 재밌다"**

**정상**: 끝말잇기가 계속됨
**문제**: 초성게임으로 넘어감

## A-7. 그만하기

게임 중에 **"그만할래"**

**정상**: 케이가 게임을 접고 일반 대화로 돌아옴
**문제**: 계속 게임을 이어가려 함

# B. 미션 별 게이지 — 개발 서버에서만

> **프로덕션은 미션 시간이 아니면 시작이 안 됩니다.** 개발 서버는 24시간 열려 있습니다.

## B-1. 짧게 답해도 별이 차는가 (핵심)

미션을 시작하고 케이 질문에 **일부러 짧게** 답하세요.

| 케이가 물으면 | 이렇게 답해보세요 |
|---|---|
| 무슨 게임 했어? | 로블록스 |
| 누구랑 놀았어? | 민준이랑 |
| 뭐 먹었어? | 떡볶이 |
| 기분 어땠어? | 속상했어 |

**정상**: 3~4턴이면 별이 3개 정도 참
**문제**: 짧게 답했다고 별이 안 참 (이번에 고친 부분입니다)

## B-2. 아무 말이나 하면 안 차는가

새 미션에서 아래처럼 답해보세요.

- "응"
- "몰라"
- "그냥"
- 질문과 상관없는 말 (학교 물었는데 "부루마불")

**정상**: 별이 안 참
**문제**: 이런 답으로도 별이 차면 미션이 의미가 없어집니다

**B-1과 B-2를 같이 보셔야 합니다.** 하나만 맞으면 고친 게 아닙니다.

## B-3. 현실과 안 맞는 질문

케이가 학교 얘기를 물으면 **"지금 방학이야"**

**정상**: 케이가 받아들이고 다른 이야기로 넘어감
**문제**: 학교 질문을 계속 반복함
