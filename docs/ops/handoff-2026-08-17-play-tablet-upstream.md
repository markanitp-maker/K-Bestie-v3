# 퀴즈마스터 · MBTI 태블릿 반응형 수정 요청 (2026-08-17)

073-1 요청서 §5·§6 에 해당하는 두 건이다. **K-Bestie 저장소에서는 고칠 수 없다.**
두 앱 모두 외부 프로젝트이고 K-Bestie 는 리버스 프록시로만 띄운다.

```
/play/quiz  → app/api/quiz-proxy/[[...path]]/route.ts  → QUIZ_UPSTREAM_ORIGIN
/play/mbti  → app/play/mbti/[[...path]]/route.ts       → MBTI_UPSTREAM_ORIGIN
```

## K-Bestie 쪽은 이미 정상이다

`components/play/PlayFrame.tsx` 의 iframe 은 `w-full h-full` 로
**태블릿 가용 영역을 그대로 넘기고 있다.** 좁아지는 원인은 전부 앱 내부 CSS 다.
K-Bestie 가 폭을 제한하고 있지 않으므로, 앱에서 풀면 바로 넓어진다.

---

## 1. 퀴즈마스터 — 태블릿에서 스마트폰 폭이 강제된다

**증상**: 태블릿에서 게임 내부가 430px 안팎의 좁은 스마트폰형 프레임으로 갇힌다.
양옆이 크게 비고, 스마트폰 외곽 테두리처럼 보인다.

**고칠 것**
- 루트/컨테이너의 고정 `max-width` 를 **태블릿 breakpoint(≥768px)에서 해제**한다.
- 태블릿에서 가용 폭을 정상적으로 쓰게 한다.

**유지할 것**
- 스마트폰 레이아웃은 지금 그대로. 회귀가 없어야 한다.
- 문제 출제·버튼·점수·진행 동작 불변.
- 전체 UI 재작성 금지. 폭 제약만 푸는 작업이다.

---

## 2. MBTI — 태블릿에서 질문 이미지가 과도하게 커진다

**증상**: 질문 이미지가 가로 폭을 따라 확대되면서 **세로 높이도 같이 커져**,
질문 텍스트와 선택지가 화면 아래로 밀린다.

**원인 형태**: 이미지에 `width: 100%; height: auto` 만 걸려 있어 가로가 넓어지는
만큼 세로도 무한정 늘어난다.

**고칠 것**
- 질문 이미지에 **세로 상한**을 둔다. 가로만 제한하면 해결되지 않는다.
- `object-fit: contain` 으로 **비율 유지, 잘림 없이**.
- 이미지 중앙 정렬 유지.

**유지할 것**
- 스마트폰에서의 현재 크기.
- 질문·선택지 구조 재설계 금지.
- 다른 놀이 이미지에 영향 없을 것.

**수치 주의**: 073-1 요청서는 `220px`·`30dvh` 를 **참고값일 뿐**이라고 못박았다.
실제 DOM 과 기기 QA 로 정한다.

## 이 방식을 고른 이유

프록시에서 CSS 를 주입하는 방법도 있으나 택하지 않았다.

- 현재 프록시는 응답 본문을 그대로 흘려보낸다. 주입하려면 HTML 을 버퍼링해
  다시 쓰는 구조로 바꿔야 한다.
- MBTI 프록시는 **2026-08-03 프로덕션 장애 지점**이다. 업스트림이 내려보낸
  `Content-Security-Policy: frame-ancestors 'none'` 때문에 iframe 이 조용히
  차단돼 사용자에게 빈 화면만 보였다. 태블릿 여백 때문에 이 경로를 다시
  건드릴 이유가 없다.
- 주입한 CSS 는 업스트림이 클래스명만 바꿔도 조용히 깨진다.
- 073-1 요청서가 금지한 범용 선택자 `!important` 를 쓰게 될 가능성이 높다.

요청서 §5 도 "upstream 코드가 안전하게 수정 가능하다면 upstream responsive CSS
수정이 우선"이라고 명시한다.

**업스트림 수정이 불가능하다고 확인되면** 그때 프록시 주입으로 간다. 그 경우
실제 DOM selector 를 먼저 특정하고 해당 route 에만 좁게 적용한다.
