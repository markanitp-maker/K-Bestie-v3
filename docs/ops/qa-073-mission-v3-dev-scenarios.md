## 먼저 이해하실 것 — 왜 두 단계인가

Mission v3는 코드 배포로 켜지지 않습니다. **환경변수 `MISSION_V3_EFFECTIVE_AT` 하나로 v2/v3가 갈립니다.**
그래서 한 환경에서 둘을 동시에 볼 수 없고, 순서대로 확인해야 합니다.

|---|---|---|
| **A** | 미설정 (현재 상태) | **기존 v2가 하나도 안 바뀌었는가** ← 가장 중요 |
| **B** | 과거 시각으로 설정 | v3 신규 흐름이 제대로 도는가 |

**A가 이번 전환의 합격 기준입니다.** 01:00 전까지 아이들은 A 상태에서 돌아갑니다.
A에서 뭔가 달라 보이면 그건 배포하면 안 된다는 뜻입니다.

## 단계 A — v2 무영향 확인 (환경변수 손대지 않고)

배포 직후 바로 진행하실 수 있습니다.

### A-1. 홈 화면 (미션 안 한 상태)
- 아이 홈 진입
- **기대**: "미션 진행 / 오늘의 미션을 시작해요" — 예전과 동일
- **실패 신호**: 문구가 달라짐, 진행률이 이상하게 표시됨, 미션 카드가 사라짐

### A-2. 미션 진행 중 홈 복귀 (핵심)
- 미션에 들어가 **2~3문제만 답하고** 홈으로 나옴
- **기대**: 홈에 **"미션 계속하기" + 진행률 배지**(예: `3/5`)가 예전처럼 표시
- **실패 신호**: 진행률이 사라지거나 `0/5`·`NaN`으로 보임, "오늘의 미션을 시작해요"로 되돌아감

> 이게 이전 검증에서 **반려됐던 지점**입니다. v3 조회가 v2 세션을 못 보는 문제였고 고쳤습니다.
> 여기서 진행률이 안 보이면 수정이 실패한 겁니다.

### A-3. 미션 이어하기
- 위 상태에서 미션 카드를 눌러 다시 진입
- **기대**: 처음부터가 아니라 **하던 지점부터 이어짐**

### A-4. 미션 완료
- 미션을 끝까지 완료
- **기대**: 완료 화면 + 황금열쇠 보상이 예전과 동일하게 표시
- 홈으로 나오면 "미션 완료 / 오늘의 미션을 모두 완료했어요"

### A-5. 완료 후 재진입
- 완료 상태에서 미션 카드 다시 누름
- **기대**: 다시 시작되지 않고 완료 화면 유지

## 단계 B — v3 흐름 확인 (환경변수 설정 후)

**A가 전부 통과한 뒤에** 진행합니다. 제가 Dev에 `MISSION_V3_EFFECTIVE_AT`를 과거 시각으로
설정하고 재배포하겠습니다. 말씀만 주시면 즉시 처리합니다.

> 주의: 단계 A에서 이미 v2 미션을 한 계정은 **같은 날짜에 v2로 고정(sticky)** 됩니다.
> B는 **아직 그날 미션을 안 한 계정**이나 **날짜가 바뀐 뒤**에 테스트해야 v3가 뜹니다.
> 이건 버그가 아니라 전환 안전장치입니다.

### B-1. v3 신규 시작
- 홈 → 미션 카드 진입
- **기대**: `/child/missions/v3` 화면으로 이동. 고정 질문이 아니라 **자유롭게 대화**하는 형태

### B-2. 대화 턴
- 케이와 몇 차례 주고받기
- **기대**: 답할 때마다 케이가 반응하고 진행도가 오름. 분모는 **3**입니다(`1/3`, `2/3`)
- **실패 신호**: 같은 말이 두 번 나옴, 버튼 연타 시 턴이 두 번 나감, 응답이 멈춤

### B-3. 완료와 보상
- 목표 3개를 달성할 때까지 대화
- **기대**: 완료 화면 + 황금열쇠 **1회만** 지급
- **실패 신호**: 축하 모달이 두 번 뜸, 보상을 못 받았는데 받은 것처럼 표시

### B-4. 완료 후 재진입
- **기대**: "오늘의 미션을 모두 완료했어요. 이야기해 줘서 고마워!" + 자유대화/홈 이동만 제공
- **실패 신호**: 다시 시작 버튼이 보임

### B-5. 하루 1회 제한
- 완료 후 홈에서 미션 카드 확인
- **기대**: "미션 완료" 상태 유지, 새로 시작 불가

## 특별히 봐주셨으면 하는 것

### 안전 일시정지가 "완료"로 보이지 않는가
이번 수정의 핵심입니다. 미션이 안전상의 이유로 중단되거나 강제 종료되면
**"완료"가 아니라 각각 다른 안내**가 나와야 합니다.

| 상황 | 나와야 하는 문구 | 보상 |
|---|---|---|
| 정상 완료 | "오늘의 미션을 모두 완료했어요. 이야기해 줘서 고마워!" | 지급 |
| 안전 일시정지 | "안전을 위해 오늘 미션을 잠시 쉬고 있어요. 보호자 확인 후 다시 만나요." | **없음** |
| 강제 종료 | "오늘 미션이 종료되었어요. 내일 다시 만나요." | **없음** |

셋 다 서버 내부적으로는 같은 "오늘 더 못함" 신호를 쓰기 때문에, 예전 코드는 **전부 "완료"로 표시**했습니다.
안전 기능이 완료로 둔갑하면 아이도 보호자도 속습니다. 이걸 갈랐습니다.

의도적으로 재현하기 어려우시면 건너뛰셔도 됩니다 — 정적 검증으로 확인된 부분입니다.

### 홈과 미션 화면이 서로 다른 말을 하지 않는가
- 홈에서 "미션 계속하기"라고 했는데 들어가니 "미션 시간이 아니에요"가 뜨면 **실패**입니다
- 홈에서 본 진행률과 미션 화면의 진행 상태가 다르면 **실패**입니다

이전에 두 화면이 각자 시간을 계산해서 어긋났고, 이번에 서버 판정 하나만 보도록 고쳤습니다.
