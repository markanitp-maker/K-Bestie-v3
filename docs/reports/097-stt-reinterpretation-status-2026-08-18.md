# 097 STT 문맥 재해석 — 현재 상태와 §5-1 결정 (2026-08-18)

## 결론 먼저

**§5-1(넌센스 정답 복원)은 구현하지 않았다.** 같은 요청서의 §3-2·§5-2 와 정면으로
충돌하고, 요청서 자신이 §5-2 를 "더 중요"하다고 못박았기 때문이다.

## 충돌 내용

| 조항 | 요구 |
|---|---|
| §5-1 | 넌센스 퀴즈 중 **정답과 발음이 가까운 오인식을 복원**한다 (`소 노래` ← `오수 노래`) |
| §3-2 | **정답을 재해석으로 흘리기 금지** |
| §5-2 | **정답 오인정 0건** (요청서가 "더 중요"라고 명시) |

정답을 재해석 후보에 넣는 순간, 아이가 낸 오답이 정답으로 둔갑할 수 있다.
2026-08-17 에 임계값으로 두 번 조율해 봤으나 양방향 모두 실패했다 —
느슨하면 `타자`·`감자`가 정답 `사자`로 바뀌었고, 조이면 정상 보정(`송아치`→`송아지`)까지
막혔다. 그래서 **정답 후보를 아예 담지 않는 방식**으로 확정했다.

아이가 답을 맞히지 못하는 것은 아쉬운 정도지만, **틀린 답이 정답으로 둔갑하면**
아이는 자기가 맞혔다고 믿는다. 되돌릴 수 없는 실패다.

## 지금 동작하는 것 / 안 하는 것

| 상황 | 재해석 | 근거 테스트 |
|---|---|---|
| 끝말잇기 (`콰자` → `과자`) | **한다** | 097-1b |
| 넌센스 정답 (`오수 노래` → `소`) | 하지 않는다 | 097-1, 097-10 |
| 초성게임 정답 (`파나나` → `바나나`) | 하지 않는다 | 097-1b |
| 미션 모드 | 하지 않는다 (§3-3) | 097-3 |
| 감정·안전 발화 | 원문 보존 | 097-8 |
| 한 낱말 오답 | 정답으로 고치지 않음 | 097-9 |

## 되살리려면

넌센스 정답 복원을 살리려면 **낱말 실재 여부 판정**이 필요하다.
`타자`·`감자`처럼 실재하는 낱말은 재해석하지 않고, 실재하지 않는 오인식만
정답 후보와 대조하는 방식이다. 사전이 필요하고 범위가 커서 별건으로 둔다.

## 남은 것

- **실사용 음성 QA**: 단위 테스트는 전부 통과하나 실제 목소리로는 미검증이다.
  STT 1·2단계도 같은 이유로 프로덕션 보류 중이다.
- **프로덕션 배포**: 073·097 대표 QA 대기로 전체 큐가 묶여 있다.

## 킬 스위치

오작동하면 배포 없이 끌 수 있다.

```
Vercel 환경변수  STT_RESCORING_DISABLED=true
```

대소문자·앞뒤 공백을 받아준다. 끄면 원문이 그대로 통과하고 `raw_transcript` 는
NULL 로 남아 재해석 도입 전과 동일해진다.
