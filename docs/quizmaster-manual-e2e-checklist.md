# 퀴즈마스터 실계정 수동 테스트 절차 (대표님 전용)

> 갱신: 2026-07-27 — 아키텍처가 **리버스 프록시**로 최종 확정되면서 흐름이 바뀌어
> 전면 개정했다. 이전 판은 `https://quizmaster-dev.vercel.app/...`로 **외부 리다이렉트**
> 되는 것을 확인하라고 안내했는데, 지금은 그런 이동이 일어나지 않는다 —
> 주소창은 항상 K-Bestie 도메인에 머문다. 그 항목을 그대로 따르면 정상 동작을
> 실패로 오판하게 되므로 주의.
>
> K-Bestie 쪽 코드/설정은 QA테스트 계정으로 이미 검증 완료된 상태이며, 실계정
> (김서아/김서현)을 이용한 마지막 확인만 대표님이 직접 진행합니다. Claude Code는
> 실계정에 접근하거나 황금열쇠를 충전하지 않습니다.

## 지금 구조 요약 (한 문단)

`/child/play`에서 퀴즈마스터를 시작하면 K-Bestie가 황금열쇠 2개를 차감하고 handoff
token을 발급한 뒤 `/play/quiz`로 이동합니다. `/play/quiz`는 K-Bestie 안의 화면이
아니라 **독립 퀴즈마스터 배포를 그대로 중계(리버스 프록시)하는 경로**입니다. 겉보기
주소는 계속 `k-bestie-v3-dev.vercel.app`이고, 퀴즈마스터 주소는 화면 어디에도
노출되지 않습니다.

## 사전 준비 (대표님이 직접)

1. 개발 서버(https://k-bestie-v3-dev.vercel.app)에 김서아 계정으로 로그인
2. 관리자 화면 또는 기존 충전 기능으로 황금열쇠 22개 충전 확인
3. 김서현 계정도 동일하게 22개 충전 확인

## 테스트 시나리오

### 1) 퀴즈마스터 실행
- `/child/play` 진입 → "퀴즈마스터" 카드 확인(황금열쇠 **2개** 표시 — 2026-07-27 비용 변경)
- "시작하기" 클릭

### 2) 황금열쇠 차감 확인
- 클릭 직후 보유 황금열쇠가 **22 → 20으로 정확히 2개** 감소했는지 확인
- 21이 되면 구 비용(1개)이 남아 있다는 뜻이므로 그대로 알려주세요

### 3) 퀴즈 화면 진입 확인 ※ 이전 판에서 바뀐 항목
- 주소창이 **`k-bestie-v3-dev.vercel.app/play/quiz`인 상태로** 퀴즈 화면이 뜨는지 확인
- **`quizmaster-dev.vercel.app` 같은 외부 주소로 이동하면 오히려 비정상입니다** —
  프록시를 우회했다는 뜻이므로 그대로 알려주세요
- 오류 화면·무한 로딩이 아닌지 확인

### 4) 퀴즈 진행
- 학년 확인 → 과목 선택 → 문제 풀이 → 자동으로 다음 문제 이동까지 정상 동작 확인
- 이미지·아이콘·글꼴이 깨지지 않는지 확인(정적 자산도 프록시를 타므로 함께 검증됨)

### 5) 중단 후 이어하기
- 퀴즈 도중 홈으로 나갔다가 `/child/play`에서 퀴즈마스터를 다시 눌러 "이어하기" 진입
- **황금열쇠가 추가로 차감되지 않는지**(20 그대로) 확인 — 재차감은 버그입니다
- 풀던 문제 지점부터 이어지는지 확인

### 6) 제출 → 결과 → 리더보드
- 끝까지 제출 후 점수·결과 화면이 뜨는지
- 리더보드에 본인 기록이 반영되는지(아이별 누적 기준)
- 완료 후 K-Bestie로 정상 복귀되는지
- (기술적으로는 퀴즈마스터가 `POST /api/quiz/completion` 호출)

### 7) 오류 복귀 화면 확인 (가능하면)
- 퀴즈 화면을 오래 열어둔 뒤(세션 만료 유도) 조작하면
  `/play/quiz-error` 화면으로 돌아오는지 확인
- "놀이로 돌아가기" 버튼이 `/child/play`로 이동하는지 확인
- 이때 차감된 황금열쇠가 되돌아오는지 확인(즉시 또는 정산 배치로 최대 6시간 내)

### 8) 환불 확인 (오류 상황 재현 시)
- 진행 중 강제 중단(브라우저 뒤로가기·새로고침)해 보고
- 차감된 황금열쇠 **2개**가 22로 환불되는지 확인(20 → 22)
- (기술적으로는 `POST /api/rewards/golden-key/refund`, 놓친 건은 정산 배치가 회수)

### 9) MBTI 영향 확인
- 같은 계정으로 MBTI 놀이도 정상 동작하는지 확인
  (퀴즈마스터 연동이 MBTI 코드/데이터에 영향 주지 않아야 함)
