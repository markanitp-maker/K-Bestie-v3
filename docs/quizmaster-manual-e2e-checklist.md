# 퀴즈마스터 연동 실계정 수동 테스트 절차 (대표님 전용)

> 이 문서는 requests/010(퀴즈마스터 연동)의 최종 E2E 확인용입니다. K-Bestie 쪽 코드/설정은
> QA테스트 계정으로 이미 검증 완료된 상태이며, 실계정(김서아/김서현)을 이용한 마지막 확인만
> 대표님이 직접 진행합니다. Claude Code는 실계정에 접근하거나 황금열쇠를 충전하지 않습니다.

## 사전 준비 (대표님이 직접)

1. 개발 서버(https://k-bestie-v3-dev.vercel.app)에 김서아 계정으로 로그인
2. 관리자 화면 또는 기존 충전 기능으로 황금열쇠 22개 충전 확인
3. 김서현 계정도 동일하게 22개 충전 확인

## 테스트 시나리오

### 1) 퀴즈마스터 실행
- `/child/play` 화면 진입 → "퀴즈마스터" 카드 확인(황금열쇠 1개 표시)
- "시작하기" 클릭

### 2) 황금열쇠 차감 확인
- 클릭 직후 보유 황금열쇠가 22 → 21로 정확히 1개만 감소했는지 화면에서 확인

### 3) handoff token 생성 + 퀴즈마스터 이동 확인
- 클릭 후 `https://quizmaster-dev.vercel.app/...`로 정상 이동하는지 확인
- 이동 실패(오류 화면/무한 로딩)가 아닌지 확인

### 4) 퀴즈마스터에서 실제 퀴즈 진행
- 퀴즈마스터 화면에서 문제 풀이를 끝까지 완료

### 5) completion callback 확인
- 완료 후 K-Bestie 쪽으로 정상 복귀되는지, 완료 처리가 반영되는지 확인
- (기술적으로는 퀴즈마스터가 `POST /api/quiz/completion`을 호출 - 화면상으로는 "정상 완료" 표시 여부로 확인)

### 6) refund callback 확인 (오류 상황 재현 시)
- 가능하다면 퀴즈마스터 진행 중 강제로 중단(예: 브라우저 뒤로가기, 새로고침)해 보고
- 이 경우 차감된 황금열쇠 1개가 다시 22로 환불되는지 확인
- (기술적으로는 퀴즈마스터가 `POST /api/rewards/golden-key/refund`를 호출)

### 7) MBTI 영향 확인
- 같은 계정으로 MBTI 놀이도 정상 동작하는지 확인(퀴즈마스터 연동이 MBTI 코드/데이터에 영향
  주지 않아야 함 - 이미 코드 리뷰로 격리 확인됐으나 실사용 확인 차원)
