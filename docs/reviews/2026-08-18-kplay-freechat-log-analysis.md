## 확인된 결함

### D1. 아이가 요청한 놀이가 무시된다 — [수정 완료]

| 시각 | 아이 | 케이 |
|---|---|---|
| 23:55:49 | "너 초성 게임 못 하니까 초성 게임은 다시 개발 해 개판이야 **끝말잇기나 하자**" | "자, 다시 낼게! 초성은 'ㅈㅇㄱ' 이야. 뭘까?" |
| 23:56:06 | "아니 내가 뭐라 그랬어 … 나는 지금 **끝말잇기 하자** 그랬잖아" | "자, 다시 낼게! 초성은 'ㅈㅇㄱ' 이야. 뭘까?" (같은 말 반복) |

원인: `findDirectlyRequestedSkill` 이 레지스트리 **첫 매칭**을 돌려준다. 등록 순서가
`CHOSUNG → WORD_CHAIN → NONSENSE_QUIZ` 라서, 아이가 문장 뒤에서 끝말잇기를 요청해도
앞에 언급된 초성게임이 항상 이긴다.

조치: `lib/k-conversation/play/skillRequestResolution.ts` 신규. 사람이 말한 순서를 따른다 —
불만·제외 맥락("초성게임은 개판이야", "끝말잇기 말고")에서 언급된 놀이는 요청으로 보지 않고,
요청 동사(하자/할래/해줘)에 가장 가까운 놀이를 고르고, 그래도 못 가리면 나중에 언급된 놀이를 고른다.
실측 두 문장을 테스트로 고정했다.

### D2. 아이가 말한 낱말이 유실된다 — [수정 완료]

| 시각 | 아이 | 케이 |
|---|---|---|
| 23:56:38 | "아 진짜 한참 째 끝말잇기 하긴 하는 구나 귀찮냐 **차표**" | "좋아! 나는 '메모지' 할게. 이제 '지'로 시작하는 말 해줘!" |
| 23:56:49 | "내가 차표 라고 했잖아 왜 갑자기 메모지가 튀어 나오니" | "그건 아직 잘 기억이 안 나는데, 다시 말해줄래?" |

원인: `extractChildCandidateWord` 가 접두어("정답은…")가 없으면 **발화 전체**를 낱말로 넘긴다.
아이는 말끝에 낱말을 붙여 말하는데("… 귀찮냐 차표"), 문장 전체가 낱말로 들어가 판정이 무너졌다.
같은 함수에서 기존 버그도 하나 나왔다 — "정답은 기차야" 가 조사 "은" 을 낱말로 잡았다.

조치: 문장이면 마지막 한글 낱말을 낱말로 본다. 접두어 패턴 순서를 고쳐 조사를 잡지 않게 했고,
종결 조사("기차야"→"기차")는 뗀 형태가 사전에 있을 때만 뗀다. 실측 문장을 테스트로 고정했다.

23:57:54 "향초" → "다시 말해주면 안 될까?" / 23:58:26 "도구" → "한 번 더 말해줄래?"

아이가 직접 항의했다("2번 정도 얘기했으면 알아 들어야 되는 거 아냐"). 재확인 횟수 상한이 없다.
제안: 같은 턴에서 재확인 2회를 넘기면 되묻지 말고 (a) 들린 대로 받아 진행하거나
(b) 문제를 넘기거나 (c) 다른 놀이를 권한다. 어느 쪽을 기본으로 할지는 제품 결정이라 남겨 둔다.

### D4. 초성게임 답변이 자해 신호로 처리됐다 — [보고, 안전 로직이라 임의 변경 안 함]

23:55:07 아이 "죽을개"(초성 ㅈㅇㄱ 답을 말하려던 것) → 케이 "그런 말 들으니까 내 마음도 되게
철렁하고 걱정되네…". 아이는 곧바로 "너가 투석 물어본거 죽을 게 아니냐고" 라고 설명했다.

초성게임 답변 맥락에서 자해 가드가 오발동했다. 아이 경험이 깨지고, 반대로 실제 자해 신호의
신뢰도도 떨어진다. 다만 자해 감지를 약화시키는 변경은 위험해서 손대지 않았다.
제안: 활성 초성게임 세션이 있고 아이 발화가 그 문제의 초성과 일치하는 단답일 때만
게임 답변으로 우선 해석. 실제 위험 신호는 그대로 유지.

### D5. 케이가 실제로 시작하지 않은 판을 시작했다고 말한다 — [보고]

23:56:24 케이 "끝말잇기 시작하자, '기차'부터 해볼게!" → 다음 턴에 실제 세션이 시작되며
케이가 다른 낱말('메모지')을 냈다. 아이 입장에서는 케이가 말을 바꾼 것이다.
저장소에는 이미 "가짜 게임 진행" 출력 차단이 있지만(`detectFakeGameplay`), **시작 선언**은
차단 대상이 아니다. 제안: 세션이 실제로 생성되지 않은 턴에서는 시작 선언을 하지 못하게 한다.

### D6. 잘못된 STT 문맥 재점수 — [보고]

23:57:14 저장된 발화는 "내가 **지구** 차표 라고" 인데 `raw_transcript` 는 "내가 **지금** 차표 라고" 다.
재점수(contextual rescoring)가 맞는 낱말을 틀린 낱말로 바꿨다. 끝말잇기 문맥이 "지"로 시작하는
낱말을 기대해서 밀어붙인 것으로 보인다. 제안: 재점수는 원문보다 확신이 확실히 높을 때만 적용하고,
바꾼 이력을 로그로 남긴다(현재 raw_transcript 저장은 되고 있어 추적은 가능하다).

### D7. 같은 문구 2연속 반복 — [부분 개선]

23:55:52 / 23:56:09 케이가 "자, 다시 낼게! 초성은 'ㅈㅇㄱ' 이야. 뭘까?" 를 글자 그대로 두 번 말했다.
이건 초성 필수 초성 가드의 고정 대체 문구다. D1 수정으로 이 상황 자체가 줄어들지만,
가드 대체 문구 자체에 반복 회피(`pickAvoiding`)를 적용하는 것은 별도 작업으로 남겨 둔다.
