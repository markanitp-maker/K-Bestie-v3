## 2. 학교 전제 질문 전수 표시 + 방학/학기 판정 설계안

### 2.1 학교 전제 질문 표시 현황 (`school_context_required`)
- **신규 123건 중**: **37건**이 `school_context_required = TRUE` (학교·수업·급식·선생님·교실·책가방·하교 전제), **86건**이 `FALSE` (주말·일상·가족·취미 universal).
- **기존 846건 중**:
  - DB 실측 `school_context_tag = 'school_required'`는 **132건** (`universal` 714건).
  - 키워드 전수 스캔 및 도메인 정밀 검증 결과: `SCHOOL_EXPERIENCE` (108건), `TEACHER_RELATIONSHIP` (16건), `LEARNING_AND_STUDY` (5건), `ACHIEVEMENT` (2건), `MOOD_CHECK` (2건), `RAPPORT_IDENTITY` (1건) = 총 **134건**이 학교 맥락을 직접 전제합니다.
  - 기존 132건 태깅은 실제 학교 전제 질문과 98.5% 정합하며, 2건의 엣지케이스(학원/학교 복합)를 제외하면 신뢰도가 매우 높습니다.

### 2.2 방학·학기·공휴일 판정 런타임 설계안 (Metadata & Runtime)

```text
[Mission Question Selection Flow: School & Vacation Context]

1. 아이 프로필 및 오늘 날짜 (KST) 확인
   ↓
2. 요일 판정 (Day of Week)
   - 토요일 / 일요일 → [주말 모드]: school_required 질문 100% 자동 제외
   ↓
3. 법정공휴일 판정 (KST Calendar)
   - 공휴일 / 대체공휴일 / 재량휴업일 → [공휴일 모드]: school_required 질문 100% 자동 제외
   ↓
4. 방학/학기 상태 판정 (child_temporal_context 조회)
   - status === 'VACATION_CONFIRMED' / 'VACATION_UNCONFIRMED'
     또는 today < expected_school_start_date
     → [방학 모드]: school_required 질문 100% 차단 (filterNonSchoolQuestions)
   - status === 'SEMESTER' (학기 중 확정)
     → [학기 모드]: school_required 질문 정상 공급
   - 상태 미확인 / 판정 실패 (Fallback)
     → [안전 우선 모드 (Safe Default)]: school_required 질문 차단, universal 질문만 공급!
```

#### 핵심 설계 원칙 4가지
1. **판정 주체 및 메커니즘**:
   - **1차 (대화 맥락)**: `child_temporal_context` 테이블 (`context_type = 'vacation_school'`)의 상태 머신 (`VACATION_UNCONFIRMED`, `VACATION_CONFIRMED`, `expected_school_start_date`, `school_question_block_until`). 대화 중 아이의 발화("방학이야", "학교 안 가") 감지 시 전환 (`lib/plan/vacationSchoolContext.ts` 활용).
   - **2차 (표준 학사 캘린더)**: 교육부 표준 여름방학(7월 하순~8월 하순), 겨울방학/봄방학(12월 하순~2월)을 시스템 레벨 '방학 주의 기간'으로 참조하되, 지역/학교별 1~2주 편차는 대화형 상태 머신으로 미세 보정.
2. **판정 실패 시 기본값 (Fail-safe Default)**:
   - **"모르면 학교 전제 질문을 제외하는 쪽이 안전하다"** 원칙을 시스템 불변식으로 확정.
   - 방학 여부가 모호하거나 DB 조회가 실패한 경우, `school_context_tag = 'school_required'` 질문을 후보군에서 전면 차단하고 `universal` 일상 질문만 공급하여 아이가 "지금 방학인데?"라고 반문하는 어색함을 100% 방지.
3. **주말 및 공휴일 판정**:
   - **토·일 주말**: `weekday_affinity` 및 KST 요일 연산만으로 100% 확정 판정 (외부 API 불필요).
   - **법정공휴일/대체공휴일**: KST 양력/음력 법정공휴일 캘린더 매핑. 평일(월~금)이더라도 공휴일이면 학교 전제 질문 자동 차단.
4. **스키마 및 컬럼 단일화**:
   - **새 컬럼 생성 금지**. 기존 `mission_questions.school_context_tag` (`school_required`, `school_optional`, `universal`)을 런타임 단일 필터 기준으로 사용.
