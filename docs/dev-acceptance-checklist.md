# 대표님 Dev 최종 확인 체크리스트

> Dev 서버: `https://k-bestie-v3-dev.vercel.app` (Production 아님 — 이 문서는 Dev 전용, Production URL은 포함하지 않는다)
> 이 문서는 requests/_log.md, git log, 코드 존재 확인을 근거로 작성했다. 확인하지 못한 부분은 "미확인"으로 표기했다.

## 시작 전에 꼭 읽어주세요

- **자동화 검증(agy Playwright QA/codex 정적리뷰)이 이미 통과한 항목**과 **대표님이 실제 스마트폰으로 확인해야 하는 항목**은 다르다. 이 문서는 후자만 다룬다. 자동화가 이미 확인한 세부 사항(버튼 크기, API 미호출 등)은 재확인할 필요 없다 — "실제로 눈으로 보고 손으로 눌러봤을 때 자연스러운가"만 봐주시면 된다.
- **테스트 계정은 반드시 `QA테스트`/`testi02`만 사용한다.** 김서아·김서현 실계정은 아래 별도 섹션(§9)에서만, 그것도 읽기 확인 위주로만 사용한다.
- 아래 항목 중 상당수는 **황금열쇠 차감·미션 진행 기록·놀이 세션 생성** 등 실제 데이터를 만든다. 각 항목의 "데이터 영향" 줄을 확인하고 진행해달라.
- 아직 완료되지 않았거나 대표님 결정이 남은 기능(자유대화 실시간 API 등)은 이 체크리스트에 넣지 않았다.

  4. 문제 중간에 벗어났다가 다시 들어가서 이어하기 확인(재차감 없어야 함)

- **실패 시 캡처**: 차감 전/후 숫자 스크린샷
- **데이터 영향**: **퀴즈마스터 시작 시 황금열쇠 2개 실제 차감.** 부족하면 "미션하러 가기" CTA로 넘어가는지만 확인(실제 시작은 생략 가능).
- [ ] 준비 중 카드 미차감 확인
- [ ] 퀴즈마스터 신규 시작+차감 확인

## 자동화가 이미 확인한 항목 (재확인 불필요)

아래는 codex 정적 리뷰 + agy Playwright E2E QA로 이미 통과 확인된 항목이라, 대표님이 다시 확인하지 않아도 된다:

- 버튼 터치 영역 44px 이상, 접근성(키보드 포커스, aria-label)
- 준비 중 카드 클릭 시 차감 API 자체가 호출되지 않는지(네트워크 레벨)
- 320px~768px 화면 폭 반응형(가로 스크롤 없음)
- 콘솔 에러 발생 여부

## 이 문서에서 제외한 항목 (아직 미완료 또는 대표님 결정 대기)

- **자유대화 실시간 API(Care Premium)**: requests/024, 대표님이 "현행 유지, 진행하지 않음"으로 확정 — 체크리스트 대상 아님
- **026 디자인 통일 전체 화면 회귀**: 토큰 정리는 완료됐으나 전체 화면 단위 시각 회귀 검증은 별도 진행 필요(이 문서 작성 시점 기준 미실시)

## 대표님(김서아·김서현) 실계정 전용 섹션

**절대 원칙**: 이 섹션은 읽기·조회 위주로만 진행한다. 비밀번호 변경, 세션 삭제, 프로필 임의 수정, 황금열쇠 임의 변경, 미션 데이터 초기화는 어떤 경우에도 하지 않는다.

- [ ] 실제 자녀 화면에서 이름/호칭이 올바르게 나오는지 조회만 확인
- [ ] 실제 보유 황금열쇠 수가 화면에 정확히 표시되는지 조회만 확인

그 외 위 1~10번 항목의 실제 조작(미션 진행, 퀴즈 시작 등)은 **QA테스트 계정으로만** 진행하고 실계정으로는 하지 않는다.
