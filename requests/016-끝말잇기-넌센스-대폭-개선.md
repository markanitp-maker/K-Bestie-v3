# 끝말잇기·넌센스 퀴즈 대폭 개선 (대표님 Dev 실사용 지적)

## 0. 완료 시 기대 결과 / 대표님 테스트 정상 프로세스

### 완료 시 기대 결과
- 아이가 판정에 항의하거나 불만을 말했을 때 그 문장을 **낱말로 채점하지 않는다.**
- 사전에 없어도 실제 한국어 낱말이면 받아 준다(`이빨`, `이사` 등).
- 넌센스 퀴즈는 **아이가 그만하자고 할 때까지 계속된다.** 케이가 임의로 끝내지 않는다.
- 퀴즈에 대한 평("이게 무슨 넌센스야?", "시시하네")이 세션을 끝내지 않는다.
- `진행해`, `계속해`, `이어서` 도 다음 문제 요청으로 인식된다.

### 대표님 테스트 정상 프로세스
1. Dev 아이 계정으로 자유대화에 들어간다.
2. 끝말잇기를 시작한다.
3. 케이가 낱말을 거절하면 `그거 있는 단어잖아` 라고 항의한다.
   → 케이가 그 문장을 낱말로 채점하지 않고 인정하는지 확인한다.
4. 사전에 없을 만한 흔한 낱말(`이빨`, `이사`)을 낸다.
   → 받아 주는지 확인한다.
5. 넌센스 퀴즈로 바꾼다.
6. 정답을 맞힌 뒤 `이게 무슨 넌센스야?` 라고 말한다.
   → 세션이 끊기지 않고 다음 문제가 나오는지 확인한다.
7. `진행해` 라고 말한다. → 다음 문제가 나오는지 확인한다.
8. `그만` 이라고 말한다. → 그때 비로소 끝나는지 확인한다.

PASS 기준:
- 항의·불만 문장을 낱말로 채점 0건
- 실제 낱말인데 사전에 없다는 이유로 거절 0건
- 아이가 그만하자고 하지 않았는데 퀴즈가 끝나는 일 0건
- `그만` 은 여전히 즉시 종료
- 초성게임 회귀 0건

## 2. 근거 — 대표님 Dev 실사용 로그 (김서아, 2026-08-20 08:28~09:28 KST)

### 2-1. 끝말잇기: 항의 문장을 낱말로 채점
```
09:23:56 아이  이빨
09:23:58 케이  "이빨"은 내가 잘 모르는 단어네!
09:24:22 아이  이빨 이 "이"로 시작하는 단어자나?
09:24:24 케이  "단어자나"는 내가 아직 잘 모르는 단어네!
```
문장이 오면 마지막 한글 토큰을 낱말로 보던 것이 원인이다. 아이 입장에서는 케이가
말을 아예 못 알아듣는 것으로 보인다.

대표님: "여전히 멍청하다. 끝말잇기는 전혀 개선이 안됨. 대폭 고도화 이모. 게임 방법도
모르고, 아는 단어도 부족하고, LLM 연동해서 끝말잇기 진행하라니까"

### 2-2. 넌센스 퀴즈: 케이가 임의로 종료
```
09:27:18 아이  메아리        → 정답
09:27:28 케이  와, 이걸 바로 맞히네! ... 다음 문제 또 풀어볼래?
09:27:37 아이  이게 무슨 넌센스야?
09:27:39 케이  그치, 좀 뻔하긴 했지? 그래도 다음 넌센스 퀴즈 마저 해볼까?
09:27:44 아이  진행해
09:27:47 케이  잠깐, 내가 순서를 헷갈렸어. 어떤 놀이부터 할까?
```
`이게 무슨 넌센스야?` 가 화제 전환으로 분류돼 **세션이 조용히 끝났다.** 그 다음
`진행해` 는 붙을 세션이 없어 케이가 즉흥으로 문제를 만들었고, 가짜 게임플레이 가드가
그것을 메뉴 문구로 갈아치웠다.

대표님: "아이가 종료 할 때 까지 계속 넌센스 퀴즈", "퀴즈 내라고 했는데, 케이 멋데로
종료 시키네"

### 2-3. 초성게임은 통과
힌트가 내용 힌트로 나오고(`비누 방울 씻을 때 쓰는 거잖아`, `놀이터에 가면 타는 거`),
오타도 관용한다(`모께레토` → 아깝다, `줄니기` → 비슷했는데). 이 부분은 건드리지 않는다.

## 3. 요구사항

### 3-1. 판정 이의·불만은 낱말로 채점하지 않는다
- `isWordChainDispute(utterance)` 를 두고 낱말 추출 **전에** 검사한다.
- 걸리면 세션을 유지하고, 케이가 아이 말에 먼저 반응한 뒤 다시 낱말을 청한다.
  채점도 라운드 기록도 하지 않는다.
- **구조로 가르지 않는다.** 문장 길이·토큰 수로는 안 된다 — 아이는 군말을 늘어놓고
  마지막에 낱말을 말하기도 한다(`아 진짜 한참 째 끝말잇기 하긴 하는 구나 귀찮냐 차표`).
  내용으로 가른다: 판정 이의(`~자나`, `맞는데`, `있는 단어`), 실력 비난(`멍청`, `개판`,
  `개선`), 규칙 질문(`규칙이 뭐야`, `어떻게 하는`).
- 지루하다·귀찮다 같은 기분 표현은 이의로 보지 않는다(낱말을 함께 말할 수 있다).
- 빈 발화는 이 가드에 걸지 않는다 — 그건 "잘 못 들었어" 로 안내해야 한다.

### 3-2. 사전에 없는 낱말은 LLM 이 판정한다
- `judgeWordChainWord()` 를 새로 둔다. 묻는 것은 하나뿐이다 — "이게 한국어 낱말인가".
- **역할 분담은 유지한다(010 §0).** 끝글자 규칙·차례·다음 낱말은 여전히 엔진이
  결정론으로 정한다. 그래서 케이가 게임을 지어내는 일은 생기지 않는다.
- 부르는 조건: 거절 사유가 `NOT_IN_DICTIONARY` 이고, **끝글자 규칙을 이미 만족**하며,
  이미 쓴 낱말이 아닐 때만.
  (`chainRules` 는 사전을 3단계, 규칙을 5단계에서 보므로 `NOT_IN_DICTIONARY` 거절은
  규칙을 아직 안 본 상태다. 규칙을 어긴 낱말을 낱말이라는 이유로 받으면 게임이 무너진다.)
- 받는 기준: 실제 낱말이고 아이에게 안전하면 받는다. 아이가 잘 안 쓰는 말이어도 받는다 —
  사전에 없다는 이유로 거절당하는 경험이 훨씬 나쁘다.
- 실패·지연은 삼킨다. 판정을 못 받으면 사전 결과를 그대로 쓴다. 제한 시간 1.8초.
- 받아 준 낱말은 사전에 없으므로 낱말에서 엔트리를 만들어 이후 흐름에 쓴다.

### 3-3. 넌센스는 아이가 그만할 때까지 계속한다
- 퀴즈 **자체에 대한 말**은 화제 전환이 아니다. 세션을 끝내지 않고 다음 문제로 넘긴다.
- `그만`·힌트·정답 공개 요청이 먼저 처리되므로 그 의도들을 가리지 않는다.
- 진짜 감정·갈등·신체 불편은 여전히 화제 전환이다(안전이 먼저다).
- `어려워`·`몰라` 는 힌트 요청으로 남긴다 — 새 문제보다 힌트가 먼저다.
- `진행해`, `계속해`, `이어서`, `그 다음`, `넘어가` 를 다음 문제 요청에 넣는다.

## 4. 남기는 것 (이번 범위 밖)
- **넌센스 문항 품질.** `산에서 내가 외친 말을 따라 하는 것은?` → 메아리 처럼 말장난이
  아니라 상식 문제인 문항이 있다. 대표님이 "이게 무슨 넌센스야?" 라고 한 지점이다.
  이건 코드가 아니라 500문항 데이터 문제이므로 별건으로 다룬다.
- 힌트가 정답 조립법을 알려주는 문항(`방학동`: "휴가 기간 뒤에 마을 동 한자를 붙여 봐").

## 5. 검증
- 실측 발화를 그대로 쓴 단위 테스트(항의 문장, `진행해`, `이게 무슨 넌센스야?`).
- LLM 판정기: 수용·거절·안전 차단·형식 오류·타임아웃·호출 실패를 각각 확인한다.
- Dev 배포 후 실화면 QA — 끝말잇기 항의·사전 밖 낱말, 넌센스 계속 진행, `그만` 즉시 종료.
- 초성게임 회귀 확인.
