# 작업 지시서

긴급 작업 순서

## 1. Mission v3 하루 1회 정책과 미션 알림 불일치 수정
현재 Production 미션 알림은 실제로 서로 다른 2개 크론에서 발송되고 있다.

- 1차 알림: 낮 시간대
- 2차 알림: 18:00
- 두 알림은 각각 독립적으로 발송 조건을 판단함

현재 문제:
- Mission v3 Track2에서는 **하루 전체 미션 1세션만 가능**하도록 변경됨
- 그러나 2차 알림 시스템은 기존 `round2_night` 완료 여부만 확인함
- 따라서 아이가 이미 1차 미션을 완료해도 18:00에 다시 미션 알림이 발송될 수 있음
- 사용자가 알림을 눌러 들어가면 하루 1회 가드 때문에 실제 미션은 실행할 수 없음

즉, **알림 정책과 실제 Mission v3 실행 정책이 불일치하는 버그**다.

작업:
- Mission v3의 하루 1세션 정책을 미션 알림 발송 조건에도 동일하게 적용
- 당일 Mission v3를 이미 완료했거나 하루 사용 가능 세션을 소진한 아이에게는 이후 미션 알림을 발송하지 않음
- `round1`, `round2_night` 등 레거시 2회 미션 개념이 Mission v3 정책과 충돌하는 부분 전체 조사
- 화면 문구뿐 아니라 크론, API, DB 조건, 알림 발송 로직을 함께 수정
- 1차 미션 완료 후 18:00 2차 알림이 발송되지 않는 것을 Dev에서 검증
- 아직 그날 미션을 하지 않은 아이에게 필요한 알림이 정상 발송되는 것도 함께 검증


## 2. 자유대화 키보드 입력 시 상태 표시 복구

미션 모드
  미션 화면(app/child/missions, 키보드 입력 중 텍스트 모드): 마이크 인디케이터가 케이 말풍선 텍스트를 가리고, 상태뱃지가     
  텍스트 모드인데도 음성 상태("말하는 중")를 그대로 표시하며, 키보드가 열려 있어도 "채팅창 닫기" 버튼이 그대로 노출돼 케이의 
  답변 말풍선이 화면 밖으로 밀려남.
  → 키보드 열림 시: 마이크 인디케이터 숨김 / 상태뱃지를 텍스트 모드 기준으로 갱신 / "채팅창 닫기" 버튼 숨김(또는 축소)해서   
  대화 내용이 항상 보이게 수정.

자유 대화 모드
유대화 텍스트 모드로 전환해도 iOS 마이크 사용 표시(상태바 검은 알약)가 계속 떠 있음 — 마이크 세션이 백그라운드에서 계속  
  켜진 채로 추정.
  → 텍스트 모드 전환 시 마이크 스트림을 실제로 정지/mute하고 있는지 확인 후, 안 되고 있으면 전환 시점에 마이크 끄도록 수정.


현재 자유대화에서 **키보드 입력 모드 사용 시 상태 표시가 나타나지 않는 문제**가 있다.

확인 대상 상태:
- `대기중`
- `듣는중`
- `말하는중`

작업:
- 음성 입력과 키보드 입력 각각의 상태 머신 및 UI 렌더링 조건 확인
- 키보드 모드로 전환해도 현재 대화 상태를 사용자가 확인할 수 있도록 수정
- 키보드 입력 → 전송 → 케이 응답 생성 → 케이 발화/출력 → 다시 입력 가능 상태까지 상태 전환 검증
- 음성 모드 상태 표시에 회귀 문제가 발생하지 않도록 함께 확인

미션 대화 키보드 입력 문제도 고쳐라 (076-mission-keyboard-ios-viewport-safe-area-layout-request)

## 3. `docs/plans/` 미착수·부분완료 작업 처리

`docs/plans/` 총 19개 중 아래 5건이 미착수 또는 부분완료 상태이므로, **문서의 완료 표기나 기존 대시보드 기록을 그대로 신뢰하지 말고 실제 코드·화면 배선·Dev/Production 동작을 기준으로 확인하여 미완료 범위를 끝까지 구현한다.**

### 3-1. `073-mission-v3-production-cutover`
현재 상태:
- 백엔드 시간 게이트만 완료
- 화면 배선 미완료
- Dev 검증 미완료
- Production 전환 미완료

작업:
- Mission v3 화면 실배선 완료
- Dev E2E 검증
- Production 전환 조건 및 기존 미션 로직과 충돌 여부 확인
- 검증 완료 후 Production 반영

### 3-2. `073-mission-v3.md`
현재 상태:
- 백엔드 코어만 구현

작업:
- 프론트엔드/화면과 Mission v3 백엔드 코어 연결
- 시작 → 진행 → 완료 → 재진입까지 실제 사용자 흐름 검증
- 기존 미션 UI/상태관리의 레거시 경로가 남아 있으면 정리
