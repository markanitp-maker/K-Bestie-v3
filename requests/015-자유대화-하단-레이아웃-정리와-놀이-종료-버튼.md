# 자유대화 하단 정리 — 카드 여백 제거, 한 줄 배치, 케이놀이 종료 버튼

## 0. 완료 시 기대 결과 / 대표님 테스트 정상 프로세스

### 완료 시 기대 결과
- 황금열쇠 카드의 흰 배경이 글자에 붙는다. 양옆에 넓은 빈 흰 공간이 없다.
- 텍스트 모드에서 소프트 키보드가 올라와도 **상태 표시와 황금열쇠가 한 줄**에 있고,
  위 말풍선이 잘리지 않는다.
- 케이놀이 중에 **`종료` 버튼**이 입력줄 바로 위 왼쪽에 보인다. 누르면 놀이가 끝나고
  원래 입력 모드로 돌아온다.
- 마이크는 화면 정중앙에 그대로 있고, 카드·버튼이 마이크·키보드·FAQ와 겹치지 않는다.

### 대표님 테스트 정상 프로세스
1. Dev 아이 계정으로 자유대화에 들어간다.
2. 황금열쇠 카드의 흰 배경이 글자에 붙어 있는지 본다.
3. 키보드 버튼을 눌러 텍스트 모드로 들어가고, 입력창을 눌러 키보드를 올린다.
4. 상태 표시와 황금열쇠가 한 줄에 있고 위 말풍선이 잘리지 않는지 본다.
5. 케이놀이를 시작한다.
6. 입력줄 위 왼쪽에 `종료` 버튼이 보이는지 확인한다.
7. `종료` 를 누른다. 케이가 마무리 인사를 하고 놀이가 끝나는지, 마이크·토글이
   돌아오는지 확인한다.

PASS 기준:
- 카드 흰 배경 폭이 내용 폭이다(칸 폭 전체를 채우지 않는다)
- 카드 문구는 2줄 이하
- 키보드 올라온 상태에서 상태 표시와 황금열쇠가 같은 y축(한 줄)
- 놀이 중 `종료` 버튼 노출, 놀이가 아닐 때 미노출
- `종료` 누른 뒤 activePlaySkillId 가 null 이 되고 입력 모드가 복귀
- 마이크 x중심 = 뷰포트 중심 (390 → 195, 412 → 206)
- 겹침 0, 화면 밖 잘림 없음

## 3. 요구사항

### 3-1. 카드가 내용 폭을 쓴다
- `DailyGoldenKeyStatus` 에서 `w-full` 을 뺀다. `max-w-full` 로 넘침만 막는다.
- 좌우 여백 `px-3` → `px-2.5`.
- 음성 모드 칸을 `justify-self-stretch` → `justify-self-center`.
- 텍스트 모드 래퍼의 `max-w` 제한을 없앤다(이제 불필요).
- 로딩 스켈레톤도 고정 폭으로 두어 로딩 중에 카드가 넓어지지 않게 한다.

### 3-2. 키보드가 올라오면 한 줄로 합친다
- 상태 알약 JSX 를 변수로 뽑아 두 자리에서 재사용한다.
- `conversation-status-panel` 은 **키보드가 닫힌 때만** 렌더한다.
  그리드 첫 행이 `minmax(0,1fr)` 이므로 이 `auto` 행이 사라진 만큼 말풍선이 커진다.
- 입력줄 위 행을 `flex items-center` 로 두고 `[종료] [상태 알약] [황금열쇠]` 를 담는다.
  항목이 둘 이상이면 `justify-between`, 카드만 있으면 `justify-end`.

### 3-3. 놀이 종료 버튼
- 놀이 중(`isPlayActive`)에만 노출한다.
- 위치: 입력줄 바로 위 행의 왼쪽.
- 디자인: `--color-k-navy` 배경, 흰 굵은 글씨 `종료`, `rounded-[14px]`,
  눌림 효과(`active:scale-95`). 응답 중에는 비활성.
- 동작: 아이가 `그만` 이라고 말한 것과 **같은 경로**로 보낸다.
  클라이언트에서 입력모드만 되돌리면 서버 세션이 살아 있어 다음 턴에 게임이
  되살아나므로, 종료는 서버가 해야 한다. 케이가 제 말투로 마무리하고
  `activePlaySkillId: null` 이 내려오면서 기존 복귀 흐름을 그대로 탄다.

### 3-4. 013 §3-6 과의 관계
013 이 막으려던 것은 "게임이 살아 있는데 음성으로 몰래 빠져나가는 것" 이다.
`종료` 는 게임을 **정상 종료**시키므로 충돌하지 않는다. "채팅창 닫기" 는 놀이 중
계속 숨긴다.

## 4. 검증
- Dev 배포 후 390px / 412px 실화면 QA.
- 카드·마이크·키보드·FAQ `boundingBox()` 로 겹침 0, 마이크 정중앙 확인.
- 카드 폭이 칸 폭보다 작아졌는지 숫자로 비교.
- 키보드 올린 상태에서 상태 알약과 카드의 y 가 같은 줄인지 확인.
- 놀이 중 `종료` 노출 → 클릭 → `activePlaySkillId: null` 과 입력모드 복귀 확인.
