# 내친구 케이(K-Bestie-v3) 아이 홈 화면 UX 변경 요청서

## 목적

현재 아이 홈 화면은 하단 탭 메뉴 기반 구조로 되어 있으나, 내친구 케이 서비스 특성상 아이가 메뉴를 탐색하는 구조보다 케이를 만나 바로 대화·미션·놀이로 연결되는 단일 홈 중심 UX가 적합하다.

이번 변경은 하단 Navigation 제거와 PWA 설치 유도 영역 추가를 목표로 한다.

---

# 변경 요약

## 제거

- 아이 화면 하단 고정 메뉴 바 전체 제거
- 홈 / 미션 / 대화 / 놀이 / 설정 탭 메뉴 제거
- 아이 전용 설정 화면 제거
- 아이 화면 내 설정 진입 경로 제거

## 유지

- 미션 기능
- 대화 기능
- 놀이 기능
- 부모 영역 설정 기능
- 보호자 설정 및 아이 정보 관리 기능

## 추가

- 화면 하단 PWA 설치 유도 카드 추가

---

```
┌─────────────────┐
│ 내친구 케이 로고 │

│ [대화하기]       │
│ [케이와 놀이]    │
│                 │
│ PWA 설치 카드    │
└─────────────────┘
```

---

# 1. 하단 Navigation 제거

## 삭제 대상

- BottomNavigation 컴포넌트
- MobileTabBar
- 하단 메뉴 아이콘
- active route 상태 관리
- 설정 메뉴 링크

## 처리 원칙

기존 기능 페이지는 삭제하지 않는다.

홈 화면에서 카드 형태로 접근하도록 변경한다.

변경 후 구조:

```
아이 홈
 ├─ 미션 진행 카드
 ├─ 대화하기 카드
 └─ 케이와 놀이 카드
```

---

# 2. 아이 설정 화면 제거

## 삭제 대상

- 아이 전용 설정 페이지
- 아이 화면 설정 메뉴

## 이유

아이 사용 흐름은 아래 구조로 단순화한다.

```
케이 만나기
      ↓
미션
      ↓
대화
      ↓
놀이
```

## 유지 위치

다음 기능은 부모 영역에서 유지한다.

- 아이 정보 관리
- 보호자 설정
- 구독 관리
- 개인정보 관리
- 서비스 설정

---

# 3. PWA 설치 카드 추가

## 위치

기존 하단 메뉴 영역을 대체하여 홈 화면 최하단 배치

---

## 디자인

### 카드

- 흰색 배경
- 둥근 모서리
- 약한 그림자
- 좌우 margin 16px
- 높이 약 72~88px

---

## 구성

### 왼쪽 아이콘

사용:

- PWA 아이콘
또는
- 내친구 케이 말풍선 심볼

크기:

- 40~48px

---

### 제목

```
내친구 케이 설치하기
```

스타일:

- K-Navy
- Bold
- 18px

---

### 설명

```
홈 화면에 케이를 두고 더 쉽게 만나요
```

스타일:

- 보조 Gray
- 13~14px

---

### 버튼

```
설치하기
```

스타일:

- K-Navy 배경
- White 텍스트
- Pill 형태

주의:

K-Orange 위 흰색 작은 텍스트 사용은 접근성 문제로 사용하지 않는다.
