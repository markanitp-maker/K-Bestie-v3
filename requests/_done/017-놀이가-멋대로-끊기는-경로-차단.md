# 놀이가 아이 뜻과 무관하게 끊기는 경로 전부 차단

## 0. 완료 시 기대 결과 / 대표님 테스트 정상 프로세스

### 완료 시 기대 결과
- 아이가 오타를 쳐도(`흰트줘`, `모루겠어`) 힌트 요청으로 알아듣는다.
- 초성게임이 힌트를 달라는 말에 **정답을 말하지 않는다.**
- `계속`, `진행해` 를 낱말로 채점하지 않는다.
- 케이가 이어갈 말을 못 찾으면 축하하고 **새 판을 시작한다.** 놀이를 끝내지 않는다.
- 아이가 놀이를 지적했을 때 "기억이 안 나" 로 회피하지 않는다.
- 아이가 `그만` 이라고 할 때만 놀이가 끝난다.

### 대표님 테스트 정상 프로세스
1. Dev 아이 계정으로 초성게임을 시작한다.
2. `흰트줘` 라고 오타로 친다. → 정답이 아니라 힌트가 나오는지 확인한다.
3. 끝말잇기로 바꾼다. 케이 낱말 뒤에 `계속` 이라고 친다.
   → 낱말로 채점되지 않고 놀이가 이어지는지 확인한다.
4. 케이가 이어갈 말을 못 찾을 때까지 진행한다.
   → 축하 후 새 판이 바로 시작되는지 확인한다.
5. 넌센스로 바꾸고 `모루겠어` 라고 친다. → 힌트가 나오는지 확인한다.
6. 놀이에 대해 지적한다(`아까랑 다르잖아`).
   → "기억이 안 나" 가 아니라 놀이를 이어가는 말이 오는지 확인한다.
7. `그만` 이라고 한다. → 그때 비로소 끝나는지 확인한다.

PASS 기준:
- 힌트 요청에 정답 노출 0건
- 오타 힌트 요청 인식 실패 0건
- 진행 지시를 낱말로 채점 0건
- 아이가 그만하자고 하지 않았는데 놀이가 끝나는 일 0건
- 정상 낱말이 진행 지시·이의로 오인되는 일 0건

## 2. 근거 — 대표님 Dev 실사용 (김서아, 2026-08-20 10:45~10:52 KST)

대표님: "게임 종료를 안 원했는데, 멋데로 또 종료하네! 개판이네. 다 개선해"

### 2-1. 초성 힌트가 정답을 그대로 말했다
```
10:46:03 아이  흰트줘
10:46:05 케이  코끼리야! 동물원이나 책에서 본 적 있지?      ← 초성 ㅋㄲㄹ 의 정답
10:46:21 아이  헐… 힌트 달라고 했더니 정답을 알려주네?
```
정답 유출 가드(`detectChosungAnswerLeak`)는 `answerMustNotAppear` 가 설정된 턴에만
돈다. 오타가 힌트 요청으로 인식되지 않아 스킬이 턴을 처리하지 못했고, 그러면 그 값이
없어 가드가 **아예 돌지 않는다.** 자유대화로 빠진 케이가 대화 맥락에 있던 정답을 말했다.

즉 이 경우 **인식 폭이 곧 가드다.**

### 2-2. 넌센스도 같은 이유로 끊겼다
```
10:51:33 아이  모루겠어
10:51:36 케이  미안, 내가 착각했어. 초성게임이랑 끝말잇기 중에 뭐 할래?
```

### 2-3. `계속` 을 낱말로 채점했다
```
10:49:02 아이  계속
10:49:06 케이  "계속"은 내가 아직 잘 모르는 단어야!
```

### 2-4. 케이가 막히면 게임을 끝냈다
```
10:49:15 케이  "이름" 다음으로 이어갈 말을 케이가 못 찾겠어! 이번 판은 네가 이겼다!
10:49:50 아이  이것도… 아이가 이기면, 다음 끝말 잇기 해야지. 왜 멋데로 종료하니?
```

### 2-5. 지적에 "기억이 안 나" 로 회피했다
```
10:46:21 아이  헐… 힌트 달라고 했더니 정답을 알려주네?
10:46:24 케이  그건 아직 잘 기억이 안 나는데, 다시 말해줄래?
10:47:06 아이  개판이구만… 다시 진행해. 아이가 게임 종료, 그만 외치기 전까지 …
10:47:09 케이  음, 그건 내가 잘 기억이 안 나네. 다시 얘기해 줄래?
```
기억 위조 가드의 대체 문구다. 목적 자체는 옳지만, 놀이 중에 이 말이 나오면 벽이 된다.

## 3. 요구사항

### 3-1. 오타를 알아듣는다
- 초성·넌센스 힌트 키워드에 흔한 변형을 넣는다:
  `흰트`, `핀트`, `힌투`, `힌드`, `힌튜`, `hint`, `모루`, `모룰`, `몰르`, `몰라겠`,
  `머르겠`, `머겠`.
- 아이는 키보드로 치고 음성인식도 거친다. 둘 다에서 나오는 변형을 받는다.
- **정답을 삼키지 않아야 한다.** 초성 낱말 풀과 끝말잇기 사전을 전수 검사해 충돌 0을
  확인한다.

### 3-2. 진행 지시는 낱말이 아니다
- `계속`, `계속해`, `진행`, `진행해`, `이어서`, `고고`, `가자`, `다시`, `또 하자` 등.
- **문장 전체가 그 말일 때만** 진행 지시로 본다. `계속기`·`가자미`·`다시마` 같은
  낱말을 삼키면 안 된다.

### 3-3. 아이가 이기면 새 판을 시작한다
- 케이가 이어갈 말을 못 찾아도 세션을 닫지 않는다.
- `GIVE_UP` 라운드를 남기고 상태는 `CHILD_TURN` 으로 둔다.
- 새 첫 낱말은 최근 첫 낱말과 이번 판에서 쓴 낱말을 함께 피해 고른다.
- 축하한 뒤 곧바로 새 첫 낱말을 제시한다. 놀이를 끝내자는 말은 하지 않는다.

### 3-4. 놀이 중에는 기억 회피 문구를 쓰지 않는다
- 기억 위조 가드의 판정 로직은 그대로 둔다 — 없는 기억에 맞장구치지 않는다.
- 다만 놀이가 살아 있을 때는 놀이를 이어가는 문구로 받는다.
- 같은 문구를 반복하지 않는다.

### 3-5. 판정 이의를 더 넓게 잡는다
실측 문장이 안 걸렸다:
`또 이러네… 이모 시작하는 이빨을 말했는데, 왜 이로 시작하는 단어여야 한다고, 아이를
화나게 만드니?`
`왜 ~ 단어/안 되`, `~했는데 ~왜`, `화나게`, `또 이러` 를 추가한다.

## 4. 검증
- 실측 발화를 그대로 쓴 단위 테스트.
- **오탐 전수 검사**: 초성 낱말 풀(80) / 끝말잇기 사전(1810) / 아이가 할 만한 평범한 말 20개.
- Dev 배포 후 실제 대화로 §0 의 7단계를 확인한다.
