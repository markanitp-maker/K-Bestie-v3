# 케이와 대화 입력 모드 선택 UI 개선 (타이핑 / 핸즈프리 세그먼트 컨트롤)

## 0. 완료 시 기대 결과 / 대표님 테스트 정상 프로세스

### 완료 시 기대 결과

현재 부모 화면 `케이와 대화`의 입력 모드 선택 UI는 하나의 버튼만 표시되고 상태에 따라 텍스트만 변경되는 구조이다.

예:
- 현재 타이핑 상태 → "⌨️ 타이핑"
- 현재 핸즈프리 상태 → "🎤 핸즈프리"

이 방식은 사용자가 현재 상태인지, 클릭하면 변경되는 대상인지 직관적으로 알기 어렵다.

최종 목표:

두 버튼을 항상 동시에 표시한다.
