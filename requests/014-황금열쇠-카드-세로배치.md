# 자유대화 하단 "오늘의 황금열쇠" 카드 내부 배치를 세로로 바꿔라

## 0. 완료 시 기대 결과 / 대표님 테스트 정상 프로세스

### 완료 시 기대 결과
- 황금열쇠 카드 안에서 🔑 아이콘이 **글자 위**에 놓인다.
- 아이콘과 두 줄 문구가 **가운데 정렬**로 세로로 쌓인다.
- 카드가 가로로 짧아지고 세로로 조금 높아진다.
- 문구는 그대로다 — `오늘의 황금열쇠` / `아직 안 받았어` / `오늘 받았어! ✓`.
- 마이크·키보드·자동수동 토글·마스코트·받침대·FAQ 버튼의 위치와 크기는 그대로다.
- iPhone 390px, Android 412px 둘 다에서 카드가 화면 밖으로 잘리지 않는다.

### 대표님 테스트 정상 프로세스
1. Dev 아이 계정으로 자유대화(`/chat`)에 들어간다.
2. 하단 오른쪽 황금열쇠 카드를 본다.
3. 🔑 가 글자 위에 있고 가운데 정렬인지 확인한다.
4. 마이크가 화면 정중앙에 그대로 있는지 확인한다.
5. 키보드 버튼으로 텍스트 모드에 들어가서도 카드가 같은 배치인지 확인한다.

PASS 기준:
- 아이콘이 글자 위에 있음
- 아이콘·문구 모두 가운데 정렬
- 문구가 3줄 이상으로 쪼개지지 않음
- 마이크 x중심 = 뷰포트 중심 (390 → 195, 412 → 206)
- 카드가 마이크·키보드·FAQ 버튼과 겹치지 않음
- 화면 밖 잘림 없음

## 3. 요구사항

### 3-1. 카드 내부를 세로 스택으로 바꾼다
- 바깥 컨테이너를 `flex-row` 에서 `flex-col` 로 바꾼다.
- `items-center` 로 가로 가운데 정렬한다.
- 아이콘과 글자 블록 사이 간격은 지금의 가로 간격보다 좁게 둔다(세로 간격은
  가로보다 크게 느껴진다).

### 3-2. 글자도 가운데 정렬한다
- 글자 블록의 두 줄(`오늘의 황금열쇠`, 상태 문구)을 `text-center` 로 둔다.

### 3-3. 건드리지 말 것
- 글자 크기(`text-[12px]`)를 줄이지 않는다.
- `break-keep` 을 유지한다 — 한글 낱말이 중간에서 쪼개지면 안 된다.
- `data-ui="freechat-daily-key-status"` 와 `data-state` 속성을 유지한다(QA 가 쓴다).
- 로딩 스켈레톤도 같은 세로 배치로 맞춘다. 그래야 조회가 끝나는 순간 카드 모양이
  덜컥 바뀌지 않는다.
- `absolute` top/left, 음수 마진, `transform` 으로 억지 보정하지 않는다.

### 3-4. 텍스트 모드에서도 같아야 한다
`app/chat/page.tsx` 는 텍스트 모드에서 이 카드를 `max-w-[240px]` 로 감싸 오른쪽에
붙여 둔다. 세로 배치로 바뀌면 그 폭이 과하게 넓을 수 있다. 실제 화면을 보고
필요하면 폭만 조정한다 — 카드 컴포넌트 안쪽은 두 모드가 같아야 한다.

## 4. 검증
- Dev 배포 후 390px / 412px 실화면 QA.
- 카드·마이크·키보드·FAQ 버튼의 `boundingBox()` 를 숫자로 측정해 겹침 0 을 확인한다.
- 마이크 x중심이 뷰포트 정중앙인지 확인한다.
- 로딩 중 → 조회 완료 전환에서 카드 크기가 크게 튀지 않는지 확인한다.
