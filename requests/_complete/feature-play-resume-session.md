# Feature Request: KY 놀이 전체 공통 이어하기(Resume Session) 기능 구현

## 목적

내친구 케이 앱 내 모든 놀이 콘텐츠에서 아이가 진행 중이던 상태를 저장하고, 앱 종료·화면 잠금·백그라운드 이동·네트워크 단절 이후 다시 접속했을 때 기존 진행 위치부터 이어서 진행할 수 있도록 공통 Resume Session 기능을 구현한다.

대상 놀이:
- 퀴즈마스터
- MBTI
- 만화책 읽기
- 향후 추가되는 모든 KY 놀이

---

# 핵심 요구사항

## 1. 메인 앱이 Resume 상태 관리의 기준이 된다

내친구 케이 메인 앱은 놀이 홈 화면에서 현재 진행 중인 놀이 여부를 판단해야 한다.

사용자가 놀이 메뉴 진입 시:

1. 진행 중 세션 조회
2. 이어하기 가능한 놀이 존재 여부 확인
3. 존재하면 해당 놀이 카드 또는 버튼에 "이어하기" 표시

---

# 2. 이어하기 동작

사용자가 이어하기를 선택하면:

- 새 놀이 세션 생성 금지
- 황금열쇠 재차감 금지
- 기존 진행 상태 그대로 복원

해야 한다.

예:

## 퀴즈마스터

기존 상태:

```
총 문제: 10개

완료:
1~6번

현재:
7번 문제 진행 중
```

앱 재접속 후:

```
이어하기 선택

→ 7번 문제 화면 표시
```

---

## MBTI

기존 상태:

```
20문항 중
13개 완료
```

이어하기:

```
14번째 문항부터 시작
```

---

## 만화책

기존 상태:

```
3화
페이지 18
```

이어하기:

```
페이지 19부터 시작
```

---

# 3. 세션 상태 기준

공통 Session 상태 관리 필요.

예시:

play_sessions

| 컬럼 | 설명 |
|---|---|
| id | 세션 ID |
| child_id | 아이 ID |
| play_type | quizmaster / mbti / comic |
| status | in_progress / completed / expired |
| progress_data | 놀이별 진행 JSON |
| last_activity_at | 마지막 활동 시간 |
| created_at | 생성 시간 |

---

# 4. 세션 만료 정책

이어하기 가능:

- status = in_progress
- 마지막 활동 시간이 유효 범위 내

이어하기 불가:

- completed
- expired
- 강제 종료 처리

---

# 5. 놀이별 데이터 연결

공통 Session은 상태 판단용으로 사용하고,
실제 상세 데이터는 각 놀이 서비스가 관리한다.

예:

```
play_sessions
      |
      |
      +-- quizmaster
      |       |
      |       quiz_attempts
      |
      +-- MBTI
      |       |
      |       mbti_sessions
      |
      +-- comic
              |
              comic_progress
```

---

# 6. 황금열쇠 처리 정책

황금열쇠는 최초 시작 시에만 차감한다.

새 시작:

```
황금열쇠 확인
↓
1개 차감
↓
놀이 세션 생성
```

이어하기:

```
기존 세션 복원
↓
황금열쇠 차감 없음
```

---

# 7. Handoff Token 정책

handoff token은 최초 진입 인증용이다.

사용하지 않는 것:

- 이어하기 판단
- 진행 상태 저장
- 마지막 위치 판단

이어하기 판단 기준:

```
play_session
+
놀이별 진행 데이터
```

---

# 8. 오류 처리

다음 상황에서도 진행 상태 유지:

- 앱 강제 종료
- 화면 잠금
- 네트워크 끊김
- 브라우저 종료
- 앱 백그라운드 이동

단, 데이터 저장 시점 기준으로 마지막 정상 상태부터 복원한다.
