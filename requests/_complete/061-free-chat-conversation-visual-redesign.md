# 061 — 자유대화 화면 비주얼·레이아웃 전면 고도화

## 1. 작업 목적

아이의 자유대화 화면을 미션 대화 화면과 동일한 디자인 시스템으로 고도화한다.

자유대화와 미션은 동일한 케이 대화 경험을 제공하므로 다음 시각 요소는 동일한 컨셉을 사용한다.

- 최근 케이 발화 중심의 3단계 대화 히스토리
- 현재 케이 발화를 가장 크게 강조하는 오렌지 테두리 말풍선
- 화면 중심의 큰 케이 마스코트
- 케이 뒤의 은은한 Halo/동심원 효과
- 더 크고 입체적인 받침대
- 마스코트 오른쪽의 현재 음성 상태 표시
- 받침대와 연결된 pill 형태의 자동/수동 토글
- 하단 중앙의 강조된 오렌지 마이크 버튼
- 좌하단 키보드 버튼
- 하늘색 → 크림색 배경
- 구름·별·작은 종이조각 등의 가벼운 장식 요소

단, 자유대화에는 미션과 다른 두 가지 명확한 차이가 있다.

1. 미션 진행률/게이지 UI를 표시하지 않는다.
2. 마스코트 왼쪽의 소리 켜짐/소리 꺼짐 상태 컨트롤을 표시하지 않는다.

즉 자유대화는 미션 화면의 시각 언어를 공유하되, 진행률과 좌측 소리 컨트롤이 없는 더 단순하고 대화 중심적인 화면으로 구현한다.

---

## 2. 가장 중요한 원칙

이번 작업은 자유대화의 기능을 다시 설계하는 작업이 아니다.

> 기존 자유대화 기능은 그대로 유지하고 UI/UX만 고도화한다.

변경 금지:

- 자유대화 응답 생성 로직
- 케이 발화 데이터
- LLM Wiki 회상
- 음성 STT/TTS
- 자동/수동 동작
- 마이크 상태 관리
- 키보드 입력
- 세션 처리
- 메시지 저장
- API
- DB
- 부모 리포트 연계

---

## 3. 구현 전 필수 확인

이미지나 외부 시안을 전제로 작업하지 않는다.

Claude Code는 먼저 저장소에서 자유대화 화면의 실제 구현을 확인하고 다음을 기록한다.

1. 자유대화 실제 라우트
2. 자유대화 메인 레이아웃 컴포넌트
3. 미션 화면과 공유하는 컴포넌트 여부
4. 대화 히스토리 렌더링 함수
5. 현재 발화 말풍선 구현 위치
6. 케이 마스코트 컴포넌트와 현재 CSS 크기
7. 받침대 크기
8. 오른쪽 voice state 표시 컴포넌트
9. 자동/수동 토글 구조
10. 마이크/키보드 버튼 구현 위치
11. 전체 Grid/Flex 구조
12. iPhone 390×844 기준 주요 요소의 getBoundingClientRect()

미션 화면에서 이미 구현한 디자인 컴포넌트 또는 스타일 토큰을 재사용할 수 있으면 재사용하고, 동일한 UI를 자유대화용으로 별도 복제하여 중복 코드를 만들지 않는다.

단, 자유대화 기능과 미션 기능이 결합되어 회귀 위험이 커지는 무리한 공통화는 하지 않는다.

## 4. 자유대화 최종 화면 구조

최종 구조는 다음과 같다.

```text
┌─────────────────────────────┐
│ ← 뒤로        대화      로그아웃 │
├─────────────────────────────┤
│                             │
│      지지난 케이 발화        │
│                             │
│       지난 케이 발화         │
│                             │
│ ┌─────────────────────────┐ │
│ │      현재 케이 발화      │ │
│ └──────────▽──────────────┘ │
│                             │
│            K        [상태]   │
│        큰 마스코트            │
│      ━━━ 큰 받침대 ━━━       │
│          [자동][수동]         │
│                             │
│ [키보드]       [큰 마이크]    │
└─────────────────────────────┘
```

자유대화에는 아래 두 영역이 존재하면 안 된다.

```text
미션 Progress / 별 진행률       → 없음
마스코트 왼쪽 소리 상태 카드     → 없음
```

---

## 5. 상단 공통 헤더

기존 AppTopHeader 정책을 유지한다.

구성:

```text
← 뒤로              대화              로그아웃
```

요구사항:

- 왼쪽: 뒤로가기
- 가운데: 대화
- 오른쪽: 기존 로그아웃 아이콘
- iPhone Safe Area 정상 적용
- 직접 URL 접근 시에도 안전한 뒤로가기 fallback 유지
- 헤더 아래에 별도의 미션 진행률 Row를 만들지 않는다.

---

## 6. 미션 진행률 영역 제거

자유대화에서는 진행률 개념이 없으므로 다음 UI는 렌더링하지 않는다.

- pill progress
- 원형 progress
- 별 progress
- progressCurrent
- progressTotal 시각 표시
- 진행률 전용 빈 공간

중요:

진행률 컴포넌트를 단순 visibility:hidden 처리하여 빈 높이를 남기지 않는다.

자유대화에서는 해당 Row 자체가 레이아웃 공간을 차지하지 않도록 제거하거나 조건부 렌더링한다.

진행률이 사라져 확보되는 세로 공간은 대화 히스토리 영역에 사용한다.

---

## 7. 대화 히스토리 정책

자유대화는 케이의 최근 발화를 최대 3단계로 보여준다.

우선순위:

```text
1. 현재 케이 발화
2. 바로 이전 케이 발화
3. 지지난 케이 발화
```

아이의 발화를 별도 말풍선으로 추가하지 않는다.

기존 자유대화의 최근 케이 발화 추출 정책을 유지한다.

공간이 충분할 때는 3개 모두 표시한다.

공간이 부족할 때는:
1. 지지난 발화부터 숨김
2. 그래도 부족하면 지난 발화 영역 축소 또는 숨김
3. 현재 케이 발화는 항상 전체 표시

현재 케이 말풍선 내부 스크롤 금지.
텍스트 잘림 금지.

---

## 8. 지지난 케이 발화

시각적 우선순위가 가장 낮다.

목표:
- 중앙 정렬
- 회색 계열 텍스트
- 별도 강한 테두리 없음
- opacity 약 0.5~0.65
- 최대 폭 약 80~85%

권장 텍스트:
- 14~15px
- font-weight 500~600
- line-height 1.4~1.5

화면이 좁거나 현재 발화가 길면 가장 먼저 사라진다.

---

## 9. 지난 케이 발화

현재 발화보다 약하게 표시한다.

목표:
- 흰색 또는 반투명 흰색 배경
- 부드러운 그림자
- 둥근 모서리
- 중앙 정렬

권장:
- max-width: 78~82%
- font-size: 15~17px
- padding-x: 16~18px
- padding-y: 11~13px
- border-radius: 16~18px

현재 발화보다 폰트 크기와 시각적 대비가 낮아야 한다.

---

## 10. 현재 케이 발화 말풍선

자유대화 화면에서 가장 중요한 텍스트 요소다.

목표:
- 흰색 배경
- 오렌지 테두리
- 둥근 사각형
- 중앙 하단 꼬리
- 큰 굵은 글씨
- 화면 중앙 정렬

권장 폭:
- 화면의 84~88%
- max-width 약 350px

권장 텍스트:
- font-size: clamp(18px, 5vw, 21px)
- font-weight: 700
- line-height: 1.4~1.45

권장 내부 여백:
- horizontal: 20~22px
- vertical: 16~18px

테두리:
- 2~2.5px K Orange

위치 정책:
- 현재 말풍선의 꼬리 아래에 확대된 케이 마스코트가 자연스럽게 이어져야 한다.
- 말풍선 꼬리와 마스코트 머리 사이 목표 간격: 14~22px

현재 발화가 길어지면:
- 말풍선 하단이 내려가 하단 UI를 밀어내지 않는다.
- 위쪽으로 높이가 증가한다.
- 과거 히스토리 영역을 먼저 사용한다.

---

## 11. 배경 디자인

기본 배경:
- 상단: 부드러운 하늘색
- 하단: 따뜻한 크림색

두 영역은 거친 직선 경계보다 자연스럽게 연결되도록 한다.

장식:
- 연한 흰 구름 2~3개
- 작은 별
- 작은 종이조각
- 작은 원형 점

총 장식 요소는 과도하지 않게 유지한다.

권장 opacity:
- 0.15~0.35

장식이 말풍선 텍스트나 버튼 위에 겹치면 안 된다.

---

## 12. 케이 마스코트

미션 화면과 동일한 확대된 마스코트 디자인 시스템을 사용한다.

iPhone 390×844 기준 목표 실제 표시 크기:
- width: 약 145~155px
- height: 약 150~165px

현재 자유대화의 기존 마스코트가 이보다 작다면 약 1.3~1.4배 수준으로 확대한다.

권장 CSS 시작점:

```css
width: clamp(135px, 39vw, 160px);
height: auto;
object-fit: contain;
```

단, 실제 asset 내부의 투명 여백을 고려해 스크린샷에서 보이는 캐릭터 크기를 확인한다.

기능 보존:
- KBestieMascotAnimation 또는 자유대화에서 사용 중인 동일 기능의 state prop 유지
- 말하기 상태에서 입 모양 애니메이션 정상 동작

---

## 13. 케이 Halo / 동심원 효과

마스코트 뒤에 은은한 장식 효과를 추가한다.

구조 예:
- 큰 연한 원
- 중간 연한 원
- 작은 연한 원
- 케이

색상:
- 연한 오렌지
- 연한 노랑
- 따뜻한 크림

opacity:
- 0.08~0.18

마스코트보다 20~45% 큰 범위.

강한 glow나 네온 효과는 사용하지 않는다.

---

## 14. 받침대

케이 확대에 맞춰 플랫폼도 미션 화면과 같은 스타일로 확대한다.

iPhone 390×844 목표:
- width: 약 185~205px
- height: 약 38~46px

구성:
- 상단: 밝은 크림 타원
- 하단: 조금 진한 크림/베이지 원통
- 약한 border
- 약한 shadow

받침대 중앙과 케이 중심을 화면 정중앙에 맞춘다.

---

## 15. 왼쪽 소리 상태 컨트롤 제거

자유대화의 가장 중요한 차이점이다.

마스코트 왼쪽에 다음 UI를 표시하지 않는다.

```text
소리 켜짐
소리 꺼짐
스피커 아이콘 카드
```

중요:
- UI만 제거한다.
- 실제 mute/unmute 음성 로직 자체를 임의로 삭제하지 않는다.
- 왼쪽 카드가 사라진 공간에 빈 placeholder를 남기지 않는다.
- 마스코트는 좌측 카드가 없어도 화면 정중앙에 위치해야 한다.

---

## 16. 오른쪽 Voice State 컨트롤

마스코트 오른쪽에는 현재 상태 컨트롤 하나만 유지한다.

표시 가능한 실제 상태 예:
- 대기 중
- 듣고 있어
- 생각 중
- 말하는 중
- 연결 중

문구는 하드코딩하지 않고 기존 voiceState 또는 자유대화 런타임 상태값을 사용한다.

목표 크기:
- width: 약 64~72px
- height: 약 72~82px

원형 아이콘:
- 36~40px

텍스트:
- 14~16px
- font-weight: 600~700

중요:
오른쪽 상태 카드 때문에 케이 마스코트가 왼쪽으로 밀려나면 안 된다.

마스코트는 화면 중앙에 독립 배치하고 상태 카드는 오른쪽 overlay 또는 별도 grid layer로 배치한다.

---

## 17. 자동 / 수동 토글

미션 화면과 동일한 pill toggle 디자인을 사용한다.

구조:

```text
[ 자동 ][ 수동 ]
```

위치:
- 받침대 바로 아래
- 또는 받침대 전면에 붙어 있는 것처럼 시각적으로 연결

전체 목표:
- width: 약 130~145px
- height: 약 38~42px

선택 상태:
- 연한 오렌지 배경
- 오렌지 border
- 오렌지 텍스트

비선택:
- 흰색 배경
- 네이비/회색 텍스트

기존 isAuto / onChangeMode / disabled 등 실제 이벤트 로직은 그대로 유지한다.

---

## 18. 마이크 버튼

화면 하단 중앙의 주요 액션 버튼이다.

미션 화면과 동일한 디자인 시스템 사용.

목표 크기:
- 88~96px

시각 스타일:
- 오렌지 원형
- 흰색 마이크
- inner highlight
- 얇은 밝은 outer ring
- 부드러운 shadow

녹음 중 기존 pulse/ping 효과가 있다면 유지한다.

기능 변경 금지:
- onMicClick
- isRecording
- isMicDisabled
- 현재 녹음 시작/중단 정책

---

## 19. 키보드 버튼

화면 좌하단 유지.

목표 크기:
- 46~50px

스타일:
- 흰색 또는 반투명 흰색
- 둥근 사각형
- 네이비/회색 키보드 아이콘
- 약한 그림자

기존 텍스트 입력 모드 기능 유지.

---

## 20. 키보드 입력 모드와의 호환

기존 키보드 UX 개선 정책을 반드시 유지한다.

키보드 모드에서는:
- 입력창은 모바일 키보드 바로 위에 고정
- 입력창 위 대화 영역만 세로 스크롤
- 키보드 최초 진입 시 최근 케이 질문/발화가 보이게 함
- 가로 밀림/잘림 금지

이번 비주얼 리디자인이 키보드 입력 UX를 다시 깨뜨리면 안 된다.

---

## 21. 자유대화와 미션 디자인의 공통/차이

공통:
- AppTopHeader
- 3단 케이 발화 구조
- 현재 발화 오렌지 말풍선
- 큰 케이 마스코트
- Halo
- 큰 받침대
- 오른쪽 voice state
- 자동/수동 pill
- 키보드
- 큰 마이크
- 하늘/크림 배경
- 구름/별 장식

미션에만 있음:
- 별 기반 Progress
- 왼쪽 소리 상태 컨트롤

자유대화에는 없음:
- Progress 없음
- 왼쪽 소리 상태 컨트롤 없음

이 차이를 반드시 유지한다.

## 22. 목표 세로 배치 — iPhone 390×844 기준

정확한 현재값은 구현 전 실제 컴포넌트에서 측정하고 아래 범위를 목표로 맞춘다.

```text
약 y=105~150  상단 헤더 종료 후 자유 공간
약 y=145~190  지지난 발화
약 y=185~250  지난 발화
약 y=250~365  현재 케이 발화 말풍선
약 y=380~535  큰 케이 마스코트
약 y=505~565  큰 받침대
약 y=550~600  자동/수동 pill
약 y=640~735  마이크
```

위 값은 QA 가이드이며 절대 위치 하드코딩을 의미하지 않는다.

flex, grid, clamp()를 사용해 반응형으로 구현한다.
