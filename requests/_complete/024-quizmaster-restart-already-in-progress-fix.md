# 퀴즈마스터 새로 시작하기 오류 수정 요청

## 문서 정보
- 대상 프로젝트: `/mnt/e/VibeCoding/K-Bestie-v3`
- 요청 유형: 버그 수정 / 놀이 세션 재시작 / 황금열쇠 중복 차감 방지
- 적용 환경: Development 우선 검증 후 Production 반영
- 관련 놀이: 퀴즈마스터
- 회귀 확인 대상: MBTI

## 배경
현재 퀴즈마스터를 일부 진행한 뒤 놀이 화면으로 나와 `새로 시작하기`를 선택하면 다음 오류가 발생한다.

> 이미 놀이를 시작하고 있어요. 잠시 후 다시 확인해주세요.

동일한 이어하기 모달 정책을 사용하는 MBTI의 `새로 시작하기`는 정상 동작한다. 따라서 공통 모달 UI가 아니라 퀴즈마스터 전용 재시작·handoff 경로의 세션 상태 전이 또는 요청 순서 문제를 우선 의심한다.

## 재현 절차
1. 퀴즈마스터를 시작한다.
2. 일부 문제를 풀고 놀이 화면으로 나온다.
3. 퀴즈마스터 카드를 다시 누른다.
4. `취소 / 새로 시작하기 / 이어하기` 모달에서 `새로 시작하기`를 누른다.
5. 재확인 모달에서 다시 `새로 시작하기`를 누른다.
6. `이미 놀이를 시작하고 있어요` 오류가 표시된다.

## 기대 동작
`새로 시작하기`를 선택하면 다음 순서로 처리되어야 한다.

1. 기존 진행 세션을 물리 삭제하지 않고 종료 또는 만료 상태로 전환
2. 기존 진행상태를 신규 세션으로 복사하지 않음
3. 황금열쇠 2개를 정확히 1회 차감
4. 신규 퀴즈 세션을 정확히 1개 생성
5. 첫 문제부터 시작
6. 더블클릭·다중 탭에서도 중복 차감과 중복 세션 생성 없음

## 원인 분석 범위
다음 흐름을 실제 모바일 로그인 세션으로 재현하고 status/body/reason을 기록한다.

1. 기존 `play_type='quiz'`의 `in_progress` 세션 조회
2. 기존 세션 종료·만료 처리
3. 황금열쇠 예약 또는 차감
4. `/api/quiz/start-handoff` 호출
5. `quiz_handoff_tokens` 생성
6. 퀴즈마스터 실행 URL 생성
7. 독립 퀴즈마스터 앱 진입

우선 확인 항목:
- 기존 세션 종료가 DB에 반영되기 전에 `start-handoff`가 호출되는 경쟁 상태
- 모달 이벤트·재확인 이벤트·연속 탭으로 동일 요청이 이중 호출되는지
- MBTI 정상 경로와 퀴즈마스터 별도 시작 경로의 차이
- UI의 이어하기 판정과 서버의 `already_in_progress` 판정이 `resume_expires_at` 기준으로 일치하는지

## 수정 요구사항

### 기존 세션 처리
- 기존 세션 물리 삭제 금지
- 현재 스키마가 허용하는 종료 상태로 전환
- 기존 답변·점수·진행 이력 보존
- 종료 완료 후 신규 세션 생성 시작

### 신규 세션 처리
- 신규 세션은 정확히 1개만 생성
- 기존 `progress_state` 복사 금지
- 학년·과목 선택부터 다시 시작하는 현재 정책이 있다면 유지
- 첫 문제부터 정상 시작

### 황금열쇠 처리
- 퀴즈마스터 새로 시작하기 비용은 황금열쇠 2개
- 정확히 1회만 차감
- 이미 소비 확정된 기존 세션은 임의 환급 금지
- reserve만 되고 confirm되지 않은 건은 기존 restore 정책 적용
- 실패 시 세션 상태와 잔액이 불일치하지 않도록 트랜잭션·멱등성 유지

### `already_in_progress` 대응
범용 alert로 끝내지 말고 다음 순서로 처리한다.

1. 최신 세션 상태 재조회
2. 유효한 이어하기 세션이면 기존 세션으로 유도
3. 기존 세션 종료와 신규 예약 사이의 경쟁 상태라면 안전하게 1회만 재시도
4. 계속 실패하면 원인이 드러나는 안내 표시
5. 무한 재시도 금지

### 중복 실행 방지
- 최종 `새로 시작하기` 클릭 즉시 버튼 비활성화
- 처리 중 상태 표시
- 연속 탭 차단
- 다중 탭·다중 기기에서도 서버 멱등성으로 중복 차감·중복 세션 생성 방지

## 기존 기능 유지
- 이어하기: 기존 진행상태 복원, 추가 차감 0회, 신규 세션 생성 없음
- 신규 시작: 진행 중 세션이 없을 때 기존 흐름 유지
- MBTI: 신규 시작·이어하기·새로 시작하기 정상 유지, 비용 3개 유지
- completion/refund callback 계약 변경 금지

## 필수 테스트 시나리오

### A. 퀴즈마스터 이어하기
- 일부 진행 후 이탈
- 이어하기 선택
- 기존 위치 복원
- 추가 차감 없음

### B. 퀴즈마스터 새로 시작하기
- 이어하기 가능한 세션에서 새로 시작하기
- 기존 세션 종료
- 신규 세션 1개 생성
- 황금열쇠 2개 1회 차감
- 첫 문제부터 시작

### C. 더블클릭
- 최종 버튼을 빠르게 여러 번 클릭
- 중복 차감·중복 세션·중복 handoff token 없음

### D. 다중 탭
- 두 탭에서 동시에 새로 시작하기
- 서버 기준 한 요청만 성공
- 차감 1회, 세션 1개

### E. 만료 세션
- `status='in_progress'`이고 `resume_expires_at`이 지난 세션
- 기존 세션 종료 후 신규 시작
- `already_in_progress` 오류 없음

### F. 잔액 부족
- 황금열쇠 2개 미만
- 기존 잔액 부족 안내
- 기존 세션이 잘못 종료되지 않음
- 부분 차감·음수 잔액 없음

### G. MBTI 회귀
- MBTI 이어하기·새로 시작하기 정상
- 비용·세션·실행 정상
