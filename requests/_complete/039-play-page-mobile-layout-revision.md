# 039 — 케이와 놀이 모바일 화면 레이아웃 재교정

## 1. 작업 목적

현재 케이와 놀이 화면 구현 결과가 기존 디자인 의도와 다르게 모바일 화면에서 과도한 여백과 큰 카드 구조로 표시되고 있다.

현재 문제:

- 놀이 카드 높이가 지나치게 큼
- 카드 내부 빈 공간이 많음
- 모바일 화면에서 한 화면에 놀이 목록과 케이 안내가 모두 보이지 않음
- 준비 중 놀이가 실제 플레이 가능한 놀이처럼 큰 영역을 차지함
- 사용자가 놀이 선택까지 스크롤해야 하는 불편 발생
- 모바일 앱 UX가 아니라 웹 카드 리스트처럼 보임

목표는 세 번째 기준 이미지처럼 변경한다.

핵심 방향:

"모바일 한 화면 안에서 열쇠 확인 → 놀이 선택 → 케이 안내 → 미션 이동까지 자연스럽게 이어지는 구조"

---

# 2. 기준 화면 구조

최종 화면 순서:

```
Header
 ↓
열쇠 정보 영역
 ↓
열쇠로 열어요
 ↓
활성 놀이 카드
 ↓
곧 만나요(준비중)
 ↓
케이 안내 영역
```

전체 화면에서 주요 콘텐츠가 최대한 함께 보여야 한다.

---

# 3. 현재 구현과 기준 이미지 차이

## 현재 문제 화면

### 카드 영역

현재:

- 카드 높이 약 300px 이상
- 내부 상단 아이콘
- 중앙 큰 빈 공간
- 하단 제목
- 하단 설명

문제:

놀이 카드가 정보 전달 대비 너무 크다.

---

## 기준 화면

놀이 카드는 다음 목적만 가진다.

- 어떤 놀이인지 보여주기
- 필요한 열쇠 표시
- 잠금 상태 표시

따라서 카드 높이를 크게 만들 필요 없음.

---

# 4. 놀이 카드 크기 변경

## 활성 놀이 카드

대상:

- 퀴즈마스터
- 오늘의 나

변경:

현재:

```
세로형 대형 카드
```

변경:

```
작은 모바일 카드
```

권장:

- 높이: 110~140px
- 좌우 padding: 16px
- border-radius: 20px
- 아이콘 영역: 56px~64px

구조:

```
┌─────────────────┐
│ 아이콘      잠금 │
│                 │
│ 놀이명          │
│ 열쇠 2개 필요   │
└─────────────────┘
```

---

# 5. 활성 놀이 카드 내부 변경

## 퀴즈마스터

유지:

- 뇌 아이콘
- 퀴즈마스터 제목
- 열쇠 필요 개수

변경:

삭제:

- 불필요한 큰 빈 공간

표시:

```
🧠

퀴즈마스터

🔑 2개 필요
```

---

## 오늘의 나

유지:

- 수정구슬 아이콘
- 제목
- 설명
- 열쇠 필요 개수

표시:

```
🔮

오늘의 나

나의 성향 알아보기

🔑 3개 필요
```

---

# 6. 잠금 표시 개선

현재:

카드 오른쪽 상단 큰 영역 차지

변경:

작은 Badge 형태 유지

예:

```
🔒 열쇠가 더 필요해요
```

위치:

오른쪽 상단

크기:

- font-size 13~14px
- padding 작게
- pill 형태

---

# 7. "곧 만나요" 영역 변경

현재 문제:

준비중 카드가 너무 크다.

준비중 콘텐츠는 서비스 준비 상태만 전달하면 된다.

변경:

높이 축소.

구조:

```
곧 만나요

┌─────────────┐ ┌─────────────┐
│ 📖          │ │ 💇          │
│ 만화책 읽기 │ │ 케이 꾸미기 │
│ 준비 중     │ │ 준비 중     │
└─────────────┘ └─────────────┘
```

권장:

- 카드 높이 100px 이하
- Gray 처리
- 클릭 불가
- 황금열쇠 차감 없음

---

# 8. 케이 안내 영역 변경

현재:

화면 아래 밀려 있음.

문제:

사용자가 케이와 놀이 화면에서 가장 중요한 안내를 못 봄.

기준:

화면 하단 고정 영역처럼 배치.

구조:

```
케이 마스코트

미션 하면 열쇠를 줄게!

[미션하러 가기 →]
```

변경:

- 케이 이미지 높이 유지
- 오른쪽 말풍선 구조
- 버튼 노출 필수

---

# 9. 전체 화면 높이 기준

목표:

390x844 기준 한 화면 내 주요 콘텐츠 표시.

반드시 보여야 하는 영역:

- 헤더
- 열쇠
- 활성 놀이
- 준비중
- 케이 안내

스크롤이 발생하더라도 최소화한다.

---

# 10. 삭제 또는 축소 대상

삭제:

- 카드 내부 의미 없는 빈 공간
- 대형 카드 높이
- 과도한 padding
- 준비중 카드의 플레이 화면 같은 표현

축소:

- 카드 높이
- 아이콘 영역
- 제목 간격
- 섹션 간 margin
