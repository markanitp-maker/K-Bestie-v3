# 관리자 LLM 사용 현황 페이지 레거시 스위치·프로필 A/B 제거

## 1. 작업 목적

관리자 `LLM 사용 현황` 페이지에서 더 이상 사용하지 않는 다음 두 영역을 완전히 제거한다.

1. `AI 프로바이더 스위치(레거시)`
2. `GCAI A/B 프로필 설정`

관리자 화면에는 각 기능이 현재 실제로 사용하는 모델을 보여주는 읽기 전용 `LLM 사용 현황`만 남긴다.

이번 작업은 관리자 UI와 관리자 전용 레거시 변경 기능 제거 작업이다. 실제 서비스의 모델 선택 로직, 환경변수, 공통 resolver, Vertex AI, Live API, STT, TTS, Supabase Edge Function 호출 로직은 변경하지 않는다.

- 현재 환경 표시
- Development / Production / Preview 환경 구분
- 역할별 모델 매핑
- 기능 영역별 실제 적용 모델
- 처리 유형
- 플랫폼
- 설정 출처
- fallback
- 상태

- 배포 커밋

페이지에는 모델을 변경하거나 전환하는 기능이 남아 있으면 안 된다.

## 4. 핵심 원칙

1. 관리자 UI만 제거하고 실제 서비스 런타임 모델은 변경하지 않는다.
2. 실제 서비스가 참조하는 환경변수나 모델 설정값을 삭제하지 않는다.
3. 실제 AI 호출부가 사용하는 resolver를 수정하지 않는다.
4. 관리자 UI 전용 mutation 경로만 제거한다.
5. 삭제 전에 해당 API·Server Action·DB UPDATE가 실제 서비스 런타임에서 사용되는지 확인한다.
6. 실제 서비스에서 사용 중인 경로라면 삭제하지 않고 관리자 화면 연결만 제거한다.
7. 읽기 전용 현황 API는 유지한다.
8. Secret, API Key, Service Account, Token은 화면이나 로그에 노출하지 않는다.
9. Development와 Production 양쪽에서 동일하게 제거한다.
10. 제거 후에도 각 기능별 실제 적용 모델은 정확히 표시되어야 한다.

## 5. 구현 전 감사

코드 수정 전에 다음을 확인한다.

### AI 프로바이더 스위치

- 페이지 컴포넌트 위치
- 드롭다운 상태 관리
- 모델 변경 API
- 모델 변경 Server Action
- DB 설정 테이블
- 마지막 변경 사용자·시각 조회
- 실제 런타임이 해당 DB 값을 참조하는지 여부
- 실제 모델 resolver가 해당 값을 읽는지 여부

### GCAI A/B 프로필

- 프로필 A/B UI 컴포넌트
- 프로필 정의 위치
- 프로필 헬스체크 API
- 프로필 전환 API
- 프로필 저장 테이블
- 활성 프로필 판정 방식
- 실제 AI 런타임이 활성 프로필 값을 참조하는지 여부
- TEXT A/B, LIVE C, STT, TTS 테스트 함수
- Production에서 실제 운영에 사용되는 경로인지 여부

### 감사 결과 분류

각 경로를 다음 중 하나로 분류한다.

```text
관리자 UI 전용
관리자 테스트 전용
실제 런타임 사용 중
사용 여부 불명확
```

`관리자 UI 전용`과 `관리자 테스트 전용`만 제거한다.

`실제 런타임 사용 중`은 삭제하지 않는다.

`사용 여부 불명확`은 임의 삭제하지 않고 보고한다.
