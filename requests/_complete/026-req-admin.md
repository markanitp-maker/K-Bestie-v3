# Request: 관리자 LLM 사용 현황 페이지 운영 중심 정리

## 목적

관리자 페이지의 "LLM 사용 현황" 화면이 개발 환경 확인용 정보와 운영 모니터링 정보가 혼재되어 있어 불필요한 정보가 노출되고 있습니다.

운영자가 실제로 확인해야 하는 정보는 "현재 어떤 AI 기능이 어떤 모델로 동작하고 있는지"이므로, 확인 불가능하거나 의미 없는 항목을 제거하고 운영 중심 화면으로 정리합니다.

---

# 1. LLM 사용 현황 요약 영역 정리

## 제거 대상

아래 항목 제거:

- 마지막 빌드
- 배포 커밋


현재 표시:

```
마지막 빌드: Unknown
배포 커밋: Unknown
```

변경:

- 해당 항목 UI 제거
- 관련 데이터 조회 로직 제거 가능


제거 이유:

- Production 환경에서 실제 확인 가능한 정보가 아님
- 관리자 운영 화면에서 의미 없는 정보
- Unknown 상태 노출로 화면 신뢰도 저하


---

# 2. 미설정 / 설정 불일치 항목 제거

현재 표시:

```
미설정: 0개
설정 불일치: 0개
```

변경:

- UI 제거
- 계산 로직 제거
- 관리자 현황 데이터에서 제외


처리 이유:

현재 해당 값은 개발 환경 검증용 상태이며 운영자가 확인하거나 조치할 수 있는 정보가 아님.

운영 화면에서는 실제 오류 상태만 표시하도록 변경.


---

# 3. Vertex Live 릴레이 서비스 항목 제거

현재 표시:

```
Vertex Live 릴레이 서비스

음성(Live) - Cloud Run

확인 불가

services/vertex-live-relay

별도 Cloud Run 서비스로 배포되어 확인 불가
```

변경:

- 해당 항목 전체 제거


제거 이유:

- 관리자 화면에서 상태 확인 불가능
- 별도 Cloud Run 서비스 배포 상태는 현재 LLM 현황 목적과 맞지 않음
- 실제 사용자 기능별 모델 현황과 혼동 발생


주의:

실제 Gemini Live API 사용 기능 및 음성 미션 런타임 코드는 변경하지 않는다.


---

# 4. 유지할 LLM 현황 정보 기준

기능별 모델 적용 현황 테이블은 아래 정보만 유지한다.


## 유지 컬럼

| 항목 | 설명 |
|---|---|
| 기능명 | 실제 서비스 기능명 |
| 적용 모델 | 현재 사용하는 Gemini/STT/TTS 모델 |
| Provider | Vertex AI / Google API 등 |
| 환경 변수 | 실제 적용 기준 |
| 호출 위치 | 코드 위치 또는 서비스 위치 |
| 상태 | 정상 / 오류 |


예:

```
자유 대화
gemini-3.5-flash
Vertex AI
정상


음성 미션 Live
gemini-live-2.5-flash-native-audio
Vertex AI Live API
정상


STT
latest_long
Google Speech API
정상


TTS
ko-KR-Journey-F
Google TTS API
정상
```
