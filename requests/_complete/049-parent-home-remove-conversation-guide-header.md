# 049 — 부모 홈 ‘대화 가이드’ 제목·설명 제거 및 Dev·Production 반영

## 1. 작업 목적

부모 홈 화면 상단에 다음 두 문구가 표시되고 있다.

```text
대화 가이드
아이와 자연스럽게 대화를 시작해 보세요.
```

두 문구는 부모 홈의 실제 콘텐츠를 이해하는 데 필요하지 않고, 화면 상단의 세로 공간만 차지한다.

첨부 이미지에서 빨간 X로 표시한 다음 두 요소를 완전히 제거한다.

1. `대화 가이드`
2. `아이와 자연스럽게 대화를 시작해 보세요.`

이번 작업은 해당 제목·설명 제거와 그에 따른 상단 여백 정리에 한정한다.

---

## 2. 적용 화면

대상:

- 부모 홈 화면
- 자녀를 선택한 뒤 8개 상태 요약을 보는 화면
- 모바일 브라우저
- 모바일 설치형 PWA
- 태블릿
- PC 브라우저 및 설치형 PWA

실제 Route와 컴포넌트 경로는 구현 전에 확인한다.

부모 리포트 화면이나 부모와 케이 대화 화면을 수정 대상으로 오인하지 않는다.

---

## 3. 제거 대상

부모 홈 DOM에서 다음 요소를 렌더링하지 않는다.

### 제목

```text
대화 가이드
```

### 설명

```text
아이와 자연스럽게 대화를 시작해 보세요.
```

제거 대상에는 다음도 포함한다.

- 제목 Wrapper
- 설명 Wrapper
- 제목·설명 사이 간격
- 해당 영역의 상단·하단 Margin
- 해당 영역을 위한 고정 높이
- 빈 Placeholder
- Skeleton 또는 반응형 전용 복제 요소
- 모바일·태블릿·PC용 중복 제목

CSS로 `visibility: hidden`만 적용하거나 투명하게 처리하지 않는다.

화면에서만 숨기고 빈 공간을 남기는 방식도 금지한다.

---

## 4. 제거 후 최종 정보 구조

현재 구조:

```text
[상단 로고·자녀 선택·알림]

대화 가이드
아이와 자연스럽게 대화를 시작해 보세요.

[오늘의 한마디]

[8개 상태 요약 카드]
```

변경 구조:

```text
[상단 로고·자녀 선택·알림]

[오늘의 한마디]

[8개 상태 요약 카드]
```

상단 헤더 다음에 `오늘의 한마디` 카드가 바로 이어져야 한다.

---

## 5. 여백 재정렬

제목과 설명을 제거한 뒤 해당 높이만큼 빈 공간이 남지 않도록 한다.

### 권장 간격

상단 헤더 하단과 `오늘의 한마디` 카드 사이:

```text
약 10px~16px
```

`오늘의 한마디` 카드와 첫 번째 상태 카드 행 사이:

```text
약 14px~20px
```

정확한 값은 현재 공통 디자인 토큰을 우선 사용한다.

금지:

- 기존 제목 영역 높이만큼 빈 공간 유지
- `min-height`, 빈 `div`, `<br>`로 공간 유지
- 모바일에서만 별도의 큰 상단 Padding 적용
- 제목을 제거하면서 `오늘의 한마디` 카드까지 함께 제거
- 문의 버튼 위치를 콘텐츠에 맞추지 않고 제목이 있던 위치에 고정

---

## 6. 오늘의 한마디 카드

다음 기존 콘텐츠를 그대로 유지한다.

```text
오늘의 한마디
아직 대화 가이드가 준비되지 않았어요.
아이와 케이와 이야기를 나누면 이곳에서 알려드릴게요.
```

실제 데이터가 있으면 현재 API의 동적 문구를 그대로 표시한다.

변경하지 않는다.

- 카드 제목
- 카드 본문
- 카드 배경색
- 데이터 조회
- 데이터 부족 처리
- 자녀별 데이터
- 카드 높이 및 내부 Padding
- 생성 시점 및 분석 로직

단, 제목·설명 제거 후 카드가 자연스럽게 위로 이동해야 한다.

---

## 7. 8개 상태 요약 카드

다음 8개 카드는 그대로 유지한다.

1. 학교·학원 생활
2. 친구 관계
3. 마음 흐름
4. 관심사·취향
5. 공부 고민
6. 디지털·콘텐츠
7. 선생님·어른
8. 반복 이야기

유지 대상:

- 아이콘
- 카테고리명
- 12자 이내 요약
- 데이터 부족 상태
- 상태 표시
- 관찰 정보
- 2열 레이아웃
- 비인터랙티브 카드 정책
- 자녀 전환 시 데이터 갱신

이번 작업을 이유로 카드 내용이나 데이터 로직을 수정하지 않는다.

---

## 8. 문의 버튼

플로팅 `문의` 버튼 기능은 유지한다.

제목 영역 제거 후 버튼이 다음 요소를 가리지 않는지 확인한다.

- 자녀 선택
- 알림 아이콘
- `오늘의 한마디` 카드
- 첫 번째 상태 카드
- 화면 우측 스크롤 영역

기존 저장 좌표가 제거된 제목 영역을 기준으로 남아 있어 콘텐츠를 가리면 현재 Viewport와 Safe Area 안으로 Clamp한다.

문의 버튼 드래그·저장·모달 기능은 변경하지 않는다.

---

## 9. 접근성

제목·설명 제거 후 Heading 구조를 감사한다.

- 존재하지 않는 `aria-labelledby` 참조 제거
- 삭제된 제목 ID를 참조하는 속성 제거
- Screen Reader가 빈 Heading을 읽지 않도록 함
- `오늘의 한마디`가 적절한 Heading 또는 카드 제목 구조를 유지
- 키보드 Focus 순서에 빈 요소가 남지 않음
- 모바일 글꼴 확대에서도 상단 간격 정상

## 11. 구현 금지 사항

- 제목 문자열만 빈 문자열로 변경
- `display: none` 뒤 고정 높이 유지
- 모바일에서만 제거하고 태블릿·PC에는 유지
- Production과 Dev에 서로 다른 코드 적용
- 관련 없는 부모 홈 UI 재디자인
- 8개 카드 데이터나 상태값 수정
- 하단 내비게이션 제거
- 문의 버튼 제거
- DB Migration 추가
- Production에서 직접 별도 Hotfix 후 Dev와 코드가 달라지는 방식

---

## 12. Dev 적용 절차

1. 현재 Branch와 미커밋 변경 확인
2. 실제 부모 홈 컴포넌트 위치 확인
3. 제목·설명 및 전용 Wrapper 제거
4. 상단 여백 재정렬
5. 모바일 반응형 확인
6. lint 실행
7. typecheck 실행
8. 관련 test 실행
9. production build 실행
10. Dev Vercel 프로젝트 배포
11. Dev Deployment ID와 Build ID 기록
12. 모바일 Dev PWA에서 새 버전 적용
13. 실제 화면 QA

Dev에서 다음을 확인한 후 Production으로 진행한다.

- 두 문구 완전 제거
- 빈 공간 없음
- `오늘의 한마디` 위로 이동
- 8개 카드 정상
- 문의 버튼 겹침 없음
- 자녀 전환 정상
- 하단 내비게이션 정상

---

## 13. Production 적용 절차

Dev 검증이 모두 PASS하면 Dev에서 검증한 동일 Commit을 Production에 배포한다.

절차:

1. Dev 검증 Commit 고정
2. Production 대상 프로젝트·Branch 확인
3. Dev와 동일 Commit인지 검증
4. Production 배포
5. Production Deployment ID와 Build ID 기록
6. 운영 도메인 연결 확인
7. 기존 모바일 Production PWA에서 업데이트 안내 확인
8. 새 버전 적용
9. 부모 홈 Smoke Test
10. 두 문구 제거 및 여백 확인
11. 자녀 전환과 8개 카드 조회 확인

Dev와 Production에서 코드를 별도로 수정하지 않는다.

---

## 14. PWA 업데이트 검증

Dev와 Production 모두 기존 설치형 PWA에서 새 UI가 적용되어야 한다.

검증 순서:

1. 이전 Build가 설치된 PWA 실행
2. 새 Build 배포
3. PWA 삭제 금지
4. 사이트 데이터 수동 삭제 금지
5. 새 버전 안내 확인
6. `새로고침` 실행
7. Active Service Worker 및 Build ID 변경 확인
8. 제목·설명 제거 화면 확인

PWA를 삭제하거나 재설치해야만 반영되면 완료가 아니다.

## 16. 완료 기준

다음 조건을 모두 만족해야 완료로 판정한다.

- Dev 부모 홈에서 `대화 가이드`가 제거됨
- Dev 부모 홈에서 `아이와 자연스럽게 대화를 시작해 보세요.`가 제거됨
- Production 부모 홈에서도 두 문구가 제거됨
- 제목·설명 전용 Wrapper가 렌더링되지 않음
- 제거된 영역에 빈 공간이 남지 않음
- `오늘의 한마디` 카드가 상단으로 자연스럽게 이동함
- 8개 상태 요약 카드가 정상 표시됨
- 카드 데이터와 자녀 전환 기능에 회귀가 없음
- 문의 버튼이 콘텐츠를 가리지 않음
- 모바일·태블릿·PC 반응형 정상
- Dev와 Production이 동일 Commit으로 배포됨
- 설치형 PWA 삭제·재설치 없이 최신 UI 적용 성공
- lint 통과
- typecheck 통과
- 관련 test 통과
- production build 통과
- Dev Smoke Test 통과
- Production Smoke Test 통과
