# REQUEST 028 — 부모 홈 대시보드 카드 하단 메타 정보 제거

## 1. 목적
부모 홈 대시보드 8개 카드 하단의 불필요한 보조 정보 영역을 전부 제거한다.

제거 대상:
- `● 특징`
- `좋아요`
- `데이터 부족`
- `관찰 n일`
- `n일 전`
- `기록 없음`
- 상태 점(dot)
- 기타 카드 하단 메타 정보 행 전체

최종 카드에는 아래만 남긴다.

```text
[아이콘] 카드 제목
실제 분석 기반 15자 이내 1줄 요약
```

## 2. 적용 대상
- 학교·학원 생활
- 친구 관계
- 마음 흐름
- 관심사·취향
- 공부 고민
- 디지털·콘텐츠
- 선생님·어른
- 반복 이야기

## 3. 유지 대상
- 카드 아이콘
- 카드 제목
- 15자 이내 1줄 요약
- 카드 클릭 동작
- 2열 레이아웃
- 오늘의 한마디
- FAQ 버튼
- 하단 내비게이션
- Last Known Valid Insight 조회 정책
- 내부 observed_at 및 관련 데이터
- 상세 리포트 연결

이번 요청은 UI 단순화 작업이며 내부 데이터는 삭제하지 않는다.

## 4. 레이아웃
변경 전:

```text
🏫 학교·학원 생활
방학이라 학교는 안 가요

● 특징              관찰 6일 · 1일 전
```

변경 후:

```text
🏫 학교·학원 생활
방학이라 학교는 안 가요
```

하단 메타 컨테이너 자체를 제거하고 빈 여백이 남지 않게 한다.

## 5. 데이터 부족 카드
데이터 부족 판단 로직 자체는 변경하지 않는다.

단, 카드 하단에 다음과 같은 별도 메타 행은 표시하지 않는다.

```text
● 데이터 부족
기록 없음
```

필요한 경우 본문 위치의 기존 데이터 부족 정책만 유지한다.

## 6. 금지 사항
- 하단 메타 정보를 다른 디자인으로 재표현 금지
- 관찰일을 다른 위치로 이동 금지
- 상태 배지·칩 추가 금지
- 카드 클릭 동작 변경 금지
- Last Known Valid Insight 로직 변경 금지
- daily_reports 수정 금지
- 리포트 생성 로직 변경 금지
- 부모 홈 전체 디자인 개편 금지

## 7. 필수 테스트
- 8개 카드 모두 하단 메타 제거 확인
- 데이터 있는 카드 정상
- 데이터 없는 카드도 하단 메타 행 없음
- 카드 클릭 및 상세 연결 정상
- iPhone Safari/PWA 정상
- Android Chrome 정상
- 태블릿 가로·세로 정상
- 2열 레이아웃 및 카드 높이 정상
