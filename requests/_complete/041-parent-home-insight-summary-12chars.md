# 041 — 부모 홈 8개 상태 카드 본문을 12자 이내로 축약

## 1. 작업 목적

부모 홈 화면의 8개 상태 요약 카드에 현재 장문의 설명이 표시되고 있어 카드가 복잡하고 핵심 내용을 빠르게 파악하기 어렵다.

각 카드의 본문 요약을 공백 포함 최대 12자로 제한하여, 부모가 아이의 최근 상태를 한눈에 이해할 수 있도록 개선한다.

---

## 2. 적용 대상

다음 8개 카드의 본문 요약에 적용한다.

1. 학교·학원 생활
2. 친구 관계
3. 마음 흐름
4. 관심사·취향
5. 공부 고민
6. 디지털·콘텐츠
7. 선생님·어른
8. 반복 이야기

---

## 3. 최종 카드 정보 구조

각 카드는 다음 구조만 유지한다.

```text
[아이콘] 카테고리명

12자 이내 핵심 요약

[상태]             [관찰 정보]
```

예시:

```text
🏫 학교·학원 생활

학교생활이 힘들어요

● 특징              관찰 2일 · 2일 전
```

---

## 4. 글자 수 기준

- 공백 포함 최대 12자
- 문장부호도 글자 수에 포함
- 의미 없는 말줄임표 사용 금지
- 기존 장문을 CSS로 2~3줄 자르는 방식 금지
- 12자를 넘긴 문자열을 단순 `substring()`으로 자르는 방식 금지
- 핵심 의미가 완결된 짧은 문장으로 제공
- 아이의 직접 발화나 민감한 고유명사는 그대로 노출하지 않음

## 6. 요약 생성 우선순위

먼저 현재 부모 홈 API와 리포트 데이터에 다음과 같은 짧은 필드가 존재하는지 확인한다.

1. `short_summary`
2. `headline`
3. `summary_title`
4. `status_title`
5. 기존 카드용 한 줄 제목

짧은 정본 필드가 존재하면 해당 값을 우선 사용한다.

적절한 필드가 없다면 기존 리포트 생성 또는 부모 홈 집계 단계에서 `compact_summary`와 같은 12자 이내 요약을 생성한다.

화면을 열 때마다 카드별 LLM을 호출하지 않는다.

## 8. 데이터 부족 상태

분석 결과가 아직 없거나 충분하지 않은 경우 장문의 안내를 표시하지 않는다.

권장 문구:

```text
분석을 준비 중이에요
아직 이야기가 적어요
확인된 내용이 없어요
```

하단 상태는 기존처럼 다음을 유지할 수 있다.

```text
● 데이터 부족
기록 없음
```

본문과 하단 정보가 같은 내용을 장황하게 반복하지 않게 한다.
