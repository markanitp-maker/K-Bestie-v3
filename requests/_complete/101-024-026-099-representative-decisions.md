# 101 — 대표님 결정 반영: 024 유지 / 026 정리 / 099 즉시 착수

## 작업 정보

- 우선순위: 높음
- 선행 작업: 없음
- 병렬 처리: 024·099는 가능, 026 코드 정리는 현재 활성 UI 작업과 충돌 여부 확인 후 진행

## 대표님 결정 (확정)

### 024 — 자유대화 실시간 API

- 자유대화는 현재 상태를 유지한다.
- 실시간 API 연동은 진행하지 않는다.
- 관련 코드·환경변수·배포 작업은 하지 않는다.
- 이 결정과 현재 미착수 상태를 최종 보고에 명확히 남긴다.

### 026 — 디자인 통일 마무리

- 폰트는 현재 정책을 유지한다.
  - 기본 UI 텍스트: Pretendard
  - 대표 문구 등 제한된 포인트 텍스트: Gaegu
- 중복 또는 더 이상 참조되지 않는 파비콘 파일은 참조 관계를 확인한 뒤 제거한다.
- 구색상 코드·토큰은 실제 참조가 없는 것부터 제거한다.
- 아직 참조 중인 구색상은 억지로 삭제하지 말고, 참조 위치·영향·후속 전환 조건을 보고한다.
- 색상·파비콘 정리 과정에서 화면 디자인·기능·PWA 설치·배포 환경을 바꾸지 않는다.

### 099 — 최종 점검표

- 지금 즉시 정리 작업을 시작한다.
- 아직 진행 중인 028 등 미완료 항목은 완료로 쓰지 말고, ‘진행 중’ 또는 ‘대표님 확인 대기’로 구분한다.
- 기존 099 범위에 따라 대표님이 실제 기기에서 확인할 수 있는 체크리스트를 작성한다.
