# 036 — 미션 대화 말풍선·마스코트·상태 카드 크기 및 배치 개선

## 1. 작업 목적

현재 미션 대화 화면을 첫 번째 첨부 이미지에서 두 번째 첨부 이미지의 구성으로 개선한다.

이번 작업은 미션 대화 로직이나 음성 상태 처리 방식을 변경하는 작업이 아니다.

다음 시각 요소의 크기와 배치만 개선한다.

1. 직전 대화 및 현재 질문 말풍선의 글자 크기 확대
2. 케이 마스코트 크기 확대
3. 케이 좌우의 소리 상태 카드와 대화 상태 카드를 케이 가까이 이동
4. 좌우 카드의 아이콘과 상태 문구 확대
5. 마스코트와 좌우 카드가 하나의 고정된 상호작용 영역처럼 보이도록 정렬

---

# 2. 현재 화면 문제

첫 번째 현재 화면에서는 다음 문제가 있다.

## 2.1 말풍선 글씨가 작음

다음 텍스트가 화면 크기에 비해 작게 표시된다.

- 직전 아이 발화
- 직전 케이 응답
- 현재 케이 질문

특히 현재 질문은 미션 화면에서 가장 중요한 내용인데도 글자가 작아 아이가 읽기 어렵다.

## 2.2 케이 마스코트가 작음

현재 케이 마스코트가 화면에서 차지하는 비중이 작다.

그 결과:

- 케이의 존재감이 약함
- 좌우 상태 카드와 하나의 그룹처럼 보이지 않음
- 화면 중앙이 비어 보임
- 아이가 현재 누구와 대화하는지 시각적으로 약하게 느껴짐

## 2.3 좌우 카드가 케이와 너무 멀리 떨어져 있음

현재 왼쪽 `소리 켜짐` 카드와 오른쪽 `대기 중` 카드가 화면 양끝에 가깝게 배치되어 있다.

이 때문에 다음 문제가 있다.

- 케이와 상태 카드의 관계가 분리되어 보임
- 화면 중심이 비어 보임
- 작은 카드와 작은 아이콘이 더 작게 느껴짐
- 좌우 카드가 독립된 버튼처럼 보임
- 모바일 화면 폭에 따라 거리 차이가 크게 발생함

## 2.4 카드 아이콘과 문구가 작음

현재 좌우 카드의 다음 요소가 작다.

- 스피커 아이콘
- 듣기 또는 대기 상태 아이콘
- `소리 켜짐` 문구
- `대기 중` 등의 상태 문구

아이 사용 화면이므로 더 크고 명확하게 보여야 한다.

---

# 3. 목표 화면

두 번째 첨부 이미지처럼 다음 구조로 변경한다.

```text
[직전 아이 발화]

[직전 케이 응답]

[현재 케이 질문 — 확대된 글씨]

[소리 카드] [확대된 케이 마스코트] [대화 상태 카드]

             [마스코트 단상]

              [자동] [수동]

[키보드]        [마이크]
```

핵심은 다음이다.

- 마스코트가 중앙에서 더 크게 보임
- 좌우 카드는 케이 바로 옆에 붙음
- 세 요소가 하나의 고정된 그룹으로 보임
- 말풍선의 글자가 더 크고 읽기 쉬움
- 좌우 카드의 아이콘과 문구도 더 크게 표시됨

---

# 4. 현재 화면과 목표 화면 차이

## 4.1 직전 아이 발화

현재:

- 글자 크기가 작음
- 화면에서 존재감이 약함

변경:

- 글자 크기를 현재보다 약 10~20% 확대
- 최소 `14px~16px`
- line-height `1.4~1.5`
- Neutral 계열 색상 유지
- 최대 2줄 유지
- 가운데 정렬 유지

권장:

```css
font-size: clamp(14px, 3.8vw, 16px);
line-height: 1.45;
```

---

## 4.2 직전 케이 응답 말풍선

현재:

- 내부 글씨가 작음
- 한 줄에 너무 많은 글자가 들어감
- 아이가 읽기에 밀도가 높음

변경:

- 글자 크기 확대
- 말풍선 좌우 너비는 현재와 유사하게 유지
- 글자 크기가 커지는 만큼 줄바꿈을 자연스럽게 허용
- 최대 3~4줄
- 글자 크기를 맞추기 위해 말풍선을 지나치게 넓히지 않음

권장:

```css
font-size: clamp(15px, 4vw, 17px);
line-height: 1.5;
padding: 14px 18px;
```

텍스트를 작게 축소하여 한 줄 수를 줄이는 방식은 금지한다.

---

## 4.3 현재 케이 질문 말풍선

현재 질문은 화면의 가장 중요한 정보다.

현재:

- 본문 글씨가 상대적으로 작음
- 질문의 중요도에 비해 시각적 강조가 부족함

변경:

- 현재보다 글자 크기를 약 15~25% 확대
- 최소 `17px`
- 일반 모바일에서 `18px~20px`
- 굵기 `650~750`
- line-height `1.4~1.5`
- K-Navy 또는 기존 진한 본문색 사용
- 왼쪽 정렬 유지
- 말풍선 내부 여백 확대

권장:

```css
font-size: clamp(17px, 4.7vw, 20px);
font-weight: 700;
line-height: 1.45;
padding: 17px 20px;
```

## 긴 질문 처리

질문이 길어질 경우:

- 글자 크기를 줄이지 않음
- 최대 높이를 설정
- 필요하면 말풍선 내부 세로 스크롤
- 말풍선 바깥 전체 레이아웃이 크게 밀리지 않도록 함

---

# 5. 케이 마스코트 확대

## 현재 문제

현재 마스코트가 좌우 카드보다 조금 큰 수준으로 보여 케이의 존재감이 약하다.

## 변경 목표

두 번째 첨부 이미지처럼 마스코트가 좌우 상태 카드보다 명확하게 크고, 화면 중심을 차지하도록 한다.

## 권장 크기

현재 마스코트 렌더링 크기보다 약 25~40% 확대한다.

권장:

```css
width: clamp(100px, 29vw, 130px);
height: auto;
```

390px 폭 기준 목표:

```text
약 108px~120px
```

현재 사용 중인 공식 3D 케이 마스코트 자산을 그대로 사용한다.

금지:

- 이미지 비율 왜곡
- 임의 Crop
- 레퍼런스 이미지에서 잘라 사용
- 저해상도 자산 확대
- 마스코트 색상 변경

---

# 6. 마스코트 단상

마스코트가 커지는 만큼 단상도 자연스럽게 맞춘다.

## 변경

- 마스코트 발이 단상 위에 자연스럽게 위치
- 단상 너비를 마스코트보다 약 1.35~1.55배 크게 구성
- 단상 높이는 과도하게 키우지 않음
- 마스코트와 단상 사이 빈 공간 제거
- 자동·수동 버튼과 단상 사이 간격 최소화

권장:

```css
width: clamp(135px, 38vw, 175px);
```

---

# 7. 마스코트와 좌우 카드 통합 배치

## 현재 구조 문제

현재 좌우 카드가 화면 양끝에 고정되어 있어 케이와 떨어져 보인다.

## 목표 구조

다음 세 요소를 하나의 중앙 그룹으로 구성한다.

```text
[소리 카드] [케이 마스코트] [상태 카드]
```

이 그룹은 화면 중앙에 고정한다.

## 권장 구현

CSS Grid 사용을 권장한다.

```css
.mascot-control-group {
  display: grid;
  grid-template-columns: auto auto auto;
  align-items: center;
  justify-content: center;
  column-gap: clamp(8px, 2.5vw, 14px);
}
```

또는 실제 컴포넌트 구조에 맞는 Flex를 사용할 수 있다.

## 금지

- 좌우 카드에 `left: 16px`, `right: 16px`를 각각 적용해 화면 양끝에 고정
- 마스코트와 상태 카드를 별도 Row로 배치
- 화면 폭이 넓어질수록 카드와 마스코트 거리가 계속 벌어지는 구조
- 마스코트 기준이 아니라 viewport 기준으로 각 카드 위치를 따로 지정

---

# 8. 좌우 카드와 마스코트 간격

두 번째 첨부 이미지처럼 카드가 케이 바로 옆에 위치해야 한다.

## 권장 간격

카드와 마스코트 이미지의 실제 외곽 사이:

```text
약 6px~14px
```

화면 폭에 따라 다음 범위에서 조정한다.

```css
gap: clamp(6px, 2vw, 12px);
```

390px 모바일에서 두 카드가 화면 가장자리에 붙지 않고 케이 가까이에 보여야 한다.

---

# 9. 좌우 상태 카드 크기 확대

## 현재

카드 크기가 작아 아이콘과 텍스트가 답답하게 보인다.

## 목표

두 번째 첨부 이미지처럼 카드 크기를 확대한다.

권장 크기:

```css
width: clamp(72px, 20vw, 88px);
min-height: clamp(82px, 22vw, 100px);
```

390px 폭 기준:

```text
너비 약 78px~86px
높이 약 88px~98px
```

## 공통 카드 스타일

- 연한 K-Sky Blue 또는 현재 상태 카드 배경 유지
- radius `16px~20px`
- 약한 그림자
- 아이콘과 문구 가운데 정렬
- 상하 padding 약 `10px~14px`
- 두 카드의 크기를 동일하게 유지
- 카드 내부 콘텐츠가 위·아래로 치우치지 않게 함

---

# 10. 왼쪽 소리 카드

## 표시

현재 상태에 따라 다음 문구를 사용한다.

```text
소리 켜짐
```

```text
소리 꺼짐
```

## 아이콘

- 현재의 작은 원형 이미지 대신 명확한 스피커 아이콘 사용
- 소리 켜짐: 스피커와 음파
- 소리 꺼짐: 스피커 차단 아이콘
- 프로젝트의 기존 아이콘 라이브러리 또는 공식 아이콘 사용

## 아이콘 크기

```css
width: clamp(34px, 9vw, 44px);
height: clamp(34px, 9vw, 44px);
```

## 문구 크기

```css
font-size: clamp(15px, 4vw, 18px);
font-weight: 700;
```

390px 화면에서는 약 `16px~17px`를 목표로 한다.

## 동작

기존과 동일하게 케이의 출력 음성만 켜고 끈다.

아이의 마이크 입력 상태를 변경하지 않는다.

---

# 11. 오른쪽 대화 상태 카드

## 상태 문구

아이 입력을 기다리는 상태에서는 두 번째 첨부 이미지처럼 다음 문구를 사용한다.

```text
듣고 있어
```

기존 상태별 문구는 실제 상태에 따라 변경한다.

| 실제 상태 | 문구 |
|---|---|
| 아이 답변 대기 | 듣고 있어 |
| 아이 음성 수신 | 듣고 있어 |
| 케이 답변 처리 | 생각 중 |
| 케이 음성 출력 | 말하는 중 |
| 최초 연결 | 연결 중 |
| 재연결 | 다시 연결 중 |
| 오류 | 연결 오류 |
| 입력 불가능 대기 | 대기 중 |

`듣고 있어`를 모든 상태에 고정하지 않는다.

레이아웃 위치와 카드 크기만 고정하고, 상태 문구와 아이콘은 실제 상태에 따라 변경한다.

## 상태 아이콘

### 듣고 있어

- 귀 아이콘
- 또는 음성 파형 아이콘

### 생각 중

- 점 3개
- 또는 생각 상태 아이콘

### 말하는 중

- 말풍선
- 또는 스피커 파형

### 대기 중

- 원형 대기 표시

### 연결 오류

- 경고 또는 연결 끊김 아이콘

## 아이콘 크기

```css
width: clamp(34px, 9vw, 44px);
height: clamp(34px, 9vw, 44px);
```

## 문구 크기

```css
font-size: clamp(15px, 4vw, 18px);
font-weight: 700;
```

상태 문구가 두 줄로 갈라지지 않도록 카드 너비를 확보한다.

---

# 12. 좌우 카드의 수직 정렬

두 카드의 세로 중심을 동일하게 맞춘다.

마스코트와의 정렬 기준:

- 카드 중심은 마스코트 몸통 중앙보다 약간 아래
- 케이 얼굴보다 카드가 위로 올라가지 않음
- 카드 하단이 마스코트 발보다 지나치게 아래로 내려가지 않음

권장 구조:

```css
align-items: center;
```

필요하면 카드에 소폭의 `translateY()`를 공통 적용할 수 있으나 좌우 카드에 서로 다른 값을 사용하지 않는다.

---

# 13. 마스코트 그룹의 고정 기준

`마스코트 + 좌우 카드 + 단상`은 하나의 묶음으로 구성한다.

```text
MascotInteractionArea
├─ ControlRow
│  ├─ SoundCard
│  ├─ Mascot
│  └─ ConversationStateCard
└─ MascotStage
```

마스코트가 커지거나 상태 문구가 변경되어도 다음 요소가 움직이지 않도록 한다.

- 카드 중심
- 단상 중심
- 자동·수동 버튼 중심
- 하단 마이크 중심

상태 카드 문구가 `대기 중`에서 `다시 연결 중`으로 바뀌어도 전체 레이아웃이 좌우로 흔들리지 않도록 한다.

---

# 14. 자동·수동 버튼

현재 기능과 기본 디자인은 유지한다.

마스코트와 단상이 커지면서 버튼이 아래로 밀리지 않도록 다음 간격을 사용한다.

```text
단상 하단
↓ 4px~10px
자동·수동 버튼
```

버튼의 실제 모드와 화면 선택 상태는 기존 정책대로 일치해야 한다.

키보드 버튼 클릭 시 수동 모드로 자동 전환하는 기존 정책을 유지한다.

---

# 15. 세로 배치 조정

마스코트 크기와 글자 크기를 키우되 하단 마이크가 잘리지 않도록 전체 세로 간격을 재조정한다.

## 축소 가능한 영역

공간이 부족한 경우 다음 순서로 간격을 축소한다.

1. 진행률과 문의 버튼 사이
2. 문의 버튼과 직전 발화 사이
3. 이전 케이 응답과 현재 질문 사이
4. 현재 질문과 마스코트 사이
5. 자동·수동 버튼과 마이크 사이

## 크기를 먼저 줄이면 안 되는 요소

- 현재 질문 글자 크기

# 16. 권장 세로 간격

|---|---:|

# 17. 반응형

## 390×844

두 번째 첨부 이미지의 크기와 배치를 목표로 한다.

- 현재 질문 글자 약 18px~20px
- 마스코트 약 108px~120px
- 좌우 카드 약 80px 전후
- 카드와 마스코트 간격 약 8px~12px

## 360×800

- 마스코트 약 98px~110px
- 좌우 카드 약 72px~80px
- 글자 크기는 가능한 한 유지
- 영역 사이 여백을 소폭 축소

## 320×568

- 현재 질문 글자 최소 17px 유지
- 마스코트 최소 약 88px~96px
- 상태 카드 최소 약 66px~72px
- 아이콘 최소 약 30px~34px
- 필요하면 최소 세로 스크롤 허용
- 좌우 카드와 마스코트를 세로로 분리하지 않음

## 태블릿·PC

- 콘텐츠 전체 최대 너비 유지
- 마스코트와 카드가 무한히 멀어지지 않도록 `max-width` 적용
- 모바일형 중앙 그룹을 유지
- 카드 위치를 viewport 좌우 끝으로 보내지 않음

# 20. 구현 원칙

- 현재 미션 화면의 실제 컴포넌트 구조를 먼저 확인한다.
- 기존 최근 변경사항을 보존한다.
- 관련 없는 파일을 수정하거나 포맷팅하지 않는다.
- 레퍼런스 이미지를 잘라 UI 자산으로 사용하지 않는다.
- 마스코트는 공식 정본 자산을 사용한다.
- 각 요소를 절대 좌표로 개별 배치하지 않는다.
- `left: 16px`, `right: 16px` 방식으로 좌우 카드를 화면 끝에 고정하지 않는다.
- 마스코트와 좌우 카드를 동일한 Grid 또는 Flex 컨테이너에 배치한다.
- 특정 390×844 화면에서만 맞는 고정 좌표 구현을 금지한다.
- 기존 상태 로직을 재작성하지 않는다.

# 23. 완료 기준

다음 조건을 모두 만족해야 완료로 판정한다.

- 직전 아이 발화 글자가 현재보다 커짐
- 직전 케이 응답 글자가 현재보다 커짐
- 현재 질문 글자가 약 17px~20px 범위로 확대됨
- 질문 가독성이 두 번째 첨부 이미지 수준으로 개선됨
- 케이 마스코트가 현재보다 약 25~40% 확대됨
- 좌우 상태 카드가 화면 끝이 아닌 케이 바로 옆으로 이동됨
- 좌우 카드와 마스코트 간격이 약 6px~14px 범위로 유지됨
- 좌우 카드 크기가 확대됨
- 아이콘 크기가 약 34px~44px 범위로 확대됨
- 상태 문구가 약 15px~18px 범위로 확대됨
- 왼쪽과 오른쪽 카드 크기와 높이가 동일함
- 상태가 변경되어도 카드 위치가 흔들리지 않음
- 마스코트·카드·단상이 하나의 그룹처럼 보임
- 자동·수동 버튼과 마이크가 화면 안에 정상 표시됨
- 기존 음성·미션·완료·보상 기능에 회귀가 없음
- 모바일·태블릿 QA 통과
- 접근성 검증 통과
- lint 통과
