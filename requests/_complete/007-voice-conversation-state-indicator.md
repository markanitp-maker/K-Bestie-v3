# 음성 대화 상태 표시 UI 추가

## 범위

작업 전 `docs/conventions.md`를 먼저 읽고 따른다.

수정 허용:
- 음성 대화 화면 관련 컴포넌트
- Gemini Live / 음성 세션 상태 관리 훅
- 연결 상태 표시 관련 UI 파일
- 관련 타입 파일

수정 금지:
- 음성 대화 핵심 처리 로직 변경
- Live API 연결 방식 변경
- STT/TTS 파이프라인 구조 변경
- 미션 질문 로직
- MBTI/놀이/황금열쇠 기능

## 요구사항

아이와 케이가 음성 대화를 진행할 때 현재 처리 상태를 아이가 이해할 수 있도록 K 옆에 표시한다.

현재 사용자는 말을 한 뒤 약 5초 이상 기다리는 동안 자신의 음성이 정상 입력됐는지 알기 어렵다.

다음 상태를 시각적으로 표시한다.

- 듣는 중
  - 아이 음성 입력 수집 중
  - 마이크 활성 상태

- 생각하는 중
  - STT 완료 후 LLM 응답 생성 대기 상태

- 말하는 중
  - TTS 음성 출력 중

- 연결 중
  - 초기 세션 연결 또는 재연결 상태

상태 표시 방식은 기존 K UI 디자인과 일관성을 유지한다.

예:
- K 옆 작은 상태 배지
- 아이콘 + 짧은 문구
- 애니메이션 표시 가능

단, 화면을 방해하지 않는 수준으로 구현한다.

## 완료조건

- 아이가 말할 때 "듣는 중" 상태 확인 가능
- 음성 입력 종료 후 "생각하는 중" 상태 확인 가능
- 케이 음성 출력 중 "말하는 중" 상태 확인 가능
- 상태 전환이 실제 음성 파이프라인 이벤트와 연결됨
- 존재하지 않는 상태를 표시하지 않음
- 기존 음성 대화 동작 회귀 없음
- `npx tsc --noEmit` 통과
- `npx next build` 성공
- Dev 배포 완료
