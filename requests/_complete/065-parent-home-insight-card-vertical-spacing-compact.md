# 065 — 부모 홈 인사이트 카드 세로 여백 축소 및 8개 항목 한 화면 노출

## 1. 작업 목적

현재 부모 홈 대시보드의 8개 인사이트 카드가 모바일 화면에서 지나치게 높은 세로 공간을 차지하고 있다.

문제의 핵심은 글씨 크기나 아이콘 크기가 아니라 다음과 같은 불필요한 카드 내부/외부 세로 여백이다.

- 과도한 `min-height`
- 큰 상하 padding
- 제목과 설명 사이의 불필요한 gap
- 카드 행 간 과도한 vertical gap
- `justify-between`, `flex-grow`, `minmax()` 등으로 인해 콘텐츠보다 카드가 더 크게 늘어나는 구조

이번 작업에서는 현재 글씨 크기와 아이콘 크기를 그대로 유지하면서, 카드 높이와 여백만 줄여 모바일 한 화면에 2열×4행, 총 8개 인사이트 카드가 하단 네비게이션 위까지 모두 보이도록 개선한다.

## 2. 가장 중요한 원칙

이번 작업에서 절대 바꾸지 않을 것:

- 카드 제목 font-size
- 카드 설명 font-size
- 아이콘 크기
- 카드의 2열 구조
- 카드별 데이터
- 카드별 클릭 기능
- 오늘의 한마디 영역
- 상단 헤더
- 아이 시작하기 CTA
- FAQ 플로팅 버튼 기능
- 하단 네비게이션 기능
- DB / API / LLM / 리포트 로직

이번 작업은 오직 카드의 불필요한 세로 여백을 줄여 정보 밀도를 정상화하는 UI 작업이다.

## 3. 목표 구조

모바일 기준으로 아래 8개 카드가 모두 한 화면에 들어와야 한다.

```text
학교·학원 생활     친구 관계
마음 흐름          관심사·취향
공부 고민          디지털·콘텐츠
선생님·어른        반복 이야기
```

각 카드는 다음처럼 컴팩트하게 구성한다.

```text
[아이콘] 제목
설명 한 줄
```

카드 내부 위/아래 빈 공간은 최소화하고 콘텐츠 높이에 맞춰 카드가 결정되게 한다.

## 4. 카드 높이 목표

iPhone 390×844 기준 권장 목표:

- 카드 높이: 약 75~85px
- 2열×4행 모두 하단 네비게이션 위에 완전히 노출
- 카드 제목과 설명은 현재 font-size 그대로 유지
- 아이콘도 현재 크기 유지

고정 `height`로 텍스트를 자르지 않는다.

우선순위:
1. 불필요한 `min-height` 제거/축소
2. 상하 padding 축소
3. 제목-설명 사이 gap 축소
4. 행 간 gap 축소
5. 카드 높이가 콘텐츠 기반으로 자연스럽게 결정되도록 조정

## 5. 구현 전 필수 확인

코드 수정 전에 실제 부모 홈 카드 컴포넌트를 찾아 아래 값을 확인한다.

1. 카드 `height`
2. 카드 `min-height`
3. `padding-top`
4. `padding-bottom`
5. `padding-left/right`
6. grid `row-gap`
7. grid `column-gap`
8. 아이콘 크기
9. 제목 `font-size`
10. 제목 `line-height`
11. 설명 `font-size`
12. 설명 `line-height`
13. 제목과 설명 사이 gap
14. 내부 `display:flex/grid`
15. `align-items`
16. `justify-content`
17. `flex-grow`
18. 부모 Grid의 `auto-rows`, `minmax()`, `grid-auto-rows`

특히 다음이 있으면 우선 원인으로 본다.

```text
min-h-[100px] 이상
py-5 / py-6
justify-between
flex-grow
grid-auto-rows: 1fr
minmax(..., 1fr)
```

## 6. 권장 변경 방향

### 6.1 min-height
현재 카드가 큰 `min-height`를 가지고 있다면 축소한다.

권장 목표:
```css
min-height: 75px ~ 85px;
```

콘텐츠 기반으로 자연스럽게 줄어들 수 있다면 `min-height` 제거를 우선 검토한다.

### 6.2 상하 Padding
권장 시작값:
```text
padding-top: 10~12px
padding-bottom: 10~12px
```

좌우 padding은 현재 가독성이 적절하면 유지한다.

### 6.3 제목/설명 간격
```text
gap: 4~6px
```

### 6.4 카드 행 간격
```text
row-gap: 10~12px
```

### 6.5 내부 정렬
피해야 할 형태:
```css
justify-content: space-between;
```

권장:
```css
justify-content: flex-start;
```

또는 자연스러운 block flow.

## 7. 카드 안 텍스트 정책

글씨 크기는 이번 작업에서 변경하지 않는다.

유지:
- 제목 font-size
- 제목 font-weight
- 설명 font-size
- 설명 line-height
- 아이콘 크기

설명이 실제로 2줄이 되는 카드가 있다면 카드 높이는 자연스럽게 늘어나도 된다.

ellipsis로 억지로 줄이지 않는다.

## 8. FAQ 플로팅 버튼

FAQ 버튼은 현재 기능과 위치 저장 정책을 유지한다.

8개 카드가 한 화면에 들어온 뒤에도 마지막 카드 내용을 가리지 않아야 한다.

기능 변경 금지.

## 9. 하단 네비게이션

하단 네비게이션은 현재 확대된 부모용 공통 크기를 유지한다.

nav를 다시 줄이지 않는다.

핵심은 nav 공간을 줄이는 것이 아니라 카드 영역의 낭비 공간을 줄여 8개 항목을 nav 위에 맞추는 것이다.

## 10. 모바일 목표

### iPhone 390×844
- 오늘의 한마디 전체 표시
- 8개 인사이트 카드 전체 표시
- 마지막 4번째 행 카드가 하단 nav에 가려지지 않음

### Android 360×800
- 카드 폭 깨짐 없음
- 제목/설명 잘림 없음
- 가능한 한 8개 전체 노출
- 작은 높이에서는 최소한 마지막 행이 nav에 의해 가려지지 않음

### Android 412×915
- 8개 전체 안정적으로 표시
- 불필요하게 카드 높이가 다시 커지지 않음

## 11. PC / 태블릿

이번 변경은 모바일 카드 밀도 개선이 핵심이다.

PC/태블릿에서는:
- 카드가 지나치게 납작해 보이지 않도록 반응형 padding 유지
- 모바일용 75~85px 기준을 그대로 강제하지 않아도 됨
- 기존 데스크톱 레이아웃을 깨지 않는다
