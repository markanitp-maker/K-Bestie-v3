# Request — 부모 홈 화면에도 앱 설치하기 배너 노출

## 1. 목적

현재 부모 홈 화면에서는 브라우저 알림 미지원 경고만 보이고,
아이 홈 또는 다른 화면에서 보이는 `앱 설치하기` 하단 배너가 노출되지 않는다.

부모 홈 화면에서도 동일하게 앱 설치 배너가 노출되도록 수정한다.

---

## 2. 문제 상황

현재 부모 홈 화면:
- 상단에 `현재 브라우저에서 알림을 지원하지 않아요. 앱의 다른 기능은 계속 이용할 수 있어요.` 경고가 표시됨
- 하지만 하단 `앱 설치하기` 배너는 없음

원하는 상태:
- 부모 홈 화면에서도 하단에 앱 설치 배너가 표시되어야 함

예상 배너 형태:
- 좌측: `모바일 / 태블릿 / PC`
- 중앙/우측: `앱 설치하기` 버튼
- 우측 끝: 닫기 `X`

---

## 3. 요구사항

### 3.1 부모 홈에도 설치 배너 노출
부모 홈 화면에 현재 아이/기타 화면에서 사용하는 것과 동일한 `앱 설치하기` 하단 배너를 노출한다.

### 3.2 배너 구성
배너는 기존 앱 설치 배너 UI를 그대로 재사용한다.

구성 요소:
- `모바일 / 태블릿 / PC`
- `앱 설치하기` CTA 버튼
- 닫기 버튼 `X`

### 3.3 동작 일관성 유지
부모 홈 배너도 기존 배너와 동일하게 동작해야 한다.

예:
- 설치 가능 환경이면 설치 흐름 연결
- 설치 불가 환경이면 기존 fallback 안내 유지
- `X` 클릭 시 닫힘
- 이미 설치된 PWA standalone 환경이면 불필요하게 노출하지 않음
- 사용자가 이미 닫은 상태라면 기존 persistence 정책을 동일하게 적용

### 3.4 경고 문구와 공존
현재 부모 홈 상단에 표시되는 브라우저 알림 미지원 경고는 유지한다.

즉 부모 홈에서는:
1. 기존 경고 문구
2. 기존 홈 콘텐츠
3. 하단 `앱 설치하기` 배너

가 함께 보일 수 있어야 한다.

경고 때문에 설치 배너가 가려지거나 렌더링되지 않으면 안 된다.

---

## 4. 구현 원칙

- 부모 홈만 별도의 신규 배너 컴포넌트를 새로 만들지 말고,
  이미 사용 중인 `앱 설치하기` 배너/설치 CTA 컴포넌트를 재사용한다.
- 아이 홈과 부모 홈의 설치 배너 노출 조건이 다르면, 차이를 분석하고 부모 홈에도 동일 정책을 적용한다.
- 설치 관련 core 로직(`beforeinstallprompt`, standalone 감지, dismiss 상태 저장 등)은 중복 구현하지 않는다.

---

## 5. 확인해야 할 사항

구현 전에 다음을 확인한다.

1. 현재 앱 설치 배너가 어디에서 렌더링되는지
2. 어떤 화면에서는 보이고 어떤 화면에서는 안 보이는지
3. 부모 홈에서 배너가 빠진 이유가
   - 단순 렌더링 누락인지
   - 조건문 차이인지
   - 레이아웃/포지셔닝 충돌인지
   - 알림 경고 컴포넌트와의 충돌인지
4. 기존 dismiss 저장 방식(localStorage/state 등)
5. standalone PWA 감지 로직

---

## 6. 수용 기준

- AC-01: 부모 홈 화면에서도 하단 `앱 설치하기` 배너가 노출된다.
- AC-02: 배너 UI는 기존 설치 배너와 동일한 스타일/구성이다.
- AC-03: `앱 설치하기` 클릭 시 기존 설치 흐름과 동일하게 동작한다.
- AC-04: `X` 클릭 시 기존 배너와 동일하게 닫힌다.
- AC-05: 이미 설치된 PWA 환경에서는 불필요하게 노출되지 않는다.
- AC-06: 부모 홈 상단 알림 미지원 경고는 그대로 유지된다.
- AC-07: 경고와 설치 배너가 동시에 있어도 레이아웃이 깨지지 않는다.
- AC-08: 아이 홈/기존 화면의 설치 배너 동작에 회귀가 없다.
