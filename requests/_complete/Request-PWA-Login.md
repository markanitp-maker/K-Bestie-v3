# Request: PWA 자동 로그인 유지 및 로그인 세션 해제 이슈 해결

## 목적

현재 부모/아이 PWA에서 로그인 상태가 자주 해제되어 다시 로그인해야 하는 문제가 발생하고 있다.

PWA는 일반 모바일 앱과 동일한 사용성을 제공해야 하므로, 사용자가 명시적으로 로그아웃하지 않는 이상 로그인 상태가 계속 유지되도록 수정한다.

---

# 현재 문제

다음과 같은 상황에서 부모와 아이 모두 로그인 상태가 자주 해제된다.

- PWA를 종료 후 다시 실행
- 일정 시간이 지난 후 재접속
- 백그라운드 후 복귀
- 기기 재부팅
- PWA 업데이트 이후
- 원인을 알 수 없는 세션 종료

이로 인해 매번 로그인해야 하는 상황이 반복된다.

---

# 목표

부모와 아이 모두 아래 정책을 만족해야 한다.

- 앱 종료 후 재실행해도 자동 로그인
- 백그라운드 후 복귀해도 로그인 유지
- 기기 재부팅 후에도 로그인 유지
- PWA 업데이트 후에도 로그인 유지
- Development / Production 동일 동작

사용자가 "로그아웃" 버튼을 누르지 않는 이상
로그인 상태는 계속 유지되어야 한다.

---

# 반드시 원인 분석

기능 추가가 아니라
현재 로그인 세션이 해제되는 근본 원인을 먼저 분석한다.

다음을 모두 확인한다.

## 1. Supabase Auth Session

- session restore
- refresh token
- access token
- auto refresh

정상 동작 여부 확인

---

## 2. Storage

다음 저장 위치 확인

- localStorage
- IndexedDB
- SessionStorage

SessionStorage 사용 여부 확인

SessionStorage 사용 중이라면 적절한 영구 저장 방식으로 변경한다.

---

## 3. Auth Restore

앱 시작 시

현재

Loading →
Login 화면

으로 이동하는 조건을 확인한다.

로그인 가능한 세션이 존재하는 경우에는

Loading →
Home

으로 바로 이동해야 한다.

---

## 4. Token Refresh

Access Token 만료 시

자동으로 Refresh Token을 이용하여
새로운 Access Token을 발급받도록 한다.

Refresh Token이 살아있는데도
로그인 화면으로 이동하는 경우를 제거한다.

---

## 5. Network Error

일시적인 네트워크 오류 때문에

로그아웃 처리하면 안 된다.

재시도 후 복구하도록 수정한다.

---

## 6. PWA

다음도 확인한다.

- Service Worker 업데이트
- Cache 업데이트
- App Reload

과정에서

로그인 정보가 삭제되는 부분이 있는지 확인한다.

---

# 로그아웃 정책

아래 경우만 로그인 화면으로 이동한다.

- 사용자가 직접 로그아웃
- Refresh Token 만료
- Refresh Token 폐기
- 계정 삭제
- 관리자에 의해 세션 무효화

그 외에는
자동 로그인 상태를 유지한다.
