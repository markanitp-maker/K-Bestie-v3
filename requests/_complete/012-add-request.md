내친구 케이 대화 화면(스마트폰/태블릿 공통)을 다음 7개 항목으로 수정한다. (1) 세션 시작 시 케이가 곧바로 미션 질문을 던지지 말고 인사 턴을 먼저 실행한다. 미션 타입에 따라 인사 문구를 분기하며, 하교 후 세션(첫번째 미션)은 "안녕~ {childName}야. 어제는 잘 잤니?" 또는 "안녕~ {childName}야. 학교는 잘 다녀왔니?" 중 하나를 랜덤으로 출력하고, 취침 전 세션(두번째 미션)은 "안녕~ {childName}야. 오늘 하루 어땠니?"를 출력한다. {childName}은 프로필의 아이 이름을 주입하고 받침 유무에 따라 "야/아" 호격 조사를 자동 처리한다(예: 서아야, 서현아). 인사 턴은 아이 응답을 1회 받고 그 응답에 대한 짧은 리액션(공감 1문장)을 출력한 뒤 첫 미션 질문으로 넘어가며, 인사 턴과 리액션은 미션 카운터(0/10)에 포함시키지 않는다. 인사 응답이 5초 이상 없거나 무음이면 케이가 한 번 더 부드럽게 재호출한 뒤 자동으로 미션 질문으로 진행한다. (2) 케이 캐릭터 오른쪽에 있는 상태 배지("말하는 중 / 듣는 중 / 생각하는 중")를 캐릭터 왼쪽으로 이동시키고, 캐릭터와 배지를 flex row로 묶어 세로 중앙 정렬한다. 상태 변경 시 배지 텍스트와 아이콘이 fade 전환되도록 한다. (3) 우측 상단의 "자동/수동" 토글 버튼을 헤더에서 제거하고 케이 캐릭터 오른쪽에 배치한다. 상태 배지(좌) - 케이 캐릭터(중앙) - 자동/수동 토글(우) 순서의 한 줄 레이아웃으로 구성하고, 토글은 세로형이 아닌 컴팩트한 가로형 세그먼트 컨트롤로 바꾸며 선택된 항목만 브랜드 그린 배경 + 흰 글씨로 표시한다. (4) 헤더의 스피커 아이콘(케이 음성 on/off)을 헤더에서 제거하고 케이 캐릭터의 왼쪽 발 옆(캐릭터 컨테이너 기준 하단 좌측)에 원형 아이콘 버튼으로 배치한다. off 상태에서는 스피커에 사선(mute) 아이콘과 회색 처리, on 상태에서는 브랜드 컬러로 표시하고 상태를 로컬스토리지에 유지한다. (5) 헤더의 "내친구 케이" 텍스트를 로고 이미지 컴포넌트로 교체한다. 로고 에셋 경로는 프로젝트 내 실제 파일로 연결하고(없으면 assets/logo-kei.svg로 임시 연결 후 TODO 주석), 높이 기준으로 고정하고 width는 auto, alt 텍스트는 "내친구 케이"로 설정한다. 기존의 소리 파형 데코 요소는 로고에 포함되어 있으므로 제거한다. (6) 케이 대화 히스토리 영역에 스크롤을 적용한다. 영역 높이는 말풍선 3개가 보이는 높이로 고정(max-height 계산 방식 사용)하고 overflow-y: auto, 커스텀 스크롤바(폭 4px, 반투명 회색, 라운드)를 적용한다. 새 말풍선이 추가되면 자동으로 최하단으로 부드럽게 스크롤하고, 사용자가 위로 스크롤 중일 때는 자동 스크롤을 멈추고 "새 메시지" 하단 플로팅 버튼을 노출한다. 아이 말풍선과 케이 말풍선의 스타일 구분은 현재 디자인을 유지한다. (7) 상단의 "0/10" 미션 진행 현황을 단순 텍스트+바에서 스텝 인디케이터 디자인으로 개선한다. 10개의 세그먼트 도트를 가로로 배치하고, 완료된 스텝은 브랜드 그린으로 채우고 현재 진행 중인 스텝은 펄스 애니메이션, 미완료는 연회색으로 표시한다. 좌측에 현재 미션 라벨(예: "하교 후 미션")을, 우측에 "3/10" 카운터를 배치하며 스텝 완료 시 채워지는 전환 애니메이션(200~300ms)을 넣는다. 전체 완료 시 인디케이터 영역이 축하 색상으로 바뀌고 완료 배지를 표시한다. 모든 수정은 스마트폰/태블릿 두 모드에서 레이아웃이 깨지지 않도록 반응형으로 처리하고, 기존 음성 인식/TTS 로직과 미션 진행 상태 관리 로직은 변경하지 않으며 UI 레이어만 수정한다. 수정 후 두 모드 각각에서 렌더링을 확인하고 변경 파일 목록을 보고한다.
