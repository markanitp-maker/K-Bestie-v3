## 16.1 상세 모달 상단 메뉴 고정

일일·주간 리포트 상세 모달의 다음 상단 메뉴는 본문을 스크롤해도 항상 화면에 유지되어야 한다.

- 빠른 요약
- 상세 보기
- 추천 가이드

### 레이아웃 구조

모달을 다음 세 영역으로 분리한다.

```text
1. 모달 제목 + 닫기 버튼
2. 빠른 요약·상세 보기·추천 가이드 탭
3. 선택한 탭의 스크롤 콘텐츠
```

모달 제목과 `X` 닫기 버튼은 최상단에 고정한다.

탭 메뉴는 제목 영역 바로 아래에 고정한다.

스크롤은 탭 아래의 콘텐츠 영역에서만 발생해야 한다.

```text
[8월 4일 일간 리포트]                [X]  ← 고정
[빠른 요약] [상세 보기] [추천 가이드]     ← 고정
────────────────────────────────────
선택한 탭의 리포트 내용                    ← 이 영역만 스크롤
```

### 구현 기준

다음 중 현재 모달 구조에 적합한 방식을 사용한다.

- 제목·탭 영역 고정 + 콘텐츠 영역 `overflow-y: auto`
- 탭 컨테이너 `position: sticky`
- 전체 모달이 아닌 콘텐츠 컨테이너만 스크롤

탭 컨테이너에 필요한 속성을 적용한다.

- 적절한 `top`
- 콘텐츠보다 높은 `z-index`
- 불투명한 배경색
- 하단 경계선 또는 약한 그림자
- 좌우 모달 여백과 일치하는 너비
- 스크롤 중 본문이 탭 위로 비쳐 보이지 않도록 처리

### 금지 사항

다음 구조를 사용하면 안 된다.

- 모달 제목과 탭까지 함께 위로 사라지는 전체 영역 스크롤
- 탭이 본문 위에 겹쳐 내용을 가리는 구조
- 탭 배경이 투명하여 본문이 비쳐 보이는 구조
- 탭 전환 시 스크롤 위치가 예기치 않게 공유되는 구조
- 모바일에서 `X` 버튼이 화면 밖으로 사라지는 구조
- 페이지 본문과 모달 내부가 동시에 스크롤되는 구조

### 탭 전환 시 스크롤 정책

각 탭을 선택하면 해당 탭 콘텐츠의 시작 위치를 보여준다.

권장 동작:

```text
상세 보기 중간까지 스크롤
→ 추천 가이드 선택
→ 추천 가이드 콘텐츠 최상단 표시
```

다시 상세 보기로 돌아왔을 때의 스크롤 위치 유지 여부는 현재 상태 관리 구조에 맞춰 결정할 수 있으나, 동일 탭 내에서 단순 리렌더링 때문에 위치가 튀면 안 된다.

### 적용 범위

다음 모든 진입 경로와 리포트 유형에 동일하게 적용한다.

- 일일 리포트 목록 카드
- 주간 리포트 목록 카드
- 지난 이력보기 일일 달력
- 지난 이력보기 주간 선택
- 빠른 요약
- 상세 보기
- 추천 가이드

목록 카드용 모달과 달력 선택용 모달에서 서로 다른 레이아웃을 사용하지 않는다.

### 모바일·태블릿 검증

다음 환경을 확인한다.

- iPhone Safari
- iPhone PWA
- Android Chrome
- 태블릿 가로·세로 화면

검증 항목:

- 제목과 `X` 버튼 유지
- 세 개 탭 유지
- 모달 본문만 스크롤
- iOS 모멘텀 스크롤 정상
- safe-area 반영
- 하단 내비게이션과 겹치지 않음
- 탭 클릭 영역 충분
- 본문 끝까지 스크롤 가능
- 배경 페이지 스크롤 차단
- 탭과 본문 사이 겹침 없음
```

- 탭 아래 콘텐츠 영역만 스크롤된다.
- 본문이 탭 뒤로 비치거나 겹치지 않는다.
- 탭을 선택하면 해당 콘텐츠의 시작 위치가 표시된다.
- 배경 리포트 목록은 스크롤되지 않는다.
- 목록 카드와 달력 진입 경로가 동일하게 동작한다.
```
