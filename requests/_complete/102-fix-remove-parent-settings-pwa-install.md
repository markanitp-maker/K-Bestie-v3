# 부모 설정 PWA 설치 메뉴 제거 및 홈 설치 진입점 단일화

## 0. 완료 시 기대 결과 / 대표님 테스트 정상 프로세스

### 완료 시 기대 결과

부모 설정 화면의 `앱 설치하기` 메뉴를 완전히 제거한다.

PWA 설치는 다음 두 곳의 **홈 화면 설치 진입점만 사용한다.**

- 부모 홈
- 아이 홈

사용자가 홈에서 `앱 설치하기`를 누르면 현재 구현 중인 공통 PWA 설치 흐름에 따라 환경별로 처리한다.

```text
부모/아이 홈
   ↓
앱 설치하기
   ↓
실행 환경 판별
   ├─ 일반 설치 지원 브라우저 → Native PWA 설치
   ├─ iPhone/iPad Safari → Safari 설치 방법 팝업
   └─ 인앱 브라우저 → 외부 Safari/Chrome 이동 방법 팝업
```

부모 설정에는 더 이상 PWA 설치 메뉴가 존재하지 않는다.

# 2. 목표

PWA 설치 진입점을 단순화한다.

현재 PWA 설치 기능은 부모·아이 홈에서 직접 제공하므로 부모 설정 화면의 별도 `앱 설치하기` 메뉴는 중복 기능이다.

따라서:

> **PWA 설치는 부모 홈 + 아이 홈에서만 제공하고, 부모 설정의 설치 메뉴는 제거한다.**

설정 화면은 반복적으로 관리하는 기능만 남기고, 일회성 설치 기능은 홈에서 처리한다.

## 3.2 부모 설정에서 제거할 UI

현재 부모 설정 화면에 존재하는 다음 카드 전체를 제거한다.

### 제목
`앱 설치하기`

### 설명
`홈 화면에 추가하여 더 편리하게 이용하세요`

### 버튼
`설치`

카드 내부 아이콘, 텍스트, 버튼을 개별 숨김 처리하지 말고 **설치 카드 전체를 제거**한다.

---

# 4. 제거 후 레이아웃

PWA 설치 카드 삭제 후:

- 빈 컨테이너를 남기지 않는다.
- 기존 카드 높이를 유지하지 않는다.
- 고정 height를 남기지 않는다.
- margin/padding 잔여값으로 빈 영역을 만들지 않는다.
- 다음 메뉴가 자연스럽게 위로 재배치되어야 한다.

현재 화면 기준으로:

```text
아이 정보 관리
보호자 설정
앱 설치하기   ← 제거
로그아웃
```

변경 후:

```text
아이 정보 관리
보호자 설정
로그아웃
```

이 자연스럽게 이어져야 한다.

# 5. 코드 정리

부모 설정 페이지에서 PWA 설치 메뉴 제거로 인해 더 이상 사용되지 않는 다음 코드가 있다면 함께 정리한다.

예:

- PWA install 관련 state
- `useInstallPrompt`
- `isStandalone`
- `isIOS`
- install click handler
- PWA Modal state
- PWA 전용 import
- PWA 전용 callback
- PWA 카드 전용 icon import

단, **해당 코드가 부모 설정 외 다른 기능에서도 사용된다면 삭제하지 않는다.**

무조건 삭제하지 말고 실제 reference를 확인한 뒤 unused가 된 코드만 제거한다.

# 7. 홈 설치 재진입 보장

부모 설정의 PWA 메뉴를 제거하면 **홈이 유일한 설치 진입점**이 된다.

따라서 작업 완료 전에 반드시 확인한다.

### 확인 사항

- 부모 홈에서 설치 안내를 닫은 뒤 다시 열 수 있는가?
- 아이 홈에서도 다시 열 수 있는가?
- 브라우저 새로고침 후 설치 진입점이 정상인가?
- 아직 설치하지 않은 사용자가 실수로 안내를 닫았다고 해서 설치 기능을 영구적으로 잃지 않는가?
- 설치 완료된 PWA에서는 불필요한 설치 UI가 다시 뜨지 않는가?

### 정책

`팝업 닫기`와 `PWA 설치 완료`는 동일한 상태가 아니다.

단순히 팝업을 닫았다는 이유로 사용자를 `설치 완료`로 간주하지 않는다.

# 8. 기존 코드 확인

수정 전에 최소 다음 영역을 확인한다.

```text

app/child/home/page.tsx
hooks/useInstallPrompt.ts
lib/pwa/standalone.ts
components/pwa/*
```

기존 조사 결과의 파일/라인이 현재 코드와 달라졌다면 **현재 HEAD를 기준으로 수정한다.**
