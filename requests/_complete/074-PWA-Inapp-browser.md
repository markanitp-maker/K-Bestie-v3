대표님, 074는 이렇게 업데이트하면 됩니다. 핵심은 **“부모님이 한눈에 보고 따라 할 수 있게, 방법 안내 글씨를 확실히 크게”**입니다.

```md
# Request 074 — 카카오 인앱브라우저 외부 브라우저 안내 화면 가독성 강화

## 1. 작업 목적

카카오톡 인앱브라우저에서 표시되는 외부 브라우저 전환 안내 화면을
부모 사용자가 설명을 읽고 바로 따라 할 수 있도록 가독성을 강화한다.

이번 작업의 핵심은 다음이다.

- 설치 방법 안내 글씨를 크게 표시
- 단계별 안내를 눈에 잘 띄게 표시
- 작은 회색 보조문구처럼 보이지 않게 변경
- iPhone / Android 각각 실제 OS에 맞는 안내 제공
- 주소 복사 성공 피드백 명확화

이번 작업은 UI/UX 수정 범위이며 기존 회원가입, 가족 초대, 로그인, PWA 설치 로직은 변경하지 않는다.

Development에서 먼저 적용·검증한다.

- Development: `https://k-bestie-v3-dev.vercel.app`
- Production: Dev 검증 완료 후 반영

---

## 2. 중요 전제 — 이 화면 노출 조건

이 외부 브라우저 안내 화면은 KakaoTalk 인앱브라우저라는 이유만으로 모든 페이지에서 표시하면 안 된다.

반드시 **사용자가 실제 `앱 설치하기` 흐름에 진입했을 때만** 표시한다.

정상 동작:

```text
카카오 인앱브라우저
→ 회원가입
→ 로그인
→ 가족 초대 수락
→ 일반 서비스 이용
```

위 흐름에서는 외부 브라우저 안내 화면을 표시하지 않는다.

오직:

```text
사용자가 `앱 설치하기` 선택
+
KakaoTalk 인앱브라우저
→ 외부 브라우저 안내 화면
```

일 때만 표시한다.

단순 KakaoTalk User-Agent 감지만으로 회원가입/로그인/초대 URL을 차단하지 않는다.

## 5. 가장 중요한 변경 — 설치 방법 안내를 크게 표시

현재 `iPhone에서 여는 방법`, `Android에서 여는 방법` 영역의 글씨가 작아
부모 사용자가 한눈에 따라 하기 어렵다.

이 영역은 일반 설명 문구가 아니라 **실제 행동 지침**이므로 크게 표시한다.

### 권장 크기 기준

현재 스타일을 확인한 뒤 아래 수준을 목표로 한다.

- 안내 박스 제목: 최소 `20px` 전후
- 단계 설명: 최소 `18px` 전후
- line-height: 최소 `1.6`
- 숫자 `1.`, `2.`도 본문과 동일하게 크게 표시
- 너무 얇은 font-weight 사용 금지

Tailwind 사용 시 예:

```text
안내 제목:
text-xl font-bold

단계 설명:
text-lg leading-8 font-medium
```

단 실제 프로젝트 typography 체계가 있으면 그 체계를 우선 사용한다.

## 6. iPhone 안내

제목:

```text
iPhone에서 여는 방법
```

내용:

```text
1. 위쪽 주소/메뉴 영역을 눌러 주세요.

2. ‘다른 브라우저로 열기’ 또는
   ‘Safari에서 열기’를 선택해 주세요.
```

### 표시 원칙

- 한 줄에 너무 많은 글자를 넣지 않는다.
- 부모 사용자가 순서대로 바로 따라 할 수 있도록 문장을 짧게 한다.
- `1`, `2` 단계 사이에 충분한 간격을 둔다.
- 핵심 행동 문구는 필요하면 굵게 표시한다.

예:

```text
1. 위쪽 주소/메뉴 영역을 눌러 주세요.

2. ‘다른 브라우저로 열기’를 선택해 주세요.
```

가능하면 설명을 더 짧고 명확하게 유지한다.

## 10. 안내 박스 디자인

안내 박스는 부모 사용자가 화면에서 가장 먼저 따라 해야 하는 영역이므로
보조 콘텐츠처럼 작게 만들지 않는다.

### 요구사항

- 충분한 내부 padding
- 제목과 단계 사이 간격 확대
- 1번과 2번 사이 간격 확대
- 본문 대비가 충분한 색상 사용
- 지나치게 연한 회색 사용 금지
- 좁은 iPhone 화면에서도 읽기 편해야 함
- 안내 박스 높이가 약간 늘어나도 가독성을 우선한다

## 12. 주소 복사하기 버튼

```text

```

권장:

- 버튼 텍스트 최소 `18px` 수준
- 모바일 touch target 최소 44px 이상

현재 실제 가입/초대 URL을 클립보드에 복사하는 기존 기능은 유지한다.

기본 상태:
