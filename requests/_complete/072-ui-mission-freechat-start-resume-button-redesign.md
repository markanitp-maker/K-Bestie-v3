# 미션·자유대화 `시작하기 / 이어하기` CTA 버튼 시각 개선

## 0. 완료 시 기대 결과 / 대표님 테스트 정상 프로세스

### 완료 시 기대 결과
- 미션과 자유대화에서 현재 말풍선처럼 보이는 `시작하기` / `이어하기` 영역을 명확한 CTA 버튼 형태로 변경한다.
- 첨부 비교 이미지의 오른쪽 시안처럼 주황색 채움 버튼 + 흰색 텍스트 + 재생(▶) 아이콘으로 보여 사용자가 즉시 “눌러야 하는 버튼”임을 인지할 수 있어야 한다.
- 미션과 자유대화에 동일한 버튼 스타일을 적용한다.
- `시작하기`와 `이어하기`의 기존 동작, 클릭 이벤트, 세션 진입 로직은 변경하지 않는다.
- 버튼 주변의 마스코트, 배경, 상태 UI, 진행률, 음성/수동 토글, 마이크 등 다른 UI는 변경하지 않는다.

### 대표님 테스트 정상 프로세스
1. Dev에서 아이 계정으로 로그인한다.
2. 미션 화면에 진입한다.
3. 신규 미션 상태에서는 `▶ 시작하기` 버튼이 오른쪽 참고 시안과 같은 명확한 주황색 CTA 버튼으로 보이는지 확인한다.
4. 버튼을 눌러 기존과 동일하게 미션이 정상 시작되는지 확인한다.
5. 미션을 중간 종료한 뒤 다시 진입해 `▶ 이어하기` 버튼이 동일한 스타일로 표시되는지 확인한다.
6. 자유대화 화면에서도 신규 상태의 `▶ 시작하기`, 이어지는 세션의 `▶ 이어하기`가 동일한 버튼 스타일로 표시되는지 확인한다.
7. 모바일에서 버튼이 말풍선처럼 보이지 않고 클릭 가능한 CTA로 즉시 인식되는지 확인한다.
8. Dev QA PASS 후 Production에 동일 변경을 배포한다.

PASS:
- 미션/자유대화 모두 `시작하기`와 `이어하기`가 동일한 CTA 버튼 스타일이다.
- 버튼 클릭 동작은 기존과 동일하다.
- 주변 UI 위치와 레이아웃에 의도하지 않은 변화가 없다.

## 1. 작업 목적

현재 미션과 자유대화의 `시작하기` / `이어하기` UI가 흰색 배경 + 주황색 외곽선 형태로 되어 있어 말풍선 또는 안내 카드처럼 보인다.

사용자가 별도 설명 없이도 즉시 “눌러야 하는 버튼”임을 알 수 있도록, 첨부 이미지의 오른쪽 시안을 기준으로 CTA 시각 스타일만 개선한다.

이번 작업은 기능 변경이 아닌 순수 UI 가독성/클릭 인지성 개선이다.

---

## 2. 적용 범위

### 대상 화면
- 미션
- 자유대화

### 대상 상태
- `시작하기`
- `이어하기`

두 화면/두 상태 모두 동일한 디자인 시스템을 사용한다.

Codex는 현재 코드에서 미션과 자유대화의 `시작하기` / `이어하기`를 실제 렌더링하는 컴포넌트와 분기 위치를 먼저 확인한 후, 가능한 한 중복 없이 동일 스타일을 적용한다.

단, 이번 작업을 이유로 대화 화면 전체 구조를 리팩터링하지 않는다.

---

## 3. 디자인 요구사항

첨부 비교 이미지의 오른쪽 버튼을 목표 시안으로 사용한다.

### 기본 스타일
- 버튼 전체는 명확한 주황색 Filled CTA
- 텍스트는 흰색
- 텍스트는 굵고 충분히 크게 유지
- 텍스트 왼쪽에 흰색 재생 아이콘 `▶` 또는 현재 아이콘 시스템에 맞는 동일 의미의 Play 아이콘 배치
- 버튼 라운드는 현재 브랜드 UI와 자연스럽게 어울리는 둥근 사각형
- 버튼 외곽에는 시안처럼 버튼이 배경에서 분명히 떠 보일 정도의 얇은 밝은 외곽/프레임 또는 부드러운 shadow 적용
- 과도한 3D 효과, 강한 그라데이션, 번쩍이는 애니메이션은 사용하지 않는다.
- 버튼이 말풍선으로 오인될 수 있는 꼬리(tail) 또는 말풍선형 시각 표현은 사용하지 않는다.

### 문구
신규 시작:
`▶ 시작하기`

이어지는 세션:
`▶ 이어하기`

아이콘과 텍스트는 한 줄 중앙 정렬한다.

### 크기
- 현재 버튼이 차지하는 전체 화면 영역을 크게 바꾸지 않는다.
- 모바일에서 충분한 터치 영역을 유지한다.
- 버튼 자체는 첨부 오른쪽 시안처럼 “중앙 CTA”로 명확하게 보이게 한다.
- 버튼 크기를 키우기 위해 주변 마스코트나 다른 UI를 밀어내지 않는다.

## 5. 주변 UI 변경 금지

첨부 이미지에서 버튼을 제외한 화면은 기준 그대로 유지한다.

변경 금지:
- 상단 헤더
- 뒤로가기
- 로그아웃
- 미션 진행률 별 UI
- 배경 색상/장식
- K 마스코트 크기/위치
- 마스코트 받침대
- 좌우 상태 아이콘
- `소리 켜짐`
- `시작 전`
- 자동/수동 토글
- 마이크 버튼
- 키보드 버튼
- 말풍선 위치/크기
- 대화 로직

버튼 변경 때문에 주변 요소의 vertical spacing이 달라지지 않도록 한다.

## 6. 구현 원칙

1. 미션과 자유대화의 현재 버튼 렌더링 위치를 확인한다.
2. 두 화면이 동일한 CTA 스타일 값을 사용하도록 한다.
3. 이미 공통 컴포넌트/스타일이 있다면 그것을 활용한다.
4. 공통화가 필요하더라도 이 버튼 범위 안에서만 최소한으로 진행한다.
5. 신규 대형 UI 컴포넌트나 화면 레이아웃 리팩터링은 하지 않는다.
6. hover가 없는 모바일에서도 눌림 상태가 명확하도록 `active` 피드백은 유지/추가 가능하다.
7. `disabled` 상태가 현재 존재한다면 기존 disabled 동작을 유지하고 시각적으로도 구분한다.
8. 접근성 이름은 기존 문구 의미를 유지한다.

- 자유대화 `이어하기` 클릭 → 정상 재개

### UI QA
- 4개 경우 모두 동일한 Filled Orange CTA 스타일
- 흰색 Play 아이콘 + 흰색 문구
- 중앙 정렬
- 말풍선처럼 보이지 않음
- 텍스트 잘림 없음
- 버튼 주변 요소 이동 없음
- 가로 overflow 없음
