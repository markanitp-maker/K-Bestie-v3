## 제목
미션 대화 / 자유 대화 음성 화면 레이아웃 통합

## 목적

현재 내친구 케이 음성 대화 화면은 미션 대화와 자유 대화가 서로 다른 UI 구조로 구현되어 있어 사용자가 다른 서비스처럼 느끼는 문제가 있다.

미션 대화 화면을 기준 레이아웃으로 삼아 자유 대화 화면도 동일한 Voice Conversation UI 경험을 제공하도록 통합한다.

기능 로직(STT/TTS, 음성 처리, 대화 저장, 미션 진행 로직)은 변경하지 않고 UI 레이어만 통합한다.

---

# 요구사항

## 1. 공통 음성 대화 레이아웃 컴포넌트 적용

미션 대화와 자유 대화가 동일한 레이아웃 구조를 사용하도록 변경한다.

공통 구조:

```
VoiceConversationLayout

├── Header
│   ├── 뒤로가기
│   ├── 내친구 케이 로고
│   └── 연결 상태 표시
│
├── MissionProgress
│   └── 미션 화면에서만 표시
│
├── ConversationHistory
│   └── 최근 대화 표시 영역
│
└── VoiceControlArea
    ├── 상태 표시
    ├── 케이 마스코트
    ├── 자동/수동 토글
    └── 음성 컨트롤 버튼
```

자유 대화에서는 미션 진행 영역만 숨기고 나머지 구조는 동일하게 유지한다.

---

# 2. Header 영역 통일

미션 대화 화면 기준으로 자유 대화 화면 Header를 통일한다.

적용 항목:

- 뒤로가기 위치 동일
- 내친구 케이 로고 위치 동일
- 로고 크기 동일
- 우측 연결 상태 표시 동일
- 상단 높이 동일

현재 자유 대화 화면처럼 로고만 단독 표시되는 구조 제거.

---

# 3. 대화 히스토리 영역 통일

미션 대화와 동일한 ConversationHistory 영역 적용.

조건:

- 최근 대화 메시지 표시
- 말풍선 스타일 동일 적용
- 아이 메시지 / 케이 메시지 스타일 유지
- 전체 페이지 스크롤 금지
- 히스토리 영역 내부 스크롤 사용
- 최대 표시 개수는 기존 미션 대화 기준 유지

자유 대화에서도 동일한 대화 경험 제공.

---

# 4. 하단 케이 컨트롤 영역 통합

미션 대화에서 적용한 하단 구조를 자유 대화에도 동일 적용한다.

최종 구조:

```
[상태 배지]      [케이 마스코트]      [자동/수동]
```

## 상태 배지

표시:

- 듣는 중
- 생각하는 중
- 말하는 중

조건:

- 상태 텍스트 변경만 발생
- 전체 레이아웃 위치 변경 금지
- 마스코트 위치 영향 금지
- 자동/수동 버튼 위치 영향 금지

상태 배지는 고정 width 영역으로 처리한다.

예:

```
[120px 상태 영역] [120px 케이 영역] [120px 토글 영역]
```

---

# 5. 케이 마스코트 위치 통일

미션 대화 기준으로 적용한다.

조건:

- 화면 중앙 기준 고정
- 상태 배지 변화에 따라 이동 금지
- 자동/수동 토글 변화에 따라 이동 금지
- 스마트폰/태블릿 동일 위치 유지

---

# 6. 자동/수동 토글 통일

현재 미션 대화에서 사용하는 자동/수동 버튼 디자인을 자유 대화에도 적용한다.

조건:

- 케이 오른쪽 고정
- 세로형 제거
- 가로형 세그먼트 컨트롤 유지
- 선택 상태 브랜드 컬러 적용

---

# 7. 음성 컨트롤 버튼 통일

미션 대화에서 적용한 음성 버튼 UI를 자유 대화에도 적용한다.

동일 적용:

- 마이크 버튼
- 녹음 중지 버튼
- 비활성 상태 버튼

상태별 디자인 유지:

- 아이가 말할 수 있는 상태
- 케이가 말하는 중인 상태
- 녹음 불가능 상태

---

# 8. 반응형 적용

지원 환경:

- 스마트폰
- 태블릿
- PC 웹/PWA

조건:

- 스마트폰 현재 정상 UI 유지
- 태블릿/PC에서도 동일 VoiceConversationLayout 사용
- 화면 크기에 따라 깨짐 없음

---

- 자유 대화 비즈니스 로직

UI 컴포넌트 구조 개선만 수행한다.

# 10. QA 검증

수정 완료 후 반드시 QA 진행한다.

검증 항목:

확인 대상:

- 미션 대화
- 자유 대화

확인 내용:

- 케이 위치 동일 여부
- 상태 배지 위치 동일 여부
- 자동/수동 위치 동일 여부
- 음성 버튼 동일 여부

## 상태 변경 테스트

반복 테스트:

```
듣는 중
→ 생각하는 중
→ 말하는 중
→ 듣는 중
```

검증:

- 상태 변경 시 마스코트 이동 없음
- 자동/수동 버튼 이동 없음
- 레이아웃 흔들림 없음

- 태블릿
