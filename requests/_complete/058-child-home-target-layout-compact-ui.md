# 058 — 아이 홈 화면 목표 UI 정밀 재배치

## 1. 작업 목적

첨부 비교 이미지에서 왼쪽은 현재 아이 홈 화면이고, 오른쪽은 목표 UI다.

이번 작업의 목적은 기능·데이터·라우팅을 변경하지 않고, 아이 홈 화면의 레이아웃과 각 카드의 높이·간격·배치를 목표 이미지에 맞게 재조정하는 것이다.

핵심 방향은 다음과 같다.

- 상단 마스코트·인사 영역을 조금 더 컴팩트하게 정리
- 30일 이벤트 카드의 세로 높이를 크게 줄이고 정보 밀도를 높임
- 이벤트 카드와 미션 상태 말풍선 사이 간격 축소
- 미션 진행 카드를 조금 더 위로 올리고 높이를 줄임
- 하단 `대화하기 / 케이와 놀이` 카드도 위로 당겨 첫 화면에 더 안정적으로 노출
- 전체 첫 화면의 빈 공간을 줄이고, 주요 행동 영역을 한 화면에 모음

---

## 2. 비교 이미지 기준

첨부 합성 이미지 전체 크기: 약 `841 × 718px`

- 왼쪽 패널: 현재 화면
- 오른쪽 패널: 목표 화면

정확한 구현 전에는 브라우저에서 현재 아이 홈 화면 각 요소의 `getBoundingClientRect()`를 직접 측정하고, 아래 목표 구조와 비교하여 실제 수정값을 산출한다.

고정 px만 하드코딩하지 말고, 기준 viewport에서 목표 비율을 맞춘 뒤 반응형으로 보정한다.

---

## 3. 상단 영역 변경

### 3.1 이벤트/알림 버튼

현재 왼쪽 화면:
- 좌측 상단에 `종 아이콘 + 이벤트` 형태

목표 오른쪽 화면:
- 종 아이콘 단독 버튼
- 텍스트 `이벤트` 제거
- 버튼 크기는 아이콘만 담는 정사각형 형태로 축소
- 상단 좌측 여백은 유지
- 로그아웃 버튼과 같은 높이 축에 맞춤

### 3.2 로그아웃 버튼

- 기능과 위치는 유지
- 목표 화면과 동일하게 상단 우측에 작고 독립적인 아이콘 버튼 형태 유지
- 다른 요소를 밀어내지 않게 한다.

---

## 4. 케이 마스코트 및 인사 영역

현재 왼쪽 화면은 마스코트와 인사 영역이 다소 크게 차지한다.

목표 오른쪽 화면에서는:

- 마스코트는 현재보다 약간 작아짐
- 마스코트 상단 위치는 비슷하지만 전체 높이를 줄임
- 인사 문구가 마스코트에 더 가깝게 붙음
- `안녕, ○○야!`
- `오늘은 뭐 하고 놀까?`
- 두 줄 간격을 축소
- 인사 영역과 이벤트 카드 사이 여백도 축소

### 구현 원칙

- 마스코트 비율 유지
- `object-contain`
- 상단 배경 영역의 전체 높이를 줄인다.
- 마스코트 크기만 줄이고 불필요한 빈 spacer가 남지 않게 한다.
- 인사 문구의 글자 크기·행간은 목표 이미지와 비슷하게 조정

---

## 5. FAQ 플로팅 버튼

목표 화면에서도 좌측에 말풍선 형태 FAQ 플로팅 버튼이 유지된다.

- 현재 확정된 FAQ 버튼 동작 유지
- 홈 카드 재배치 때문에 위치가 겹치지 않게 한다.
- FAQ 버튼은 이벤트 카드나 인사 텍스트를 가리지 않아야 한다.
- 드래그 위치 저장 기능이 구현돼 있다면 유지한다.

---

## 6. “케이와 친해지는 30일” 이벤트 카드

이번 작업에서 가장 중요한 변경 영역이다.

### 6.1 현재 화면 문제

왼쪽 현재 화면:
- 카드 높이가 크다.
- 진행 정보 4줄이 세로로 쌓여 있다.
- 카드가 많은 세로 공간을 차지해 아래 미션·놀이 카드가 밀린다.

### 6.2 목표 화면

오른쪽 목표 화면:
- 카드 높이를 크게 줄인다.
- 제목 `케이와 친해지는 30일` 유지
- `0/60 완료` 유지
- 진행 바 유지
- 진행 바 아래 정보는 2열 배치

### 6.3 하단 정보 배치

왼쪽 컬럼:

```text
케이와 벌써 0번 이야기했어요!
현재 0원 구간을 달성했어요.
```

오른쪽 컬럼:

```text
10번 더 완료하면 1,000원 구간이에요.
이벤트 종료까지 28일 남았어요.
```

### 6.4 카드 높이 목표

- 현재보다 약 25~35% 높이를 줄이는 방향
- 제목/진행률/진행 바/2열 설명이 모두 한 카드 안에 들어가야 함
- 모바일에서도 2열 구조 유지
- 글자가 겹치거나 너무 작아지지 않게 line-height 조정
- 정보 영역의 불필요한 vertical padding 제거

### 6.5 구현 권장

```tsx
<div className="grid grid-cols-2 gap-x-3 gap-y-1">
  <div>...</div>
  <div>...</div>
</div>
```

- 실제 데이터는 기존 값 사용
- 값 하드코딩 금지
- 이벤트 집계 및 보상 계산 로직 변경 금지

## 7. 미션 상태 말풍선

현재:
- 이벤트 카드 아래에 말풍선이 떨어져 있음

목표:
- 이벤트 카드 바로 아래에 더 가깝게 배치
- `미션이 진행되고 있어요. 같이 할까?` 같은 상태 문구 유지
- 말풍선의 폭과 높이는 내용 기반 자동
- 말풍선과 이벤트 카드 사이 vertical gap 축소
- 말풍선과 미션 진행 카드 사이 gap도 축소

### 목표

- 이벤트 카드 → 말풍선 → 미션 카드가 하나의 연속된 흐름처럼 보이게 한다.
- 큰 빈 공간이 없어야 한다.

---

## 8. 미션 진행 카드

현재 왼쪽:
- 카드 높이가 상대적으로 크고 아래에 위치

목표 오른쪽:
- 카드가 위로 올라감
- 높이가 조금 줄어듦
- 아이콘·제목·설명·우측 `0/10` 배지는 유지
- 내부 padding 축소
- 카드 radius 및 브랜드 색상 유지

### 유지 요소

- 아이콘
- `미션 계속하기` 또는 현재 실제 상태명
- 상태 설명
- 우측 진행 횟수 배지

### 변경

- 상하 padding 축소
- 아이콘 컨테이너 약간 축소 가능
- 제목/설명 사이 간격 축소
- 카드 전체 높이를 현재보다 약 10~20% 줄이는 방향

---

## 9. 하단 `대화하기 / 케이와 놀이` 카드

목표 화면에서는 두 카드가 미션 카드 바로 아래에 붙어 올라와 있다.

### 요구사항

- 두 카드의 크기는 동일하게 유지
- 2열 구조 유지
- 현재보다 위쪽으로 이동
- 미션 카드와의 gap 축소
- 카드 내부 icon/title/subtitle 간격 축소
- 카드 전체 높이도 약간 줄여도 되지만 과도하게 작아지지 않게 한다.
- `대화하기`
- `케이와 놀이`
- 보유 열쇠 표시
- 기존 기능과 클릭 동작 유지

---

## 10. 전체 세로 배치 목표

현재 왼쪽:

```text
상단 버튼
→ 큰 마스코트
→ 인사
→ 큰 이벤트 카드
→ 말풍선
→ 미션 카드
→ 놀이 카드
```

목표 오른쪽:

```text
상단 아이콘 버튼
→ 조금 더 컴팩트한 마스코트
→ 인사
→ 낮아진 이벤트 카드
→ 바로 아래 상태 말풍선
→ 컴팩트 미션 카드
→ 바로 아래 놀이 카드 2개
```

핵심은 각 요소를 단순히 `translateY`로 위로 당기는 것이 아니라:

- 높이
- padding
- margin
- gap
- spacer
- flex/grid row

를 실제로 줄여 정상적인 문서 흐름으로 배치하는 것이다.

## 12. 반응형 기준

### 기준 모바일

- iPhone 390×844
- Android 360×800
- Android 412×915

### 요구사항

- 가로 스크롤 없음
- 카드 잘림 없음
- FAQ 버튼이 콘텐츠를 가리지 않음
- 이벤트 카드 2열 정보가 깨지지 않음
- 첫 화면에서 미션 카드와 놀이 카드까지 최대한 많이 보이도록 함
- 화면 높이가 작아져도 카드가 겹치지 않음

### PC / 태블릿

기존 PC/태블릿 레이아웃이 있다면 현재 구조를 깨지 않는다.

모바일 최적화가 PC에 그대로 확대되어 과도하게 넓어지지 않게 `max-width` 유지.

## 13. 구현 전 필수 측정

수정 전에 다음 요소의 실제 값을 Dev에서 측정해 보고한다.

- 마스코트 top / width / height
- 인사 문구 top / bottom
- 30일 이벤트 카드 top / bottom / height
- 상태 말풍선 top / bottom
- 미션 카드 top / bottom / height
- 놀이 카드 top / bottom / height
- 각 영역 사이 gap

수정 후 동일 값을 다시 측정하여 비교한다.

## 14. 완료 조건

다음 조건을 모두 만족해야 한다.

- 왼쪽 현재 화면보다 오른쪽 목표 화면과 시각적으로 훨씬 가까워짐
- 이벤트 카드 높이가 명확하게 감소
- 이벤트 카드 하단 정보가 2열로 표시
- 상태 말풍선이 이벤트 카드와 가까워짐
- 미션 카드가 위로 이동하고 컴팩트해짐
- 놀이 카드가 위로 올라옴
- 마스코트·인사 영역의 과도한 높이가 줄어듦
- 기능·데이터 로직 회귀 없음
- iPhone/Android에서 레이아웃 깨짐 없음
