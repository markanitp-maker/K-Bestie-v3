# BUG: 자녀 프로필 수정 시 성·이름 데이터 미표시

- 상태: TODO
- 유형: BUG FIX
- 우선순위: HIGH
- 대상: 부모 설정 페이지 > 아이 정보 관리 > 자녀 프로필 수정

## 문제 현상

부모 화면에서:

1. 부모 로그인
2. 설정 페이지 이동
3. 아이 정보 관리 선택
4. 기존 등록된 아이의 프로필 수정 버튼 클릭

시 자녀 프로필 수정 모달이 열리지만 기존 저장된 아이의 "성"과 "이름" 값이 입력 필드에 표시되지 않는다.

현재 화면:
- 성 입력창: 빈값
- 이름 입력창: 빈값

정상 동작:
- 기존 아이 정보가 자동으로 입력되어 있어야 한다.
- 사용자는 필요한 항목만 수정할 수 있어야 한다.

## 재현 환경

화면:
- 부모 설정 페이지

기능:
- 아이 정보 관리
- 자녀 프로필 수정

환경:
- Production / Preview / Dev 동일 여부 확인 필요

## 예상 원인 확인 필요

다음 항목을 우선 확인한다.

1. 수정 모달 오픈 시 기존 child profile 데이터를 API 또는 state에서 정상 조회하는지 확인
2. 조회 데이터의 필드명과 입력 컴포넌트 mapping 확인

예:
DB:
- first_name
- last_name

Frontend:
- childName
- childSurname

등 필드명 불일치 여부 확인

3. 신규 아이 추가 화면과 수정 화면에서 사용하는 데이터 구조가 동일한지 확인
4. 수정 모달 초기 state 생성 시 기존 데이터를 덮어쓰는 초기화 코드 존재 여부 확인
5. React useEffect dependency 문제로 데이터 반영 전에 빈 state가 렌더링되는지 확인

## 수정 요구사항

- 수정 모달 진입 즉시 기존 아이의 성과 이름을 표시한다.
- 기존 학년, 관심사, 요금제 등 현재 정상 동작하는 값은 회귀하지 않는다.
- 저장하지 않고 취소하면 기존 데이터 변경 없이 종료된다.
- 성 또는 이름만 수정 후 저장 가능해야 한다.
- 신규 아이 추가 기능에는 영향이 없어야 한다.

## 검증 시나리오

### Case 1: 기존 아이 수정

1. 부모 로그인
2. 설정 > 아이 정보 관리 이동
3. 기존 아이 수정 클릭
4. 성/이름 표시 확인
5. 저장 없이 취소
6. 기존 데이터 유지 확인

### Case 2: 이름 변경

1. 기존 아이 수정 진입
2. 이름 변경
3. 저장
4. 다시 수정 화면 진입
5. 변경된 이름 표시 확인

### Case 3: 관심사/학년 회귀 확인

1. 기존 아이 수정
2. 성/이름 외 다른 항목 변경
3. 저장
4. 모든 값 정상 저장 확인

### Case 4: 신규 아이 추가

1. 아이 추가 화면 진입
2. 빈 입력 상태 정상 확인
3. 신규 아이 생성 정상 확인

## 완료 조건

- 기존 아이 수정 모달에서 성·이름 자동 표시
- 저장 및 수정 정상 동작
- 신규 아이 추가 회귀 없음
- 부모 설정 화면 기존 기능 정상
- TypeScript 검사 통과
- 테스트 통과
- Preview 검증 완료
