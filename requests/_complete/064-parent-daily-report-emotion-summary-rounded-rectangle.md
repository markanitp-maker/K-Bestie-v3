# 064 — 부모 일일 리포트 감정 요약 박스 형태 개선

## 1. 작업 목적

부모 일일 리포트 카드 안의 감정 요약 영역이 현재 지나치게 둥근 pill/원형 형태로 보인다.

이번 작업에서는 해당 영역의 기능이나 데이터는 그대로 유지하고, 시각적 형태만 부모가 읽기 쉬운 **가로로 넓은 둥근 사각형 카드** 형태로 변경한다.

이번 작업 범위는 감정 요약 박스 UI에 한정한다.

---

## 2. 현재 문제

현재 감정 요약 영역은 다음과 같은 형태다.

- 좌우 끝이 지나치게 둥글다.
- 전체적으로 pill 또는 말풍선처럼 보인다.
- 같은 폭을 사용하더라도 실제 텍스트가 들어갈 수 있는 내부 면적이 작다.
- 텍스트 줄바꿈이 많아진다.
- 부모 리포트의 정보 카드라기보다 작은 상태 배지처럼 보인다.

---

## 3. 목표 형태

현재 pill형 박스를 **둥근 사각형(rounded rectangle)** 형태로 변경한다.

완전히 각진 사각형은 아니다.

적당한 radius를 가진 넓은 요약 카드처럼 보여야 한다.

---

## 4. 구체적 UI 변경

### 4.1 Border Radius

현재처럼 `rounded-full`, 매우 큰 radius, pill 형태를 사용하지 않는다.

권장 시작값:

```css
border-radius: 14px ~ 18px;
```

Tailwind 기준 예:

```text
rounded-[16px]
```

실제 기존 디자인 시스템과 맞는 값을 사용한다.

### 4.2 박스 폭

현재보다 카드 내부 가로 공간을 더 넓게 사용한다.

원칙:

- 부모 리포트 카드의 좌측 패딩 이후부터
- 우측 점수(`1점`, `4점` 등) 영역 바로 전까지
- 가능한 가로폭을 최대한 사용

권장 구조:

```text
[ 감정 요약 박스 flex-1 ] [ 점수 ]
```

감정 요약 박스에는:

```css
flex: 1;
min-width: 0;
```

를 적용하여 부모 카드 안에서 자연스럽게 확장되게 한다.

고정 width를 불필요하게 사용하지 않는다.

### 4.3 박스 높이

고정 height를 만들지 않는다.

텍스트 내용에 따라 자동으로 높이가 늘어나야 한다.

```css
height: auto;
```

권장 시작값:

```text
padding-x: 14~16px
padding-y: 10~12px
```

### 4.4 내부 텍스트

기존 데이터와 문구는 변경하지 않는다.

조건:

- 텍스트 잘림 금지
- ellipsis 금지
- 내부 스크롤 금지
- 한글 줄바꿈 정상
- 박스 폭보다 긴 텍스트가 부모를 밀어내지 않도록 `min-width:0` 적용

### 4.5 왼쪽 상태 점

현재 감정 요약 앞에 표시되는 파란색 원형 점/상태 아이콘이 있다면 유지한다.

단:

- 둥근 사각형 박스 안에서 자연스럽게 정렬
- 텍스트와 수직 중앙 또는 첫 줄 기준 정렬
- 박스 모양을 다시 pill처럼 보이게 만드는 과도한 여백 금지

### 4.6 오른쪽 점수

현재 오른쪽의 `1점`, `4점` 등 점수 표시는 유지한다.

요구사항:

- 감정 요약 박스 바깥 오른쪽에 유지
- 박스와 적절한 gap 확보
- 세로 중앙 정렬 또는 내용 높이에 맞는 자연스러운 정렬
- 점수가 박스 내부로 들어가거나 겹치지 않게 한다.

권장 구조:

```tsx
<div className="flex items-center gap-2">
  <div className="flex-1 min-w-0 rounded-[16px] ...">
    ...
  </div>
  <div className="shrink-0">
    1점
  </div>
</div>
```

실제 컴포넌트 구조에 맞게 적용한다.

---

## 5. 변경하지 않을 것

이번 작업에서 다음은 변경하지 않는다.

- 날짜 영역
- 카드 전체 디자인
- 리포트 본문
- `자세히 보기`
- 일간/주간 탭
- 점수 계산
- 감정 데이터
- 리포트 API
- DB
- 리포트 생성 로직
- 부모 하단 네비게이션

오직 **감정 요약 박스의 형태와 내부 공간 사용 방식**만 변경한다.

---

## 6. 구현 전 확인

코드 수정 전에 다음을 확인한다.

1. 부모 일일 리포트 카드 실제 컴포넌트
2. 감정 요약 박스에 적용된 현재 className
3. 현재 `rounded-full`, 큰 border-radius 또는 pill 스타일 적용 여부
4. 박스 width/max-width
5. 점수 영역과의 Flex/Grid 관계
6. 작은 화면에서 줄바꿈되는 실제 원인

확인 후 최소 수정으로 처리한다.

---

## 7. QA 기준

### 1점 카드
- 감정 요약 박스가 둥근 사각형으로 보임
- pill 형태로 보이지 않음
- 점수와 겹치지 않음

### 4점 카드
- 문장이 길어도 박스 높이가 자연스럽게 늘어남
- 가로폭을 충분히 사용
- 텍스트 잘림 없음

### 긴 문장
- 내부 스크롤 없음
- 말줄임 없음
- 카드 바깥으로 넘치지 않음

### 모바일
- iPhone 390×844
- Android 360×800
- Android 412×915

가로 스크롤이나 우측 잘림이 없어야 한다.
