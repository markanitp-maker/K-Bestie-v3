# REQUEST #093 — 회원가입 3/4 가족 만들기·기존 가족 참여 통합

- 상태: IN_PROGRESS
- 우선순위: P0 긴급
- 대상: 신규 보호자 회원가입 3/4 가족 단계, 가족 소속 판정·회원가입 라우팅

## 목표

회원가입 3/4 한 화면에 `가족 만들기`와 `가족 구성원으로 참여하기`를 함께 제공한다.

## 필수 요구사항

1. 가족 만들기 선택 시 현재 보호자를 `owner_parent`로 하는 새 가족을 기존 방식대로 멱등 생성하고 4/4 최초 아이 등록으로 이동한다.
2. 가족 참여 선택 시 새 family·child를 만들지 않고 기존 초대·참여·가족코드·초대링크·승인요청 구현을 우선 재사용한다.
3. 참여 성공 시 기존 `family_members`에 정상 보호자 역할로 연결하고 기존 아이·리포트·가족 데이터를 공유한다.
4. 기존 가족 참여 보호자는 아이 등록을 강제하지 않고 회원가입 완료 후 보호자 홈으로 이동한다.
5. `membershipState`와 라우팅은 `owner_parent`뿐 아니라 정상 보호자 `family_members` 연결도 유효한 가족 소속으로 판정한다.
6. 탈퇴 복구 우선순위, OAuth, 약관, 기존 가족 생성 멱등성, 기존 아이 등록 플로우는 변경하지 않는다.
7. 회원가입 3/4 한 화면에 위쪽 가족 만들기, 아래쪽 가족 구성원으로 참여하기 UI를 기존 디자인 톤으로 제공한다.

## 검증

- A: 첫 보호자 가족 만들기 → 아이 등록 → 보호자 홈
- B: 두 번째 보호자 가족 참여 → 기존 가족 연결 → 새 family 0·새 child 0 → 보호자 홈
- C: 두 보호자가 동일 가족·동일 아이 조회
