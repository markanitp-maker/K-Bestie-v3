미션/대화 화면에 떠 있는 좌측 하단 플로팅 버튼 "케이 챗봇"의 위치와 라벨을 수정하라. 현재 좌측 하단에 있는 플로팅 진입 버튼을 제거하고, 첨부 이미지의 우측 상단 빨간 박스 영역(상단 헤더 우측, 진행 표시 영역 쪽)으로 이동시켜라. 버튼 라벨은 "케이 챗봇"이 아니라 "문의"로 변경한다. 기존 문의하기/건의하기/버그 신고 모달 기능과 동작은 그대로 유지하고, 모바일에서 헤더/진행바/기존 아이콘과 겹치지 않게 배치하며, 태블릿/PC에서도 동일한 의미의 우측 상단 위치로 반응형 정렬되게 수정하라. 수정 후 미션 화면과 대화 화면 기준 전/후 스크린샷과 변경 파일 목록을 보고하라.

현재 놀이 연동 구조를 수정한다. 퀴즈마스터는 메인 앱 내부 컴포넌트로 포팅하지 않는다. 독립 Vercel 앱으로 유지한다. K-Bestie 메인 앱에서는 기존 MBTI와 동일하게 PlayModal/iframe 방식으로 호출하도록 변경한다. 현재 카드 클릭 시 외부 URL 전체 이동하는 구조를 제거하고, 놀이 선택 → 황금열쇠 확인 → 전체 화면 모달 → iframe 로딩 → callback 처리 구조로 변경한다. MBTI 구현 방식을 먼저 분석하고 동일 패턴으로 퀴즈마스터 연결만 추가한다.
