# 관리자 리포팅 수동 실행 결과의 아이 표시값 개선

## 1. 목적
관리자 `리포팅 수동 실행`의 V3 처리 결과에서 내부 UUID인 `child_id`를 그대로 표시하지 않고 `아이 이름 (로그인 아이디)` 형식으로 표시한다.

예:
- 안서아 (asa@kbestie.local)
- TestA (testa@kbestie.local)
- 박서둥 (psd160202@kbestie.local)

## 2. 표시 규칙
1. 이름과 로그인 아이디가 모두 있으면 `아이 이름 (로그인 아이디)`
2. 이름만 있으면 `아이 이름`
3. 로그인 아이디만 있으면 `로그인 아이디`
4. 둘 다 없을 때만 `e74a4ed1...`처럼 마스킹 UUID

전체 UUID는 기본 화면에 노출하지 않는다.

## 3. 변경 대상
`리포팅 수동 실행 → 실행 결과 → V3 처리 상태`

기존 컬럼명 `아이 ID`를 `아이`로 변경한다.

## 4. 적용 범위
다음 모든 결과 행에 동일하게 적용한다.
- 특정 아이 1명 실행
- 전체 아이 실행
- 즉시 대화 수집
- 즉시 리포트 생성
- 수집 후 리포트 즉시 생성
- 성공
- 실패
- 건너뜀
- 이미 완료됨
- RETRYABLE_ERROR
- PERMANENT_ERROR

## 5. 서버 조회 방식
결과 API 또는 Server Action에서 `child_id`를 기준으로 아이 프로필과 아이 로그인 계정 정보를 조인한다.

확인 대상:
- `child_profiles`
- 아이 로그인 계정 테이블
- `auth.users`
- 가족 연결 테이블
- 기존 관리자 아이 목록 조회 로직

권장 응답 필드:
```text
childId
childName
loginId
maskedChildId
```

클라이언트에서 전체 아이 목록을 다시 받아 수동 조인하지 않는다.

## 6. 로그인 아이디 기준
아이의 실제 로그인 계정 값을 표시한다. 부모 이메일, 표시명, 내부 UUID와 혼동하지 않는다.

## 7. 예외 처리
- 아이 프로필 없음: 로그인 아이디만 표시
- 로그인 아이디 없음: 이름만 표시
- 둘 다 없음: 마스킹 UUID
- 삭제·비활성 아이: 기존 이력을 유지하고 가능하면 `삭제된 아이 (e74a4ed1...)`로 표시
- 중복 이름: 로그인 아이디로 구분

## 8. 보안
- 전체 UUID 기본 화면 미노출
- Service Role Key 클라이언트 노출 금지
- 관리자 권한 서버 검증
- 일반 부모·아이 접근 차단
- API Key, DB 비밀번호, Token 로그 출력 금지

## 9. UI 요구사항
- 컬럼명: `아이`
- 셀 표시: `안서아 (asa@kbestie.local)`
- 좁은 화면에서는 이름 우선, 로그인 아이디 줄바꿈 또는 말줄임 허용
- 전체 UUID는 tooltip에도 표시하지 않는 것을 기본값으로 한다
- PC와 모바일 모두 레이아웃 정상

## 11. 테스트

### 전체 아이

- 성공·실패·건너뜀 모두 동일 적용

- 둘 다 없는 경우

### 권한

- 일반 부모 접근 차단
- 아이 접근 차단

- UUID를 계속 기본값으로 표시하지 않는다
- 클라이언트에서 별도 전체 목록 수동 조인 금지
- 부모 로그인 아이디 표시 금지
- 이름만으로 식별 금지
- 실제 파이프라인 로직 변경 금지
- Dev만 수정하고 Production 누락 금지
