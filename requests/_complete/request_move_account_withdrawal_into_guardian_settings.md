# 부모 설정 회원 탈퇴 메뉴 위치 변경

## 1. 작업 목적
부모 설정 화면에서 독립 카드로 노출되는 `회원 탈퇴` 기능을 제거하고, `보호자 설정` 메뉴 내부 최하단의 위험 작업 영역으로 이동한다.

회원 탈퇴는 사용 빈도가 낮고 비가역적인 기능이므로 설정 메인 화면에 크게 노출하지 않는다. 사용자가 보호자 설정을 직접 펼친 경우에만 접근할 수 있도록 하여 실수 클릭 가능성을 낮춘다.

## 2. 확정 변경안

### 설정 메인 화면
유지:
- 아이 정보 관리
- 보호자 설정
- 앱 설치하기
- 로그아웃
- 기타 기존 일반 설정

제거:
```text
회원 탈퇴
계정과 모든 데이터를 삭제합니다
```

### 보호자 설정 내부
권장 순서:
1. 내 이름 수정
2. 알림 환경 설정
3. 가족 구성원 보호자
4. 구분선
5. 위험 작업
6. 회원 탈퇴

기본 상태에서는 보호자 설정이 접혀 있으므로 회원 탈퇴가 보이지 않아야 한다.

## 3. UI 구조

```tsx
<GuardianSettingsAccordion>
  <NameSettings />
  <NotificationSettings />
  <FamilyGuardianSettings />
  <Divider />
  <DangerZone>
    <AccountWithdrawalItem />
  </DangerZone>
</GuardianSettingsAccordion>
```

회원 탈퇴 항목 예시:

```text
회원 탈퇴
계정과 관련 데이터를 삭제합니다                         >
```

요구사항:
- 일반 설정보다 시각적 강조를 낮춤
- red 계열 텍스트 또는 경고 아이콘 유지
- 큰 빨간 카드나 대형 버튼 사용 금지
- 보호자 설정 내부의 컴팩트한 하위 항목 형태
- 위험 작업 영역 상단에 구분선 적용
- 최소 터치 영역 44px 이상 권장

## 4. 기존 탈퇴 기능 유지
이번 작업은 위치와 노출 방식만 변경한다.

다음은 변경하지 않는다.
- 탈퇴 API
- 본인 확인 절차
- 비밀번호 재확인
- 최종 확인 모달
- 탈퇴 경고 문구
- 데이터 삭제 정책
- soft-delete 30일 정책
- 복구 가능 기간
- 최종 삭제 처리
- 연결된 아이 및 가족 데이터 처리
- 결제·구독 해지 처리
- 로그아웃 및 세션 종료
- 관리자 탈퇴 계정 표시 정책

회원 탈퇴 항목을 클릭했다고 즉시 탈퇴 처리하면 안 된다. 기존 최종 확인 절차를 그대로 유지한다.

## 5. 로그아웃
로그아웃은 현재처럼 설정 메인 화면 하단에 유지한다.

- 로그아웃: 일반 세션 종료
- 회원 탈퇴: 보호자 설정 내부 위험 작업
- 두 기능을 같은 위치나 같은 강조도로 배치하지 않음
- 회원 탈퇴 카드 제거 후 생기는 여백은 자연스럽게 정리

## 6. 반응형 요구사항

### 모바일
- 보호자 설정 기본 접힘
- 펼친 경우 회원 탈퇴가 최하단에 표시
- 하단 네비게이션과 겹치지 않음
- 텍스트 잘림 없음

### 태블릿
- 현재 보호자 설정 레이아웃 유지
- 위험 작업 영역이 전체 폭의 대형 카드처럼 보이지 않음

### PC
- 설정 메인 화면에 회원 탈퇴 독립 노출 없음
- 보호자 설정 내부 폭에 맞춰 정렬

## 7. 접근성
- 키보드 포커스 가능
- 스크린리더 라벨 제공
- 색상만으로 위험도 전달하지 않음
- focus style 유지
- 확인 모달의 포커스 트랩과 ESC 처리 유지

## 8. 구현 제한
다음 작업은 하지 않는다.
- 회원 탈퇴 API 재작성
- 데이터 삭제 정책 변경
- soft-delete 기간 변경
- 결제 환불 정책 변경
- 가족 데이터 삭제 범위 변경
- 보호자 설정 전체 리디자인
- 로그아웃 위치 변경
- 회원 탈퇴 기능 삭제
- 관리자 탈퇴 계정 관리 기능 변경

## 9. 점검 대상 파일
실제 프로젝트 구조를 확인한 뒤 다음 후보를 중심으로 작업한다.

```text
app/parent/settings/page.tsx
components/parent/settings/*
components/settings/*
```

검색 키워드:
```text
회원 탈퇴
계정과 모든 데이터를 삭제합니다
보호자 설정
로그아웃
```

현재 회원 탈퇴 컴포넌트가 별도 파일이면 재사용하고 위치만 이동한다.
