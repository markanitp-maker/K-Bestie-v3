# 066 — 미션 대화 우선순위 표시 및 별 진행률 위치 미세 조정

## 1. 작업 목적

현재 미션 대화 화면에서 다음 두 가지 UI 문제를 수정한다.

1. 현재 발화가 길어졌을 때 이전 발화 말풍선이 겹치거나 일부 잘린 상태로 남는 문제
2. 상단 별 진행률 바가 헤더에 너무 붙어 위쪽 일부가 잘려 보이는 문제

이번 작업은 미션 화면의 표시 우선순위와 세로 배치만 조정한다.

기존 미션 기능, 질문 로직, 음성 처리, 마스코트, 자동/수동, 마이크, 키보드, 진행률 계산 로직은 변경하지 않는다.

---

## 2. 대화 표시 우선순위 확정

미션 화면에서 케이 발화는 최대 3개까지 표시할 수 있다.

표시 우선순위는 아래와 같이 고정한다.

```text
1순위: 현재 발화
2순위: 지난 발화
3순위: 지지난 발화
```

### 2.1 현재 발화

- 항상 전체 내용을 표시한다.
- 말풍선 내부 스크롤 금지
- ellipsis 금지
- 텍스트 잘림 금지
- 현재 발화가 길어지면 아래로 케이 영역을 밀어내지 않고 위쪽 히스토리 공간을 먼저 사용한다.

### 2.2 지난 발화

현재 발화 다음으로 중요하다.

- 현재 발화 표시 후 남은 대화 영역을 사용한다.
- 공간이 충분하면 전체 표시
- 공간이 부족하면 표시 가능한 범위만 사용하거나, 현재 UI 정책에 맞게 축약/숨김 처리
- 절대로 현재 발화 뒤에 겹쳐서 일부만 보이는 상태로 남기지 않는다.
- 말풍선 하단이 현재 발화 말풍선 뒤에 가려지는 상태 금지

### 2.3 지지난 발화

가장 낮은 우선순위다.

- 현재 발화 + 지난 발화를 표시한 뒤 공간이 남을 때만 표시
- 공간이 부족하면 완전히 숨김
- 지지난 발화를 유지하기 위해 현재/지난 발화를 압축하지 않는다.

---

## 3. 표시 시나리오

### 케이스 A — 현재 발화가 짧음

```text
지지난 발화
지난 발화
현재 발화
```

3개 모두 표시

### 케이스 B — 현재 발화가 중간 길이

```text
지난 발화
현재 발화
```

지지난 발화 숨김

### 케이스 C — 현재 발화가 매우 김

```text
현재 발화
```

또는 남는 공간이 충분할 경우:

```text
지난 발화 일부/전체
현재 발화
```

현재 발화는 항상 전체 표시한다.

---

## 4. 레이아웃 원칙

대화 영역은 케이 마스코트 상단과 명확히 분리한다.

목표 구조:

```text
상단 헤더
↓
별 진행률
↓
최소 여백
↓
지지난 발화 — 공간 있을 때만
지난 발화 — 현재 발화 다음 우선
현재 발화 — 항상 전체
↓
약 16~24px
↓
케이 마스코트
```

### 금지

- 이전 발화와 현재 발화 겹침
- 현재 발화와 마스코트 겹침
- 이전 말풍선 일부만 가려진 상태
- 말풍선 내부 세로 스크롤
- 현재 발화 잘림
- 과거 발화를 유지하기 위해 하단 조작 UI를 밀어내는 구조

---

## 5. 구현 방향

현재 대화 영역의 실제 높이를 기준으로 표시 가능 여부를 결정한다.

권장 방식:

1. 현재 발화를 먼저 렌더링하고 실제 높이 확보
2. 남은 높이에 지난 발화가 들어가는지 판단
3. 추가 공간이 남으면 지지난 발화 표시
4. 공간이 부족하면 오래된 발화부터 제거

단순 CSS `overflow:hidden`으로 말풍선을 잘라내는 방식은 금지한다.

가능하면 React 렌더링 단계에서 표시 개수를 결정한다.

기존 최근 케이 발화 추출 로직은 유지한다.

---

## 6. 현재 발화와 마스코트 사이 간격

현재 발화 말풍선 꼬리 하단과 케이 마스코트 머리 상단 사이에 안정적인 간격을 유지한다.

목표:

```text
16~24px
```

현재 발화가 길어져도 이 최소 간격을 침범하지 않아야 한다.

공간 확보는 오래된 히스토리를 제거하여 처리한다.

마스코트 위치와 크기는 이번 작업에서 변경하지 않는다.

---

## 7. 별 진행률 바 위치 미세 조정

현재 별 진행률 컨테이너가 상단 헤더에 너무 붙어 있어 위쪽 둥근 모서리/그림자 영역이 일부 잘려 보인다.

진행률 UI 자체의 디자인은 정상이며, 이번 작업에서는 **위치만 아주 조금 아래로 이동**한다.

### 변경 요구사항

- 진행률 컨테이너 전체를 현재보다 약 `6~8px` 아래로 이동
- 별 크기 변경 금지
- 진행률 컨테이너 높이 변경 금지
- 진행률 컨테이너 폭 변경 금지
- 별 간격 변경 금지
- 진행률 개수 변경 금지
- 진행률 계산 로직 변경 금지

즉:

```text
현재 위치 + 6~8px Y offset
```

수준의 미세 조정만 한다.

---

## 8. 진행률 바 하단 여백

진행률 바를 6~8px 내린 뒤에도 그 아래에 불필요한 큰 빈 공간을 만들면 안 된다.

진행률 바 하단과 첫 번째 대화 히스토리 시작점 사이에는 자연스러운 최소 간격만 둔다.

권장:

```text
약 12~20px
```

진행률 바를 내린 만큼 대화 영역 전체가 그대로 아래로 밀리지 않도록 전체 세로 배치를 다시 계산한다.

## 11. QA 시나리오

### 11.1 짧은 현재 발화

- 지지난 + 지난 + 현재 모두 표시
- 서로 겹치지 않음
- 마스코트와 현재 발화 사이 간격 정상

### 11.2 중간 길이 현재 발화

- 지지난 발화 숨김 가능
- 지난 + 현재 표시
- 이전 말풍선이 현재 말풍선 뒤에 가려지지 않음

### 11.3 긴 현재 발화

- 현재 발화 전체 표시
- 지난 발화는 공간이 허용될 때만 표시
- 지지난 발화는 숨김
- 마스코트와 겹치지 않음

### 11.4 별 진행률

- 상단이 잘리지 않음
- 기존보다 약 6~8px 아래
- 별 크기/폭/높이 동일
- 헤더와 자연스러운 간격
- 진행률 아래 불필요한 빈 공간 없음
