퀴즈마스터 연동 작업을 시작하라. 현재 놀이 화면의 퀴즈마스터 버튼 클릭부터 실제 실행까지 연결해야 한다. 클릭 시 메인 앱에서 아이의 황금열쇠 보유량을 확인하고 1개 소비 거래를 생성한 뒤 reward_transaction_id를 발급하고 child_id와 실제 grade(1~6)를 포함한 quiz_handoff_tokens를 생성하라. 생성 성공 후 퀴즈마스터 실행 URL로 이동시키고, grade가 없는 경우 임의값으로 처리하지 말고 오류 처리하라. 퀴즈마스터 완료 callback(/api/quiz/completion)과 환불 callback(/api/rewards/golden-key/refund)을 연결하고, 오류 발생 시 버그 신고 후 황금열쇠 환불이 가능하도록 구현하라. 먼저 현재 메인 앱의 놀이 화면, 황금열쇠 관리 코드, child profile schema, reward transaction 구조를 분석한 뒤 기존 구현과 충돌하지 않는 방식으로 개발하라.
