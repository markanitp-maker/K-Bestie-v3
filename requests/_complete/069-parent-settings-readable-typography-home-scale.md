# 068 — 부모 설정 화면 타이포그래피·아이콘 크기 확대 및 홈 화면 가독성 기준 통일

## 1. 작업 목적

현재 부모 설정 화면은 카드 구조와 기능 자체는 적절하지만, 제목·설명·상태·아이콘이 전체적으로 너무 작아 부모가 모바일에서 읽기 어렵다.

이번 작업의 목적은 **설정 화면의 구조와 기능은 그대로 유지하면서, 글씨와 아이콘 크기만 부모 홈 화면의 인사이트 카드 수준으로 키워 가독성을 통일**하는 것이다.

핵심 원칙:

> 카드 높이와 불필요한 여백을 크게 늘리지 않고, 글씨와 아이콘만 홈 화면 수준으로 명확하게 키운다.

---

## 2. 적용 대상

부모 설정 화면의 다음 영역 전체에 적용한다.

- 아이 추가
- 아이 승인 요청 현황
- 아이 이름 / 학년
- 승인 완료 / 승인 대기 / 거절 등 상태 배지
- 아이 정보 관리
- 보호자 설정
- 설치됨 / PWA 관련 상태
- 로그아웃
- 각 카드의 보조 설명
- 좌측 아이콘
- 우측 화살표/상태 표시

하단 네비게이션은 현재 부모 공통 네비게이션 크기를 그대로 유지한다.

---

## 3. 목표 디자인 기준

설정 화면의 타이포그래피 스케일을 부모 홈 화면의 8개 인사이트 카드와 동일한 수준으로 맞춘다.

### 제목

홈 화면 카드 제목과 동일한 가독성 수준으로 확대한다.

권장 시작값:

```text
font-size: 16~18px
font-weight: 700
line-height: 1.3~1.4
```

### 설명

홈 화면 카드 설명과 동일한 수준으로 확대한다.

권장 시작값:

```text
font-size: 13~15px
font-weight: 400~500
line-height: 1.4~1.5
```

### 상태 / 아이 이름 / 학년

예:

```text
안서현 · 4학년
승인 완료
```

권장:

```text
font-size: 14~16px
font-weight: 600~700
```

상태 배지는 현재 색상 체계를 유지하되 글씨와 padding을 읽기 쉬운 수준으로 확대한다.

---

## 4. 아이콘 크기

설정 화면 각 카드의 좌측 아이콘이 현재 너무 작으므로 부모 홈 카드의 아이콘 크기 수준으로 확대한다.

적용 대상 예:

- + 아이 추가
- 아이 정보 관리
- 보호자 설정
- 설치됨
- 기타 설정 아이콘

권장:

```text
현재 대비 약 20~30% 확대
```

아이콘 컨테이너도 필요 시 같이 확대하되, 카드 높이가 과도하게 커지지 않도록 한다.

---

## 5. 우측 화살표 및 보조 UI

현재 카드 우측의 `>` 화살표, 상태 표시, 기타 보조 UI도 너무 작지 않게 조정한다.

권장:

- 화살표 icon size 소폭 확대
- 상태 badge font-size 확대
- touch target 최소 44px 수준 확보

단, 시각적 우선순위는 카드 제목보다 낮게 유지한다.

---

## 6. 카드 높이 및 여백 정책

이번 작업에서 중요한 점은 **글씨를 키운다고 카드 높이와 여백까지 과도하게 키우지 않는 것**이다.

유지 원칙:

- 현재 카드 폭 유지
- 현재 카드 간 간격 유지 또는 최소 조정
- 상하 padding은 글씨가 잘리지 않는 범위에서만 보정
- 불필요한 `min-height` 증가 금지
- 큰 `py-*` 추가 금지
- 카드가 화면을 과도하게 밀어내지 않게 한다

목표:

> 홈 화면처럼 큼직하게 읽히되, 설정 항목도 모바일 한 화면에 최대한 많이 보이게 한다.

---

## 7. `아이 승인 요청 현황` 영역

이 영역은 일반 카드보다 정보량이 많으므로 다음 요소를 각각 확대한다.

- 섹션 제목 `아이 승인 요청 현황`
- 아이 이름
- 학년
- 상태 배지

예:

```text
아이 승인 요청 현황

안서현 · 4학년              승인 완료
안서현 · 4학년              승인 완료
```

요구사항:

- 이름/학년을 쉽게 읽을 수 있어야 함
- 상태 배지의 글씨도 읽기 쉬워야 함
- 행 높이는 내용에 맞게 최소한만 증가
- 항목 간 간격은 명확하지만 과도하지 않게 유지

---

## 8. `설치됨` 영역

현재:

```text
설치됨
이미 앱으로 이용 중이에요
```

구조는 그대로 유지한다.

변경:

- `설치됨` 제목 확대
- 설명 문구 확대
- 아이콘 확대

기능이나 PWA 상태 판정 로직은 변경하지 않는다.

---

## 9. 로그아웃

로그아웃 버튼은 현재 기능과 색상을 유지한다.

단, 글씨가 너무 작다면 부모 홈 타이포그래피 기준에 맞게 소폭 확대한다.

로그아웃 동작, 세션 삭제, confirm 정책은 변경하지 않는다.

---

## 10. 변경 금지

이번 작업에서 다음은 변경하지 않는다.

- 설정 화면 메뉴 순서
- 아이 추가 기능
- 승인 요청 로직
- 아이 정보 관리 기능
- 보호자 설정 기능
- PWA 설치 상태 로직
- 로그아웃 기능
- DB
- API
- 인증
- 라우팅
- 부모 하단 네비게이션 구조
- 카드 데이터

이번 작업은 **설정 화면의 타이포그래피와 아이콘 크기 통일**이 목적이다.

---

## 11. 구현 전 확인

코드 수정 전에 다음을 확인한다.

1. 부모 설정 화면 실제 파일
2. 부모 홈 인사이트 카드의 현재 title font-size
3. 부모 홈 인사이트 카드의 현재 description font-size
4. 부모 홈 카드 icon size
5. 설정 카드 title font-size
6. 설정 카드 description font-size
7. 설정 카드 icon size
8. 설정 카드 padding / min-height
9. 승인 요청 행의 font-size와 height
10. 하단 nav 공통 컴포넌트 여부

부모 홈의 실제 현재 CSS 값을 기준으로 설정 화면의 목표값을 잡는다.

추측값만으로 적용하지 않는다.

## 12. QA 기준

### 가독성

- [ ] `아이 추가` 제목이 홈 카드 제목 수준으로 읽힘
- [ ] 설명 문구가 홈 카드 설명 수준으로 읽힘
- [ ] 승인 요청 아이 이름/학년이 명확하게 읽힘
- [ ] 상태 배지가 쉽게 읽힘
- [ ] `아이 정보 관리`, `보호자 설정`, `설치됨` 제목이 충분히 큼
- [ ] 좌측 아이콘이 홈 화면 수준으로 커짐

### 밀도

- [ ] 글씨를 키웠지만 카드 높이가 과도하게 커지지 않음
- [ ] 불필요한 여백이 증가하지 않음
- [ ] 모바일 한 화면에 기존과 비슷한 수의 메뉴가 보임
- [ ] 세로 스크롤량이 불필요하게 증가하지 않음

### 기능

- [ ] 아이 추가 정상
- [ ] 승인 요청 조회 정상
- [ ] 아이 정보 관리 이동 정상
- [ ] 보호자 설정 이동 정상
- [ ] 설치 상태 표시 정상
