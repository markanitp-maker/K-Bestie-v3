대표님, 이해했습니다. 현재 문제는 상태 배지 위치를 고정하지 않고 전체 그룹을 가운데 정렬하면서 발생하는 레이아웃 이동(layout shift) 입니다.
현재 구조:
[상태 배지] + [케이 마스코트] + [자동/수동]
        ↓
전체 flex row 중앙 정렬
        ↓
"생각하는 중..." / "말하는 중..." / "듣는 중" 글자 길이 변경
        ↓
전체 폭 변경
        ↓
케이와 자동/수동 버튼 위치 이동
이 구조라서 아이 입장에서는 케이 캐릭터가 계속 좌우로 움직이는 것처럼 보입니다.
수정 방향은 아래가 맞습니다.
[Claude Code]
음성 대화 하단 컨트롤 영역의 레이아웃 이동 문제를 수정하라. 현재 상태 배지(말하는 중/듣는 중/생각하는 중)의 텍스트 길이에 따라 전체 flex 영역 width가 변경되면서 케이 마스코트와 자동/수동 토글 버튼 위치가 계속 이동하는 문제가 발생한다. 아래 구조로 변경한다. 1) 하단 중앙 영역은 고정 3영역 구조로 변경한다. 전체 container는 position relative 또는 CSS grid를 사용한다. 2) 케이 마스코트는 항상 화면 정중앙 기준으로 고정한다. 상태 텍스트 길이에 영향을 받지 않도록 독립 영역으로 분리한다. 3) 자동/수동 토글 버튼은 케이 오른쪽 고정 위치에 배치한다. 버튼 width와 height를 고정하고 상태 변경으로 위치가 변경되지 않도록 한다. 4) 상태 배지는 케이 왼쪽 고정 위치에 배치한다. "듣는 중", "생각하는 중", "말하는 중" 텍스트 길이가 달라도 배지 영역 width를 고정하거나 min-width를 지정하여 주변 요소가 이동하지 않도록 한다. 5) 상태 배지 내부 텍스트와 아이콘만 fade transition으로 변경한다. 상태 변경 시 container 위치 이동은 절대 발생하지 않는다. 최종 레이아웃은 왼쪽 상태 배지 / 중앙 케이 마스코트 / 오른쪽 자동·수동 토글 구조로 고정한다. 예시: [상태 120px 고정] [케이 중앙 120px 고정] [토글 120px 고정]. 6) 스마트폰/태블릿 모두 동일하게 적용하고 기존 음성 상태 로직, STT/TTS, 미션 진행 로직은 변경하지 않는다. UI 레이어만 수정한다. 수정 완료 후 실제 상태 변경 테스트(듣는 중→생각하는 중→말하는 중)를 반복하면서 케이 위치와 토글 위치가 단 1px도 이동하지 않는지 확인하고 QA 로그에 결과를 기록한다.
