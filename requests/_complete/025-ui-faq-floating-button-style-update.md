# REQUEST #025 — FAQ 플로팅 버튼 UI 변경

- 상태: TODO
- 유형: UI 개선
- 우선순위: HIGH
- 개발 담당: Codex
- 대상: 아이 화면, 부모 화면 공통 FAQ 플로팅 버튼

---

## 0. 작업 목표

현재 화면 우측 하단의 FAQ 플로팅 버튼 UI를 브랜드 가이드에 맞게 단순화·정리한다.

변경 목표:

1. 버튼 내부의 `FAQ` 텍스트를 제거한다.
2. 말풍선 아이콘만 유지한다.
3. 버튼 배경색을 기존 네이비 계열에서 주황색 계열로 변경한다.
4. 브랜드 가이드라인의 주황 계열을 사용한다.
5. 기존 버튼의 기능, 위치, 클릭 동작에는 회귀가 없어야 한다.

---

## 1. 현재 문제

현재 FAQ 플로팅 버튼은:

- 말풍선 아이콘 + `FAQ` 텍스트 조합
- 네이비 계열 배경

문제점:

- 버튼 크기 대비 텍스트 비중이 커서 시각적으로 답답함
- 버튼이 다른 플로팅 요소와 함께 있을 때 시인성이 다소 무거움
- 브랜드 포인트 컬러(주황 계열) 반영이 부족함

---

## 2. 변경 요구사항

### 2.1 버튼 텍스트

현재:

```text
[말풍선 아이콘] FAQ
```

변경:

```text
[말풍선 아이콘]
```

요구사항:

- `FAQ` 텍스트 완전 제거
- 아이콘만 남긴다
- 아이콘 자체는 기존 말풍선 아이콘을 우선 재사용한다
- 아이콘 교체가 필요하면 기존 디자인 시스템 범위 내에서만 수정한다

---

### 2.2 배경색

현재:

- 네이비 계열 배경

변경:

- 주황색 계열 배경

요구사항:

- 내친구 케이 브랜드 가이드라인의 주황 계열 사용
- 임의의 새 색상 토큰을 만들지 말고 기존 브랜드 컬러를 재사용한다
- 가능하면 현재 프로젝트의 디자인 토큰/상수/테마에 정의된 주황색을 사용한다

브랜드 가이드 기준 확인 대상 예시:

- K-Orange
- K-Mascot Orange
- 기존 CTA 버튼에 사용 중인 오렌지 계열

정확한 컬러값은 현재 프로젝트의 브랜드 가이드 소스 기준으로 확인 후 적용한다.

---

## 3. 유지해야 하는 요소

다음은 변경하지 않는다.

- FAQ 버튼의 기능
- 클릭 시 이동/모달/FAQ 동작
- 버튼의 플로팅 동작
- 위치 정책
- safe-area 대응
- z-index 정책
- 접근성 속성
- 아이/부모 공통 노출 정책

즉, 이번 작업은 **기능 변경이 아니라 UI 스타일 변경**이다.

---

## 4. 디자인 요구사항

### 4.1 버튼 형태

- 현재 플로팅 버튼 스타일 유지
- 둥근 형태 유지
- 아이콘이 버튼 중앙에 자연스럽게 위치해야 함
- 텍스트 제거 후 버튼 크기가 지나치게 어색하지 않도록 패딩, 너비, 높이 재조정

### 4.2 아이콘 표시

- 아이콘만 단독으로 봐도 식별 가능해야 함
- 배경색과 충분한 대비 확보
- 아이콘 색상은 기존 흰색 또는 현재 대비가 가장 좋은 색을 사용
- 브랜드 가이드와 접근성 대비 기준을 해치지 말 것

### 4.3 사이즈

- 텍스트 제거 후 버튼이 너무 작아져 터치 영역이 줄어들면 안 됨
- 모바일 터치 영역은 충분히 유지
- 아이콘만 보여도 버튼 역할을 인지할 수 있어야 함

---

## 5. 접근성

텍스트를 제거하더라도 접근성은 유지해야 한다.

필수:

- `aria-label="FAQ"` 또는 동등한 접근성 라벨 유지
- 스크린리더에서 의미가 전달되어야 함
- 키보드 포커스 가능 상태 유지
- 포커스 스타일 제거 금지

---

## 6. 구현 원칙

- 기존 FAQ 버튼 컴포넌트를 재사용한다
- 관련 없는 스타일 리팩터링 금지
- 브랜드 컬러 토큰이 이미 있으면 그것을 사용한다
- 하드코딩 색상 추가는 최소화한다
- 아이/부모 화면 각각 별도 구현하지 말고 공통 컴포넌트 기준으로 수정한다

---

## 7. 확인 대상

Codex는 작업 전에 다음을 확인한다.

- FAQ 버튼이 공통 컴포넌트인지 화면별 개별 구현인지
- 현재 사용 중인 브랜드 색상 토큰
- 버튼 스타일이 Tailwind/className 기반인지 CSS module/styled system 기반인지
- 아이콘 소스가 SVG/아이콘 라이브러리/이미지인지
- 동일한 FAQ 버튼이 여러 군데 중복 구현되어 있는지

중복 구현이 있으면 한 곳만 수정하지 말고 실제 사용자 노출 경로 전체를 정리한다.
