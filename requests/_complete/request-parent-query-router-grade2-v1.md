# 부모 궁금증 처리 엔진 구현 요청 — 초등학교 2학년 v1.0

## 1. 작업 목적

부모가 케이에게 자유 입력으로 아이에 관한 질문을 남겼을 때, 해당 질문을 초등학교 2학년 발달 단계와 서비스 안전 원칙에 따라 `CRISIS`, `RED`, `GREEN`으로 분류하고, 허용된 질문만 부모 확인 후 아이 미션 대화에 편입하도록 구현한다.

이 문서는 **2학년 전용 명세**다. 현재 개발 중인 4학년 구현은 수정·재설계·롤백하지 않고 기준 인터페이스로 유지한다.

정책 식별값:

```text
policy_version: PQR-G2-1.0
source_grade: 2
applicable_grades: [2]
default_route: RED
production_enabled: false
expert_review_status: PENDING_REVIEW
```

## 2. 구현 불변식

1. 기본값은 `RED`다.
2. 판정 순서는 `CRISIS → RED → GREEN → DEFAULT_RED`로 고정한다.
3. 부모 문장을 아이에게 그대로 전달하지 않는다.
4. Green List에 명확히 매칭될 때만 아이 질문 대기열에 등록한다.
5. 애매한 입력은 Green으로 추정하지 않는다.
6. 아이가 “몰라”, “없어”, “말하기 싫어”, “넘어갈래”라고 하면 꼬리질문 없이 종료한다.
7. 부모 질문에서 파생된 답변은 반드시 재확인하고, 아이가 최종 확인한 내용만 부모에게 전달한다.
8. Crisis 감지·문구는 임상 검증 전 Production에서 활성화하지 않는다.
9. LLM 단독 Green 판정은 금지한다.
10. Green 승인 질문만 Q&A와 미션 질문 대기열에 등록한다.

## 3. 기존 제한 정책 통합

- 아이별 주 3회
- 아이별 하루 최대 1회
- KST 기준
- 주간 기준: 월요일 00:00:00 ~ 일요일 23:59:59
- 초안 모달 열기·취소·Red·Crisis·등록 실패는 차감하지 않음
- Green 질문 최종 승인 및 DB 저장 성공 시에만 차감
- 중복 클릭·네트워크 재시도에도 중복 등록·중복 차감 금지
- 세션당 부모 질문 최대 1개
- 아이 상태가 적절하지 않으면 해당 세션 삽입 생략 가능

## 4. 고정 판정 흐름

```text
부모 입력
→ 인증·부모-아이 권한 확인
→ 대상 아이 학년=2 확인
→ CRISIS 감지
→ RED 패턴·의미 매칭
→ GREEN 화이트리스트 매칭
→ Green 4조건 최종 검증
→ 초안 질문 생성
→ 부모 확인 모달
→ 최종 승인
→ 질문 대기열 등록
```

Green 4조건:

```text
1. 원인·갈등·비밀 캐기 없음
2. 아이가 질문 사실을 알아도 부담·방어가 크지 않음
3. 긍정 또는 중립 정서
4. 유도 프레임 없음
```

## 5. 분류 아키텍처

권장 구조:

```text
정규화
→ Crisis deterministic gate
→ Red deterministic/semantic gate
→ LLM candidate classification
→ Green whitelist validator
→ deterministic final gate
```

LLM은 부모 의도 요약, 후보 area 분류, 질문 개수 추정, 핵심 궁금증 추출, Green 확정 후 문장 재작성만 담당한다. 최종 route는 정책 엔진이 결정한다.


## 6. GREEN LIST

질문은 한 문장·한 개념으로 구성하고 필요 시 보조 질문을 최대 1회만 사용한다.

| green_id | area | 부모 의도 | 부모 확인용 초안 | 아이 실제 질문 |
|---|---|---|---|---|
| G-01 | interest | 좋아하는 것 | 요즘 가장 좋아하는 것이 무엇인지 물어볼까요? | 요즘 제일 좋아하는 거 뭐야? |
| G-02 | school_fun | 학교에서 재밌었던 것 | 오늘 학교에서 가장 재밌었던 일이 무엇인지 물어볼까요? | 오늘 학교에서 뭐가 제일 재밌었어? |
| G-03 | play | 좋아하는 놀이 | 쉬는 시간에 가장 좋아하는 놀이가 무엇인지 물어볼까요? | 쉬는 시간에 뭐 하고 노는 게 제일 좋아? |
| G-04 | food_pref | 먹고 싶은 것 | 지금 가장 먹고 싶은 것이 있는지 물어볼까요? | 지금 제일 먹고 싶은 거 있어? |
| G-05 | pride | 잘한 것 | 오늘 스스로 잘했다고 느낀 일이 있는지 물어볼까요? | 오늘 ‘나 이거 잘했다!’ 한 거 있어? |
| G-06 | content | 좋아하는 캐릭터 | 요즘 가장 좋아하는 캐릭터가 무엇인지 물어볼까요? | 요즘 제일 좋아하는 캐릭터 뭐야? |
| G-07 | weekend | 주말에 하고 싶은 것 | 주말에 하고 싶은 것이 있는지 물어볼까요? | 주말에 뭐 하고 싶어? |

공통 Green 규칙:

- 부모 원문 그대로 전달 금지
- 한 번에 질문 1개
- 부모 확인용 문장과 아이 실제 질문 분리 저장
- 아이가 거절하면 즉시 종료
- 기존 미션 완료 조건과 분리
- 부모 개입 사실 비노출

## 6. 2학년 특칙

- 질문은 한 문장·한 개념
- 선택지를 처음부터 제시하지 않음
- 아이가 “몰라”라고 했을 때만 support prompt 최대 1회
- support prompt 후 다시 거절하면 즉시 종료
- 세션 길이가 짧거나 아이가 피곤하면 질문 삽입 생략
- `dream` 영역은 제외
- 콘텐츠 의도가 영상이면 별도 질문 사용: “요즘 제일 자주 보는 영상 있어?”

## 7. RED LIST

| red_id | area | 차단 의도 | 부모 코칭 문구 |
|---|---|---|---|
| R-01 | emotion_cause | 기분의 원인 캐기 | 2학년은 ‘왜’라고 물으면 어른 짐작에 맞춰 답하기 쉬워요. 케이는 원인을 캐묻지 않고, 직접은 ‘오늘 기억에 남는 일 있어?’처럼 짧게 열어 주세요. |
| R-02 | peer_conflict | 친구 갈등·따돌림 확인 | 이 나이에는 친구 문제를 캐물으면 입을 닫거나 어른의 말에 맞출 수 있어요. 아이가 먼저 말하면 판단 없이 들어 주세요. |
| R-03 | academic_pressure | 성적·공부량 추궁 | 저학년 공부 압박은 대화를 피하게 만들어요. ‘오늘 어떤 활동이 재미있었어?’처럼 부담 없이 물어보세요. |
| R-04 | secret | 비밀·거짓말 적발 | 케이는 아이 몰래 알아내는 도구가 아니에요. 아이와의 믿음을 지키기 위해 이 요청은 전달하지 않아요. |
| R-05 | family_complaint | 가족·집안 불만 확인 | 가족에 대한 아이 마음은 케이가 대신 캐묻지 않아요. 편안한 자리에서 직접 이야기해 주세요. |
| R-06 | fallback | Green 미매칭 전부 | 이 질문은 이 학년 허용 질문에 명확히 해당하지 않아 아이에게 전달하지 않아요. 부담 없는 관심사·놀이·학교의 즐거운 경험·먹고 싶은 것·주말 계획 질문으로 바꿔 주세요. |

Red 질문은 아이 질문 대기열에 등록하지 않고 횟수도 차감하지 않는다. 가능한 경우 검증된 Green 대안 1개를 제시하되 자동 등록하지 않는다.

## 8. CRISIS 경로

아래 신호는 Green/Red 판정 전에 가로챈다.

- 자해·자살·죽고 싶다는 표현
- 학대·성적 피해
- 심각한 폭력
- 지속적·심한 따돌림 또는 소외
- 섭식 이상
- 아이 안전에 즉각적인 우려가 있는 표현

처리 원칙:

- 아이 질문 대기열 등록 금지
- 부모 질문 횟수 차감 금지
- 아이에게 우회 질문 금지
- 일반 로그에 원문 저장 금지
- 내부에는 최소 분류 코드만 저장
- `expert_review_status='PENDING_REVIEW'`
- 임상 전문가 승인 전 `production_enabled=false`

## 9. 초안 모달 및 Q&A 연동

Green 확정 시에만 아래 흐름을 실행한다.

```text
Green 확정
→ 부모 확인용 초안 생성
→ 대상 아이·주간 N/3·오늘 N/1 표시
→ 부모 수정·승인
→ 서버 최종 검증
→ 질문 대기열 등록
→ Q&A에 ‘질문 대기 중’ 표시
```

부모 확인용 문장과 아이 실제 질문을 분리 저장한다.

필수 필드:

```text
source='PARENT_QUERY_ROUTER'
source_grade=2
policy_version='PQR-G2-1.0'
router_route='GREEN'
router_rule_id
parent_draft_text
child_question_text
expert_review_status
```

## 10. 미션 연동

- 기존 4학년 구현의 API·DB·Q&A·미션 대기열 인터페이스를 재사용한다.
- 4학년 구현을 공통화한다는 이유로 재설계하지 않는다.
- Green 승인 질문만 미션 질문 대기열에 넣는다.
- 한 미션에 부모 질문 최대 1개
- 기존 미션 유효 답변 10개에 포함하지 않음
- 부모가 시켰다는 사실 비노출
- 아이 답변 후 재확인 필수
- 아이가 최종 확인한 답변만 부모에게 전달
- 아이가 거절하면 즉시 `DECLINED`
- 미확인 STT 결과를 부모에게 전달 금지

## 11. 테스트 요구사항

### 판정 순서

- Crisis+Green → Crisis
- Red+Green → Red
- Green 근거 없음 → Default Red
- LLM confidence 높음+화이트리스트 미매칭 → Red
- LLM Green+Red 패턴 감지 → Red

### 제한

- 주 1·2·3회 성공, 4회 차단
- 같은 날 두 번째 등록 차단
- 취소·Red·Crisis·API 실패 미차감
- 중복 클릭·재시도 중복 등록 0건

### 미션 E2E

1. Green 질문 등록
2. Q&A `질문 대기 중`
3. 다음 미션에서 자연스럽게 질문
4. 부모 개입 문구 미노출
5. 아이 답변
6. 케이 재확인
7. 아이 최종 확인
8. 부모 Q&A `답변 완료`
9. 미션 유효 답변 10개 미포함
10. 다른 가족 데이터 혼입 0건

### 거부 E2E

1. 아이가 “말하기 싫어” 응답
2. 꼬리질문 0회
3. 상태 `DECLINED`
4. 부모에게 거부 사실만 표시
5. 거부 원문·이유 추측 비노출

## 13. 배포 원칙

- 4학년 구현은 기준본으로 유지
