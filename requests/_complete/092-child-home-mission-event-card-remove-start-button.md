# 092 — 아이 홈 30일 이벤트 카드 미션 시작 버튼 제거

## 목표

아이 홈 `케이와 친해지는 30일` 이벤트 카드는 안내와 진행 상태만 표시하고 미션 진입은 기존 `미션 진행` 카드/정상 시작 플로우만 사용한다.

## 요구사항

- 이벤트 카드 우측 `미션 시작하기` 버튼 제거
- 시작 전·진행 중·완료 모든 상태의 조건부 렌더링 제거
- 버튼 제거 후 카드 높이·텍스트 정렬·여백 정돈
- 기존 미션 진행·이벤트 집계·보상 로직 변경 금지

## 검증

- Development 모바일에서 이벤트 카드 레이아웃 자연스러움 확인
- 아래 `미션 진행` 카드와 역할 중복 제거 확인
- 타입체크·빌드 후 Production 반영 및 smoke
