# 케이 챗봇 플로팅 버튼 드래그 이동 기능

- 상태: TODO
- 유형: 신규 기능 개선
- 우선순위: HIGH
- 대상: 아이 화면, 부모 화면
- 요청 파일: requests/021-feature-draggable-k-chatbot-button.md

---

## 1. 목적

현재 케이 챗봇(문의하기) 버튼은 특정 위치에 고정되어 있어 화면 콘텐츠, 하단 메뉴, 입력 영역과 겹치는 문제가 발생한다.

사용자가 원하는 위치로 버튼을 직접 이동할 수 있도록 드래그 가능한 플로팅 버튼(Floating Action Button) 방식으로 개선한다.

목표:

- 사용자가 방해받지 않는 위치에서 버튼 사용 가능
- 모든 화면에서 접근성 유지
- 모바일 환경에서 자연스러운 UX 제공

---

# 2. 현재 문제

## 현재 동작

- 케이 챗봇 버튼이 fixed 위치로 고정되어 있음
- 화면 콘텐츠 위에 겹쳐 표시됨
- 사용자가 위치 변경 불가능

## 문제 사례

발생 가능 상황:

- 하단 내비게이션과 겹침
- 카드 콘텐츠를 가림
- 입력 버튼 또는 주요 CTA와 충돌
- 음성 대화 UI와 겹칠 가능성 존재

---

# 3. 개선 방향

## 기본 원칙

기존:

```
고정 위치 버튼
↓
사용자가 이동 가능한 플로팅 버튼
```

으로 변경한다.

---

# 4. 버튼 동작 방식

## 기본 위치

초기 위치:

- 기존 케이 챗봇 버튼 위치 유지
- 최초 사용자는 기존 UX와 동일하게 사용 가능

---

## 이동 방식

사용자가 버튼을:

- 길게 누르기
또는
- 드래그 시작

하면 이동 모드로 전환한다.

동작:

```
버튼 길게 누름
        ↓
드래그 시작
        ↓
원하는 위치 이동
        ↓
손 떼기
        ↓
가장 가까운 화면 가장자리 자동 정렬
```

---

# 5. 위치 Snap 기능

완전 자유 위치 저장이 아니라 화면 가장자리 기준으로 자동 정렬한다.

지원 위치:

- 좌측 상단
- 좌측 중앙
- 좌측 하단
- 우측 상단
- 우측 중앙
- 우측 하단


예:

```
사용자 이동 위치

        💬


손 떼기


                 💬
```

---

# 6. 위치 저장

사용자가 변경한 위치는 저장한다.

저장 방식:

우선순위:

1. localStorage
2. 향후 사용자 설정 DB 확장 가능 구조 유지


저장 데이터 예:

```json
{
  "xPercent": 90,
  "yPercent": 80,
  "edge": "right",
  "updatedAt": "2026-07-27T12:00:00"
}
```

# 7. 화면별 정책

## 아이 화면

목적:

아이 사용 중 실수 이동 방지

정책:

- 짧은 클릭:
  - 문의 모달 열기

- 길게 누르기(400~500ms):
  - 이동 모드 진입

- 드래그 이동 가능

- safe-area 영역 침범 금지


---

## 부모 화면

정책:

- 자유로운 드래그 이동 허용
- 마지막 위치 저장
- 다음 접속 시 기존 위치 복원

```

```
