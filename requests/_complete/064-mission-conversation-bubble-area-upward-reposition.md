작업명
미션 대화 화면 — 말풍선 3단 영역 상향 재배치 및 케이 마스코트 비겹침 정렬
1. 배경 / 문제 정의
현재 미션 대화 화면에서 케이의 대화 영역이 전체적으로 너무 아래에 배치되어 있습니다.
대화 영역은 아래 3단으로 구성되어 있습니다.
전전 발화(가장 흐리게 보이는 이전 케이 발화)
이전 발화(반투명 흰색 버블)
현재 발화(오렌지 테두리의 메인 말풍선)
문제는 이 3단 대화 묶음 전체가 아래로 내려와 있어서,
현재 발화 말풍선이 케이 마스코트와 너무 가까워지고, 화면이 답답해 보이며, 경우에 따라 겹쳐 보이는 느낌까지 발생한다는 점입니다.
반대로 상단 진행률 바 아래에는 애매한 빈 공간이 남아 있어서, 위쪽 공간을 효율적으로 쓰지 못하고 있습니다.
즉, 이번 수정의 핵심은 다음입니다.
대화 3단 영역 전체를 지금보다 더 위로 올린다
위쪽에 쓸데없는 큰 빈 공간은 만들지 않는다
현재 발화 말풍선과 케이 마스코트가 겹치지 않게 한다
전체적으로 더 안정적이고 밀도 있는 화면 배치를 만든다
2. 작업 목표
이번 작업의 목표는 아래와 같습니다.
케이의 3단 대화 영역(전전 발화 / 이전 발화 / 현재 발화)을 하나의 묶음으로 보고 전체를 상향 이동
진행률 바 아래 불필요한 세로 여백 축소
현재 발화 말풍선과 케이 마스코트 사이에 자연스러운 간격 확보
긴 문장이 들어와도 말풍선이 케이 영역과 겹치지 않게 레이아웃 안정화
화면이 위는 비고 아래는 답답한 구조가 아니라, 위쪽은 알차고 아래는 안정적인 구조가 되도록 조정
3. 요구사항
3-1. 대화 3단 영역 전체 상향 이동
아래 3개를 하나의 묶음으로 보고 전체를 위로 이동해 주세요.
전전 발화
이전 발화
현재 발화(메인 말풍선)
중요:
현재 발화 말풍선만 따로 올리는 방식이 아니라
3단 대화 묶음 전체를 함께 위로 올려야 합니다
3-2. 상단 불필요 여백 제거
진행률 바 아래에 불필요하게 큰 빈 공간이 생기면 안 됩니다.
원칙:
진행률 바 아래에서 대화가 자연스럽게 바로 시작되어야 함
하지만 너무 딱 붙으면 안 되고, 시각적으로 자연스러운 최소 간격만 유지
권장 기준:
진행률 바 하단 ~ 전전 발화 시작점 간격: 약 12~20px 수준
지금처럼 히스토리 영역이 시작되기 전에 큰 공백이 생기면 안 됨
3-3. 현재 말풍선과 케이 마스코트 비겹침
현재 발화 말풍선과 케이 마스코트가 시각적으로 겹치거나 너무 답답하게 가까워 보이면 안 됩니다.
원하는 상태:
현재 발화 말풍선은 케이 위에 분명하게 위치
현재 말풍선 하단 꼬리와 케이 머리 사이에 숨 쉴 공간이 있어야 함
케이가 말풍선을 “받쳐 들고 있는 것처럼” 자연스러운 구조여야 함
권장 기준:
현재 말풍선 꼬리 하단 ~ 케이 머리 상단 간격: 약 16~24px
최소한 말풍선이 케이의 시각 영역을 침범하면 안 됨
3-4. 긴 문장 대응 우선순위
현재 발화 문장이 길어질 경우에도 케이 영역을 침범하면 안 됩니다.
우선순위는 아래와 같이 처리해 주세요.
전전 발화 영역을 먼저 줄이거나 숨김
그다음 이전 발화 영역의 높이나 표시량을 줄임
현재 발화 말풍선은 최대한 온전하게 유지
현재 발화가 길어져도 케이 마스코트 영역과 겹치지 않게 유지
즉,
아래 케이 영역을 밀어내는 방식이 아니라,
위쪽 히스토리 영역을 먼저 압축하는 방향으로 처리해 주세요.
4. 구현 원칙
유지해야 하는 것
기존 3단 히스토리 구조 유지
전전 발화 / 이전 발화 / 현재 발화의 시각적 위계 유지
현재 말풍선의 기본 디자인(오렌지 테두리, 꼬리, 강조 텍스트) 유지
케이 마스코트 기능 로직 유지
음성 상태 / 자동·수동 / 마이크 / 진행률 관련 기능 로직은 건드리지 않음
바꿔야 하는 것
대화 3단 영역의 세로 시작 위치
각 히스토리 블록 간의 vertical spacing
현재 발화 말풍선과 케이 사이 간격
필요 시 Row 2 / Row 3 배치 기준 또는 padding / margin 조정
5. 기술 점검 및 수정 포인트
아래 포인트를 우선 확인 후 수정해 주세요.
대화 히스토리 전체 컨테이너의 상단 시작 위치
전전 발화의 top margin / padding
이전 발화와 현재 발화 사이 gap
현재 발화 말풍선의 bottom margin
케이 마스코트 영역의 top margin / row 시작 위치
Grid / Flex 구조에서 히스토리 영역이 아래로 밀리는 원인
justify-center, 과도한 padding-top, 불필요한 spacer 존재 여부
Row 2(히스토리)와 Row 3(케이 영역)의 역할 분리가 명확한지 검토
가능한 수정 방향:
히스토리 영역을 top-aligned 구조로 조정
Row 2 내부 상단 padding 축소
Row 3(케이 영역)은 유지하되 Row 2 콘텐츠를 위로 압축
현재 말풍선이 아래로 처지지 않도록 spacing 재조정
6. 목표 화면 감각
최종 화면은 아래와 같은 인상이 나와야 합니다.
진행률 바 바로 아래에서 대화가 자연스럽게 시작된다
전전 발화 / 이전 발화 / 현재 발화가 위쪽 영역에 밀도 있게 정렬된다
현재 발화 말풍선과 케이가 서로 분리되어 안정적으로 보인다
말풍선이 케이와 겹치지 않는다
위는 비어 있고 아래는 답답한 구조가 아니라, 위쪽은 알차고 아래는 안정적이다
즉,
현재의 “위는 비고 아래는 몰린 화면”을
“위쪽은 정리되고 아래는 안정적인 화면”으로 바꾸는 것이 목표입니다.
