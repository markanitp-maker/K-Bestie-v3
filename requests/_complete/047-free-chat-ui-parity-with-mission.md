# 047 — 자유대화 화면을 미션 대화 UI와 통일하되 진행률·소리 카드 제거

## 1. 작업 목적

현재 아이와 케이의 자유대화 화면은 첨부 이미지 왼쪽처럼 오래된 구조로 표시되고 있다.

현재 자유대화 화면의 문제는 다음과 같다.

- 화면 대부분이 의미 없는 빈 공간으로 남아 있음
- 아이와 케이의 직전 대화가 화면에 구조적으로 표시되지 않음
- 케이의 현재 발화가 말풍선으로 명확하게 표시되지 않음
- 마스코트가 화면 하단에 지나치게 작게 배치됨
- 자동·수동 버튼과 마스코트의 관계가 분리되어 보임
- 현재 케이가 듣는 중인지, 생각 중인지, 말하는 중인지 확인하기 어려움
- 키보드·마이크·문의·종료 버튼이 서로 분리되어 일관성이 없음
- 미션 대화 화면과 자유대화 화면이 서로 완전히 다른 서비스처럼 보임
- 실제 모바일 PWA에서 아이가 대화 흐름을 직관적으로 이해하기 어려움

자유대화 화면을 첨부 이미지 오른쪽의 현재 미션 대화 화면과 동일한 시각 구조로 변경한다.

다만 자유대화에는 다음 두 요소가 필요하지 않으므로 표시하지 않는다.

1. 상단 미션 진행률 10개 원
2. 마스코트 왼쪽의 소리 켜짐·꺼짐 카드

이번 작업은 자유대화 기능 로직을 변경하는 작업이 아니다.

기존 자유대화 기능은 그대로 보존하고 UI 구조와 배치만 미션 대화 화면 수준으로 교체한다.

---

# 2. 적용 대상

대상:

- 아이 자유대화 화면
- 케이와 자유롭게 이야기하는 화면
- 자유대화 음성 입력 상태
- 자유대화 텍스트 입력 상태
- 자동 입력 모드
- 수동 입력 모드
- 케이 듣는 중
- 케이 생각 중
- 케이 말하는 중
- 연결 중·재연결 중·오류 상태
- 자유대화 종료 직전 상태

실제 Route와 컴포넌트 경로는 구현 전에 확인한다.

미션 대화 화면 Route를 수정 대상으로 오인하지 않는다.

---

# 3. 기준 화면 해석

첨부 이미지 오른쪽의 미션 대화 화면을 자유대화 화면의 시각적 기준으로 사용한다.

미션 대화 기준 화면의 주요 구성은 다음과 같다.

```text
[문의]                              [X 종료]

[미션 진행률] ← 자유대화에서는 제거

[직전 아이 발화]

[직전 케이 응답]

[현재 케이 발화 또는 질문 말풍선]

[소리 카드] [케이 마스코트] [대화 상태 카드]
     ↑ 자유대화에서는 제거

               [자동] [수동]

[키보드]        [마이크]
```

자유대화 최종 구조는 다음과 같다.

```text
[문의]                              [X 종료]

[직전 아이 발화]

[직전 케이 응답]

[현재 케이 발화 말풍선]

          [케이 마스코트] [대화 상태 카드]

               [자동] [수동]

[키보드]        [마이크]
```

---

# 4. 반드시 제거할 요소

## 4-1. 상단 미션 진행률

자유대화 화면에는 다음 UI를 표시하지 않는다.

```text
○ ○ ○ ○ ○ ○ ○ ○ ○ ○
```

제거 대상:

- 진행률 10개 원
- 진행률 카드 배경
- 진행률 애니메이션
- 진행률 영역 Wrapper
- 해당 영역이 차지하던 높이
- 진행률 아래 불필요한 Spacer
- `0/10`, `3/10` 등 미션 진행 상태 표시

중요:

- CSS로 보이지 않게만 숨기지 말고 자유대화 DOM에서는 렌더링하지 않는다.
- 제거된 진행률 영역만큼 대화 콘텐츠가 자연스럽게 위로 이동해야 한다.
- 자유대화 로직에 미션 진행률 상태나 가짜 진행 데이터를 추가하지 않는다.
- 미션 화면의 진행률 UI와 기능은 변경하지 않는다.

---

## 4-2. 왼쪽 소리 켜짐·꺼짐 카드

자유대화 화면에서는 마스코트 왼쪽에 다음 카드를 표시하지 않는다.

```text
[스피커 아이콘]
소리 켜짐
```

또는:

```text
[음소거 아이콘]
소리 꺼짐
```

제거 대상:

- 왼쪽 소리 상태 카드
- 카드 배경
- 스피커·음소거 아이콘
- `소리 켜짐`, `소리 꺼짐` 문구
- 해당 카드가 차지하던 Grid Column
- 해당 카드 전용 빈 공간

중요:

- 자유대화의 실제 오디오 출력 기능을 제거하지 않는다.
- 오디오 재생, TTS, 음량 및 기존 음소거 정책은 그대로 유지한다.
- 이번 작업은 화면에 보이는 왼쪽 소리 카드만 제거하는 것이다.
- 미션 대화 화면의 소리 카드는 변경하지 않는다.

---

# 5. 유지할 상단 컨트롤

## 5-1. 문의 버튼

문의 버튼은 화면 좌측 상단에 유지한다.

기준:

- K-Navy 배경
- 말풍선 아이콘
- `문의` 문구
- 기존 클릭·길게 누르기·드래그 기능 유지
- 현재 Viewport와 Safe Area 내부에 표시
- 상단 상태 표시줄 아래 배치
- 대화 말풍선을 가리지 않음
- 종료 버튼과 겹치지 않음

문의 버튼의 저장 좌표가 이전 자유대화 레이아웃 기준이라 화면 중앙이나 주요 콘텐츠를 가리는 경우 현재 Layout Version 기준으로 위치를 보정한다.

문의 기능, 건의, 버그 신고 및 제출 로직은 변경하지 않는다.

---

## 5-2. 종료 버튼

우측 상단에 X 종료 버튼을 배치한다.

기준:

- 미션 대화 화면과 동일한 아이콘 스타일
- 최소 터치 영역 44×44px
- Safe Area 반영
- `aria-label="자유대화 종료"`
- 문의 버튼과 동일한 상단 기준선 또는 자연스러운 위치 관계 유지

동작은 기존 자유대화 종료 로직을 그대로 사용한다.

변경 금지:

- 자유대화 세션 저장 방식
- 종료 확인 정책
- 오디오 연결 종료
- 대화 저장
- 홈 복귀 Route
- 일일 자유대화 횟수·시간 정책

---

# 6. 대화 표시 영역

자유대화 화면에도 미션 대화 화면과 동일하게 대화의 문맥이 보이도록 한다.

최종 순서:

1. 직전 아이 발화
2. 직전 케이 응답
3. 현재 케이 발화 말풍선

다만 실제 자유대화 데이터 구조를 그대로 사용하고, 화면을 위해 새로운 대화 데이터를 생성하지 않는다.

---

## 6-1. 직전 아이 발화

미션 화면의 상단 보조 발화 영역과 동일한 스타일로 표시한다.

예시:

```text
그래 내일 제가 옆에 좀 있어라.
```

기준:

- 가운데 정렬
- Neutral 보조 텍스트
- `font-size: 13px~15px`
- `line-height: 1.4~1.5`
- 최대 2줄
- 너무 긴 경우 의미가 유지되도록 기존 자막 정책을 사용
- 화면 전체를 아래로 과도하게 밀지 않도록 최대 높이 제한
- 아이의 현재 처리 중인 미완성 발화를 확정 발화처럼 표시하지 않음

데이터가 없는 첫 대화 시작 상태에서는 빈 Wrapper를 남기지 않는다.

---

## 6-2. 직전 케이 응답

직전 케이 응답은 흰색 또는 반투명 흰색의 둥근 카드로 표시한다.

예시:

```text
서아야, 오늘 학교에서 숨바꼭질도 하고
속상한 일도 있었지? 케이가 여기 있을게!
```

기준:

- 화면 중앙 정렬
- 너비 약 `76%~84%`
- 흰색 또는 기존 미션 대화 카드 배경
- radius `16px~22px`
- 내부 좌우 Padding `14px~18px`
- 내부 상하 Padding `10px~14px`
- `font-size: 14px~16px`
- `line-height: 1.4~1.5`
- 최대 3~4줄
- 약한 그림자
- 긴 문장이 화면 폭을 넘지 않음
- 가로 스크롤 금지

직전 응답이 없으면 카드 영역 자체를 렌더링하지 않는다.

---

## 6-3. 현재 케이 발화 말풍선

자유대화에서 케이가 현재 말하고 있거나 마지막으로 전달한 핵심 문장을 미션 화면의 주황색 테두리 말풍선으로 표시한다.

예시:

```text
내일 서아 옆에 꼭 붙어서 즐거운 시간 함께 보낼게.
오늘 수업, 쉬는 시간, 점심시간 중에서
제일 기억나는 시간은 언제야?
```

기준:

- 흰색 배경
- K-Orange 테두리
- 아래 중앙 말풍선 꼬리
- 화면 너비 약 `84%~90%`
- 가운데 정렬
- `font-size: clamp(17px, 4.5vw, 20px)`
- `font-weight: 650~750`
- `line-height: 1.4~1.5`
- 내부 Padding `16px~20px`
- K-Navy 또는 진한 본문색
- 약한 주황색 그림자
- 최대 높이를 초과하는 긴 텍스트는 기존 정책에 맞게 내부 스크롤 또는 안전한 높이 조정
- 글자를 작게 줄여 억지로 한 화면에 맞추지 않음

자유대화이므로 `현재 질문`만 표시하는 것으로 제한하지 않는다.

케이가 질문하지 않고 공감·반응·인사를 말하는 경우에도 같은 말풍선에 표시할 수 있어야 한다.

---

# 7. 상단 진행률 제거 후 위치 재배치

진행률 카드가 제거되므로 다음 영역을 위로 이동한다.

- 직전 아이 발화
- 직전 케이 응답
- 현재 케이 말풍선
- 마스코트 상호작용 영역

상단에 진행률이 있었던 것처럼 큰 빈 공간을 남기지 않는다.

권장 간격:

| 구간 | 권장 간격 |
|---|---:|
| 상단 Safe Area → 문의·종료 | 8~12px |
| 문의·종료 → 직전 아이 발화 | 36~56px |
| 직전 아이 발화 → 직전 케이 응답 | 8~12px |
| 직전 케이 응답 → 현재 케이 말풍선 | 10~16px |
| 현재 말풍선 → 마스코트 영역 | 28~44px |

실제 모바일 화면 높이에 따라 `clamp()`를 사용한다.

---

# 8. 마스코트 상호작용 영역

자유대화 화면에서도 케이 마스코트를 미션 화면과 같은 위치·크기·단상 구조로 표시한다.

단, 왼쪽 소리 카드를 제거하므로 최종 구조는 다음과 같다.

```text
          [케이 마스코트] [대화 상태 카드]
               [단상]
```

또는 시각적 균형을 위해 다음 구조를 사용할 수 있다.

```text
      [빈 고정 공간] [케이 마스코트] [대화 상태 카드]
```

단, 빈 고정 공간은 실제 보이는 카드나 클릭 요소가 아니어야 한다.

왼쪽 소리 카드가 제거됐다는 이유로 마스코트가 화면 왼쪽으로 치우치거나 오른쪽 상태 카드가 화면 끝으로 멀어지면 안 된다.

---

## 8-1. 케이 마스코트

기준:

```css
width: clamp(92px, 27vw, 120px);
height: auto;
```

390px 전후 모바일 목표:

```text
약 100px~115px
```

요구사항:

- 공식 케이 마스코트 자산 사용
- 비율 왜곡 금지
- 흐릿하게 확대하지 않음
- 발이 단상 위에 자연스럽게 위치
- 말풍선과 적절한 간격 유지
- 상태 변화 시 레이아웃이 크게 흔들리지 않음
- 기존 자유대화의 감정·상태별 마스코트 자산 전환이 있다면 그대로 유지

---

## 8-2. 단상

기준:

- 마스코트 바로 아래
- 너비 약 `135px~170px`
- 마스코트보다 넓게 표시
- 높이를 과도하게 키우지 않음
- 마스코트 발과 단상 사이 큰 빈 공간 금지
- 자동·수동 버튼과 자연스럽게 연결

---

# 9. 오른쪽 대화 상태 카드

미션 대화 화면의 오른쪽 상태 카드를 자유대화에도 적용한다.

표시 상태 예시:

| 실제 상태 | 화면 문구 |
|---|---|
| 아이 답변 대기 | 듣고 있어 |
| 아이 발화 수신 | 듣고 있어 |
| 케이 응답 생성 | 생각 중 |
| 케이 음성 출력 | 말하는 중 |
| 연결 준비 | 연결 중 |
| 재연결 | 다시 연결 중 |
| 입력 대기·일시정지 | 대기 중 |
| 오류 | 연결 오류 |

첨부 이미지 기준으로 현재 케이가 발화 중이면 다음처럼 표시한다.

```text
말하는 중
```

기준:

- 마스코트 오른쪽에 배치
- 너비 약 `66px~84px`
- 최소 높이 약 `76px~96px`
- 연한 K-Sky Blue 계열 배경
- radius `16px~20px`
- 상태 아이콘 중앙 정렬
- 상태 문구 `14px~17px`
- 굵기 `700`
- 최소 터치 영역은 필요하나 상태 표시 전용이면 버튼으로 인식시키지 않음
- 상태 문구 변화 시 카드 너비와 위치가 흔들리지 않음
- 색상뿐 아니라 아이콘과 텍스트로 상태 전달

상태 문구를 타이머나 가짜 Mock 값으로 표시하지 않는다.

기존 실제 자유대화 상태 머신을 그대로 연결한다.

# 10. 왼쪽 소리 카드 제거 후 균형 기준

소리 카드가 사라져도 다음을 지켜야 한다.

- 마스코트 중심은 화면 중앙에서 크게 벗어나지 않음
- 오른쪽 상태 카드가 마스코트에 붙어 보임
- 오른쪽 상태 카드가 화면 우측 끝에 떨어져 있지 않음
- 마스코트와 상태 카드 간격 약 `8px~14px`
- 전체 그룹이 화면 중앙에 하나의 덩어리로 보임
- 상태 카드가 말풍선 꼬리와 겹치지 않음
- 자동·수동 버튼의 중심이 마스코트·단상 중심과 일치

권장 구조:

```css
.free-chat-mascot-group {
  display: grid;
  grid-template-columns: auto auto;
  align-items: center;
  justify-content: center;
  gap: clamp(8px, 2.5vw, 14px);
}
```

마스코트 정중앙 배치가 필요하면 상위 Wrapper에서 상태 카드 너비를 고려해 시각 중심을 보정한다.

절대좌표로 기기마다 별도 위치를 지정하지 않는다.

# 28. 완료 기준

다음 조건을 모두 만족해야 완료로 판정한다.

- 실제 모바일 자유대화 화면이 미션 대화 화면과 동일한 시각 체계로 변경됨
- 자유대화 화면의 구형 대규모 빈 공간이 제거됨
- 직전 아이 발화가 표시됨
- 직전 케이 응답이 표시됨
- 현재 케이 발화가 주황색 테두리 말풍선에 표시됨
- 케이 마스코트가 적절한 크기로 중앙에 표시됨
- 마스코트 단상이 표시됨
- 오른쪽 대화 상태 카드가 실제 상태와 연동됨
- 자동·수동 버튼이 기존 기능과 연동됨
- 키보드·마이크 입력이 정상 작동함
- 문의 버튼과 종료 버튼이 정상 작동함
- 자유대화 화면에 미션 진행률이 표시되지 않음
- 자유대화 화면에 왼쪽 소리 카드가 표시되지 않음
- 실제 오디오·TTS 기능은 그대로 유지됨
- 미션 진행률·보상·질문 로직이 자유대화에 혼입되지 않음
- 실제 모바일 PWA에서 UI가 정상 표시됨
- 모바일 PWA 삭제·재설치 없이 최신 UI가 적용됨
- 기존 자유대화 연결·저장·종료 기능에 회귀가 없음
- iOS PWA QA 통과
- Android PWA QA 통과
- 접근성 검증 통과
- lint 통과
- typecheck 통과
- 관련 test 통과
- production build 통과
