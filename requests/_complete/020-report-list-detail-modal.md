# REQUEST 020 — 일일·주간 리포트 상세 모달 구현

## 1. 작업 목적

부모 화면의 일일·주간 리포트 목록에서 특정 리포트 카드를 선택하면 별도 페이지로 이동하지 않고 모달 팝업을 열어 다음 세 가지 내용을 확인할 수 있도록 구현한다.

1. 빠른 요약
2. 상세 보기
3. 추천 가이드

첨부 이미지의 왼쪽 화면은 리포트 목록이며, 목록의 특정 항목을 누르면 오른쪽 화면처럼 상세 모달이 열려야 한다.

---

## 2. 적용 화면

다음 두 목록에 동일하게 적용한다.

- 일일 리포트 목록
- 주간 리포트 목록

리포트 카드 전체를 클릭 가능한 영역으로 사용한다.

카드 내부의 텍스트, 날짜, 상태 영역 중 어느 곳을 눌러도 동일한 상세 모달이 열려야 한다.

---

## 3. 기본 동작

### 3.1 리포트 카드 선택

사용자가 일일 또는 주간 리포트 카드를 선택하면 다음 동작을 수행한다.

```text
리포트 카드 선택
→ 선택한 리포트 ID 확인
→ 해당 아이와 기준 날짜 검증
→ 상세 데이터 조회
→ 상세 모달 표시
```

페이지 이동이나 전체 새로고침은 발생하지 않아야 한다.

목록의 현재 스크롤 위치와 선택된 일일·주간 탭 상태는 그대로 유지한다.

---

### 3.2 모달 기본 탭

모달을 처음 열면 기본 선택 탭은 다음으로 한다.

```text
빠른 요약
```

상단에는 다음 세 개 탭을 표시한다.

```text
빠른 요약 | 상세 보기 | 추천 가이드
```

선택한 탭은 K-Navy 계열의 강조 상태로 표시하고, 나머지 탭은 비활성 상태로 표시한다.

---

## 4. 모달 UI 구조

```text
┌─────────────────────────────┐
│ 빠른 요약  상세 보기  추천 가이드    X │
├─────────────────────────────┤
│                             │
│ 선택한 탭의 리포트 내용         │
│                             │
│ 내용이 길면 내부 스크롤          │
│                             │
└─────────────────────────────┘
```

### 필수 구성

- 상단 탭 3개
- 우측 상단 닫기 버튼 `X`
- 선택한 리포트의 기준 날짜 또는 기간
- 선택한 아이 이름
- 리포트 콘텐츠 영역
- 모달 내부 세로 스크롤
- 모바일 안전 영역 반영

---

## 5. 빠른 요약 탭

빠른 요약은 부모가 리포트의 핵심을 짧은 시간 안에 파악하는 화면이다.

### 일일 리포트 표시 항목

- 오늘의 한마디
- 주요 감정 또는 마음 상태
- 가장 중요한 사건
- 주요 관심사
- 부모가 알아야 할 핵심 변화
- 오늘의 대화거리 1개

### 주간 리포트 표시 항목

- 이번 주 한마디
- 주간 감정 흐름
- 가장 많이 등장한 관심사
- 반복된 사건 또는 주제
- 지난주 대비 주요 변화
- 이번 주 부모 대화 포인트

빠른 요약은 상세 내용을 그대로 반복하지 않고 핵심만 압축해 표시한다.

---

## 6. 상세 보기 탭

상세 보기는 해당 일일 또는 주간 리포트의 전체 분석 내용을 확인하는 화면이다.

### 일일 리포트 상세 항목

- 학교·학원 생활
- 친구 관계
- 마음 흐름
- 관심사·취향
- 공부 고민
- 디지털·콘텐츠
- 선생님·어른
- 반복 이야기
- 오늘의 한마디
- 주요 사건 및 변화 신호
- 부모 전달 메시지

### 주간 리포트 상세 항목

- 주간 학교·학원 생활
- 주간 친구 관계
- 주간 마음 흐름
- 주간 관심사·취향
- 주간 공부 고민
- 주간 디지털·콘텐츠
- 선생님·어른 관련 변화
- 반복 주제
- 주요 변화 신호
- 주간 종합 요약

실제 DB와 API에 존재하는 필드명을 먼저 확인하고 기존 리포트 구조에 맞춰 매핑한다.

존재하지 않는 데이터를 화면에서 임의 생성하지 않는다.

---

## 7. 추천 가이드 탭

추천 가이드는 부모가 아이와 실제 대화를 이어갈 수 있도록 행동 중심으로 제공한다.

### 표시 항목

- 오늘 또는 이번 주 아이에게 건넬 첫 문장
- 자연스럽게 이어갈 후속 질문 2~3개
- 피해야 할 질문 또는 표현
- 부모가 관찰할 포인트
- 부담 없이 함께할 행동 제안

### 작성 기준

- 훈계나 심문처럼 느껴지지 않도록 한다.
- 리포트에서 실제 확인된 내용을 바탕으로 한다.
- 부모에게 전문 진단처럼 전달하지 않는다.
- 아이의 말을 캐묻거나 검증하도록 유도하지 않는다.
- 짧고 바로 사용할 수 있는 문장으로 제공한다.

예시:

```text
첫 문장
“오늘 피구 얘기 조금 더 듣고 싶어.”

후속 질문
- 어떤 순간이 가장 재미있었어?
- 다음에도 또 하고 싶어?
- 같이한 친구 중 기억나는 친구가 있어?

피해야 할 표현
- 왜 그것밖에 못 했어?
- 누구랑 싸운 거 아니야?
```

---

## 8. 일일·주간 데이터 구분

모달은 선택한 리포트의 유형을 기준으로 데이터를 조회해야 한다.

```ts
type ReportModalTarget =
  | {
      reportType: "daily";
      reportId: string;
      childId: string;
      businessDate: string;
    }
  | {
      reportType: "weekly";
      reportId: string;
      childId: string;
      weekStartDate: string;
      weekEndDate: string;
    };
```

일일 리포트 선택 시 주간 데이터를 조회하거나, 주간 리포트 선택 시 일일 데이터를 임의 조합하지 않는다.

---

## 9. 데이터 조회 원칙

모달은 반드시 선택한 카드의 리포트 ID를 기준으로 데이터를 조회한다.

### 필수 조건

- 선택된 `child_id` 일치
- 선택한 `report_id` 일치
- 일일·주간 리포트 타입 일치
- 기준 날짜 또는 기간 일치
- 정상 완료된 리포트만 표시
- 다른 아이의 데이터 혼합 금지

최신 리포트를 임의로 다시 조회하여 선택한 카드와 다른 내용을 표시하면 안 된다.

과거 리포트를 눌렀다면 해당 과거 리포트 내용이 열려야 한다.

---

## 10. API 구현

기존 리포트 조회 API를 우선 재사용한다.

기존 API로 필요한 데이터를 모두 반환할 수 없다면 다음 목적의 상세 조회 API를 추가한다.

```text
GET /api/parent/reports/{reportId}
```

또는 기존 프로젝트 API 규칙에 맞는 동일 목적의 경로를 사용한다.

### API 응답 예시

## 11. 로딩·오류·데이터 부족 처리

### 로딩 중

모달 프레임을 먼저 표시하고 콘텐츠 영역에는 스켈레톤 또는 로딩 표시를 사용한다.

```text
리포트를 불러오고 있어요.
```

### 조회 실패

```text
리포트를 불러오지 못했어요.
잠시 후 다시 확인해 주세요.
```

오류 발생 시 모달 전체가 빈 화면으로 남거나 앱이 종료되면 안 된다.

### 일부 데이터 부족

해당 섹션에만 다음과 같이 표시한다.

```text
이 항목은 확인할 대화가 충분하지 않아요.
```

`새로운 이야기가 있어요`와 같은 의미 없는 placeholder를 사용하지 않는다.

## 12. 모달 닫기

다음 동작으로 모달을 닫을 수 있어야 한다.

- 우측 상단 `X`
- 모달 외부 배경 선택
- 모바일 뒤로 가기
- 데스크톱 `Escape`
- 하드웨어 또는 브라우저 뒤로 가기

모달을 닫으면 리포트 목록의 기존 스크롤 위치로 돌아간다.

모달을 닫는 과정에서 목록을 다시 불러오거나 선택된 자녀가 변경되면 안 된다.

---

## 13. 모바일 UX

첨부 이미지와 같은 모바일 부모 화면을 기준으로 구현한다.

### 요구사항

- 화면 좌우 안전 여백 확보
- 상단 헤더 또는 브라우저 영역과 겹치지 않음
- 하단 내비게이션과 겹치지 않음
- 모달 최대 높이는 현재 화면의 안전 영역 내에서 제한
- 내용이 길면 모달 내부만 스크롤
- 배경 화면 스크롤 잠금
- 탭 영역은 상단 고정
- `X` 버튼은 항상 접근 가능
- 긴 텍스트가 화면 밖으로 넘치지 않음

모바일에서는 전체 화면에 가까운 대형 모달 또는 현재 디자인 시스템의 반응형 다이얼로그를 사용한다.

---

## 14. 접근성

- 모달에 `role="dialog"` 적용
- `aria-modal="true"` 적용
- 모달 제목과 연결된 `aria-labelledby` 적용
- 모달 오픈 시 포커스를 모달 내부로 이동
- 모달이 열린 동안 포커스가 배경으로 빠져나가지 않도록 처리
- 닫기 후 포커스를 선택했던 리포트 카드로 복귀
- 탭에 적절한 `role="tab"`과 선택 상태 적용
- 키보드로 탭 이동 및 모달 닫기 지원

---

## 15. 캐시 및 상태 관리

- 선택한 리포트 ID별 상세 데이터를 캐시할 수 있다.
- 모달 재오픈 시 불필요한 중복 요청을 줄인다.
- 단, 다른 아이의 같은 날짜 리포트와 캐시 키가 충돌하면 안 된다.
- 캐시 키에는 최소한 `childId`, `reportType`, `reportId`를 포함한다.
- 새 리포트가 생성 또는 갱신되면 해당 리포트 상세 캐시를 무효화한다.

---

## 16. 기존 화면 영향 방지

이번 작업으로 다음 기존 기능이 변경되면 안 된다.

- 일일·주간 탭 전환
- 최근 7일 대화 횟수 표시
- 월별 리포트 목록
- 목록 카드의 기존 요약 문구
- 자녀 선택
- 하단 내비게이션
- 부모 홈 대시보드
- 리포트 생성 및 보존 정책

목록 카드를 선택했을 때 모달을 여는 기능만 추가하며, 목록 화면 디자인을 불필요하게 전면 변경하지 않는다.

## 17. 필수 테스트 시나리오

### 시나리오 A — 일일 리포트 선택

1. 일일 탭 진입
2. 과거 일일 리포트 카드 선택
3. 빠른 요약 모달 표시
4. 상세 보기 탭 전환
5. 추천 가이드 탭 전환
6. 선택한 날짜의 동일 리포트 내용 확인

예상 결과:

- 페이지 이동 없음
- 선택한 일일 리포트 내용 표시
- 다른 날짜 데이터 혼합 없음

### 시나리오 B — 주간 리포트 선택

1. 주간 탭 진입
2. 특정 주간 리포트 선택
3. 빠른 요약·상세 보기·추천 가이드 확인

예상 결과:

- 선택한 주간 기준 데이터 표시
- 일일 리포트를 임의로 표시하지 않음

### 시나리오 C — 과거 리포트 선택

최신 리포트가 아닌 과거 리포트 카드를 선택한다.

예상 결과:

- 선택한 `report_id`의 과거 내용 표시
- 최신 리포트로 자동 교체되지 않음

### 시나리오 D — 일부 데이터 부족

예상 결과:

- 존재하는 내용은 정상 표시
- 부족한 섹션만 데이터 부족 표시
- 모달 전체 실패 처리 금지

### 시나리오 E — 다자녀 계정

1. 첫 번째 아이의 리포트 열기
2. 모달 닫기
3. 두 번째 아이로 변경
4. 두 번째 아이 리포트 열기

예상 결과:

- 아이별 데이터 혼합 없음
- 이전 아이 캐시 노출 없음

### 시나리오 F — 모바일 닫기

- `X`
- 배경
- 뒤로 가기

각 방식으로 모달이 정상 종료되고 목록 위치가 유지되는지 확인한다.

### 시나리오 G — 긴 상세 리포트

예상 결과:

- 모달 내부만 스크롤
- 탭과 닫기 버튼 고정
- 배경 화면 스크롤 없음

- [ ] 주간 리포트 카드를 선택하면 상세 모달이 열린다.
- [ ] 기본 탭은 빠른 요약이다.
- [ ] 빠른 요약·상세 보기·추천 가이드 탭이 정상 전환된다.
- [ ] 선택한 리포트 ID의 데이터만 표시한다.
- [ ] 선택한 아이의 데이터만 표시한다.
- [ ] 과거 리포트 선택 시 해당 과거 데이터가 표시된다.
- [ ] 페이지 이동과 전체 새로고침이 없다.
- [ ] 모달을 닫으면 목록 스크롤 위치가 유지된다.
- [ ] 모바일 화면에서 모달이 잘리지 않는다.
- [ ] 긴 내용은 모달 내부에서 스크롤된다.
- [ ] `X`, 배경, 뒤로 가기, Escape로 닫을 수 있다.
- [ ] 데이터 부족과 오류 상태가 안전하게 표시된다.
- [ ] 일일·주간 리포트 데이터가 혼합되지 않는다.
- [ ] 다자녀 데이터가 혼합되지 않는다.
- [ ] 접근성 속성과 포커스 처리가 적용된다.
- [ ] Development E2E 검증이 완료된다.
- [ ] BLOCKER 및 HIGH 문제가 0건이다.
