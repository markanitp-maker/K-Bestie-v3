# 069 — 부모 일일·주간 리포트 모달 타이포그래피 통합 확대

## 1. 작업 목적

현재 부모 리포트 목록 화면의 글씨 크기는 읽기 적절하지만, 일일 리포트와 주간 리포트의 상세 모달 내부 글씨가 지나치게 작다.

특히 아래 영역이 작다.

- 빠른 요약
- 상세 보기
- 추천 가이드
- 각 카드 제목
- 각 섹션 제목
- 각 본문
- 모달 상단 제목
- 탭 글씨

이번 작업의 목적은 **부모 리포트 목록 화면의 현재 가독성 수준을 기준으로, 일일·주간 리포트 모달 전체의 타이포그래피를 동일한 수준으로 확대**하는 것이다.

핵심 원칙:

> 부모가 목록 화면에서 읽는 크기와 모달 안에서 읽는 크기가 크게 달라지지 않게 한다.

## 2. 구현 현황 확인 결과

사전 점검 결과:

- 일일 리포트와 주간 리포트 모달은 별도 구현이 아니라
  `ReportDetailModal.tsx`
  하나의 공통 컴포넌트를 사용한다.
- `reportType` prop으로 일일/주간을 분기한다.
- 따라서 이번 작업은 최대한 `ReportDetailModal.tsx` 한 곳에서 공통 적용한다.
- 별도 일일/주간 타이포그래피를 중복 구현하지 않는다.

기준 부모 리포트 목록 본문:

```text
text-lg = 18px
line-height ≈ 32px
현재 모달 주요 값:
모달 제목: text-base = 16px
탭: text-xs = 12px
빠른 요약/추천 가이드 본문: text-sm = 14px
상세 보기 섹션 본문: text-xs = 12px
현재 모달은 목록 화면보다 최대 6px까지 작아 부모가 읽기 불편한 상태다.
3. 확정 타이포그래피 원칙
이번 작업에서는 “스크롤을 줄이기 위해 글씨를 작게 유지”하지 않는다.
대표 요구사항은 다음과 같다.
첫 번째 부모 리포트 목록 화면에서 읽히는 글씨 크기를 기준으로, 일일·주간 모달의 본문도 동일한 수준으로 크게 보여준다.

따라서 본문 기준은 18px로 한다.
스크롤 길이가 조금 늘어나는 것은 허용한다.
가독성을 위해 글씨를 다시 14~16px로 줄이지 않는다.

현재:

최종:
18px
font-weight: 400~500
line-height: 1.65~1.75
Tailwind 적용 시 실제 프로젝트에서 18px 기준을 유지한다.
예:
text-lg
다만 기본 text-lg의 line-height가 현재 화면에서 과도하게 넓다면 font-size는 18px로 유지하면서 line-height만 별도로 조정할 수 있다.
예:
text-[18px] leading-[1.65]
중요:
18px 자체는 줄이지 않는다.
가독성을 위해 충분한 행간을 유지한다.
긴 리포트는 자연스럽게 세로 스크롤한다.
8. 보조 문구
본문보다 중요도가 낮은 다음 정보는 본문과 동일하게 18px까지 올릴 필요는 없다.
예:
AI Insight by 내친구 케이
날짜 badge
작은 상태 라벨
보조 메타데이터
목표:
13~14px
단, 현재 10~12px처럼 지나치게 작게 보이면 안 된다.
9. 카드 Padding / Gap
글씨를 확대하면서 카드 자체의 여백까지 크게 키우지 않는다.
현재 카드 padding과 gap은 기본적으로 유지한다.
필요한 경우에만:
padding 상하 +2~4px
수준으로 보정한다.
금지:
글씨 확대와 동시에 py-6, py-8 등 큰 padding 추가
카드마다 불필요한 빈 공간 확대
글씨보다 여백이 더 많이 커지는 구조
핵심:
글씨는 크게, 카드 여백은 과도하게 키우지 않는다.

13. 모달 크기와 스크롤
글씨가 커지므로 세로 스크롤 길이는 증가할 수 있다.
이것은 정상이다.
유지해야 할 것:
모달 헤더 고정 또는 현재 정상 구조
탭 영역 정상 접근
본문 세로 스크롤
X 닫기 버튼 접근 가능
하단 내용까지 정상 스크롤 가능
금지:
글씨가 커졌다는 이유로 font-size 다시 축소
본문 잘림
overflow hidden으로 내용 제거
긴 텍스트 ellipsis 처리
내부 horizontal scroll

15. 공통 구현
ReportDetailModal.tsx가 일일/주간 공통 컴포넌트이므로 가능하면 이 파일에서 공통 typography class를 정리한다.
예:
report-modal-title
report-tab-label
report-card-title
report-section-title
report-body
report-meta
등의 공통 패턴으로 정리할 수 있다.
단, 새 CSS 시스템을 과도하게 만들 필요는 없다.
현재 Tailwind 구조 안에서 중복 클래스를 상수화하거나 공통 className으로 정리하는 것도 허용한다.
