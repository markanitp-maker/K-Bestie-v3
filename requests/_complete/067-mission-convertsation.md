# 미션 대화 응답 구조 개선 요청

## 목적
미션 진행 중 아이 발화 이후 생성되는 케이의 응답 구조를 개선한다.

현재 미션 대화에서 아이의 답변마다 STT 확인용 구조와 고정 공감 문구가 반복 삽입되어 대화 흐름이 부자연스럽고, STT 처리 구조와도 맞지 않는 문제가 발생하고 있다.

미션은 케이가 아이를 심문하듯 질문하는 방식이 아니라, 아이의 답변을 자연스럽게 받아주고 다음 질문으로 연결하는 대화 방식으로 변경한다.

---

## 현재 문제점

### 1. 아이 발화 확인 단계 제거

현재 방식:

아이 답변 → "네가 한 말을 잘 들었어" 형태 확인 → 케이 응답

예:
```
아이:
"게임을 보고 나서 계속 하고 싶었지."

케이:
"게임을 보고 나서 계속 하고 싶었지."
얘기 잘 들었어, 들려줘서 고마워!
요즘 친구들이랑 자주 하는 놀이나 이야기는 뭐야?
```

문제:
- STT 결과를 별도 확인하는 구조가 실제 음성 대화 흐름과 맞지 않음
- 매번 아이 말을 다시 읽어주는 과정에서 대화 지연 발생
- 아이 입장에서는 같은 말을 반복해서 듣는 느낌 발생
- 자연스러운 친구 대화가 아니라 설문조사 형태가 됨

---

## 변경 요청

### 1. 아이 발화 확인 응답 제거

금지:

```
"네 말 잘 들었어"
"얘기 잘 들었어"
"들려줘서 고마워"
"말해줘서 고마워"
```

위와 같은 고정 확인 문구를 매 질문마다 출력하지 않는다.

---

### 2. 리액션 + 화제 전환 구조 적용

아이 답변을 직접 반복하지 않고, 짧은 리액션 후 다음 질문으로 자연스럽게 연결한다.

기본 구조:

```
[리액션]
+
[접속사/화제 전환]
+
[다음 질문]
```

예:

현재:
```
"게임을 보고 나서 계속 하고 싶었지."
얘기 잘 들었어, 들려줘서 고마워!
요즘 친구들이랑 자주 하는 놀이나 이야기는 뭐야?
```

개선:
```
그랬구나.
그럼 요즘 친구들이랑 자주 하는 놀이나 이야기는 뭐야?
```

---

## 응답 생성 규칙

### 허용 리액션 예시

상황에 맞게 다양하게 사용:

```
그랬구나.
아 그렇구나.
재밌었겠다.
정말 궁금했겠다.
그럴 수 있지.
와, 신기하다.
좋았겠다.
```

---

### 허용 화제 전환 표현

다음 질문으로 자연스럽게 연결:

```
그럼~
그리고~
그러면~
이번에는~
그때~
또 궁금한 게 있는데~
```

---

## 예외 처리

### 미션 마지막 질문 완료 시

전체 미션 종료 시에는 1회 정도 자연스러운 감사 표현 허용.

예:

```
오늘 이야기 많이 해줘서 고마워.
다음에도 케이랑 재미있는 이야기 나누자!
```

단, 매 질문마다 반복 금지.

---

## 대화 품질 기준

목표:

기존:
```
질문 → 답변 확인 → 감사 → 질문
```

변경:
```
질문 → 아이 답변 → 공감 리액션 → 자연스러운 다음 질문
```

케이는 조사자가 아니라 아이 이야기를 들어주는 친구 역할을 유지한다.

---

## 개발 검증 항목

1. 미션 10개 질문 전체 진행 테스트
2. 아이 답변마다 아래 문구 반복 출력 여부 확인
   - "얘기 잘 들었어"
   - "들려줘서 고마워"
   - "말해줘서 고마워"
3. 아이 답변 이후 바로 리액션+다음 질문 연결 여부 확인
4. STT 변환 결과 재확인 단계가 UI/응답 흐름에 영향을 주지 않는지 확인
5. 미션 완료 마지막 응답에서만 감사 표현 1회 출력 확인

수정 후 기존 미션 질문 흐름, 유효 답변 판정, 완료 조건은 변경하지 않는다.
