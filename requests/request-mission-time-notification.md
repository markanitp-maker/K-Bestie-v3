# Request MD: 미션 시간 알림 기능 추가

## 목적
아이 계정으로 로그인된 PWA 앱 사용자에게 미션 시작 시간을 알려주는 알림 기능을 추가한다.

## 요구사항

### 1. 알림 대상
- 알림 대상은 아이 계정으로 로그인된 PWA 앱 사용자만 해당한다.
- 부모 계정에는 미션 시간 알림을 발송하지 않는다.
- 일반 웹 브라우저 접속 사용자에게는 푸시 알림을 발송하지 않는다.

### 2. 미션 시작 알림 시간
Production 기준 Asia/Seoul 타임존을 사용한다.

- 미션Ⅰ 시작 알림
  - 방학: 매일 10:00
  - 학기 중: 매일 13:00

- 미션Ⅱ 시작 알림
  - 매일 18:00

### 3. 발송 조건
- 해당 미션을 이미 완료한 아이에게는 알림을 발송하지 않는다.
- 동일 미션에 대한 중복 알림 발송을 방지한다.
- 기존 미션 완료 데이터, 황금열쇠, 리포트 데이터에는 영향을 주지 않는다.

### 4. 알림 클릭 동작
- 알림 클릭 시 아이 인증 상태를 유지한 상태에서 해당 미션 화면으로 바로 이동한다.

### 5. 권한 및 PWA 처리
- 알림 권한을 거부한 경우 앱 접속 시 알림 권한 안내 배너를 표시한다.
- PWA 미설치 상태인 경우 앱 접속 시 PWA 설치 안내 배너를 표시한다.

### 6. Dev 환경 QA 기능
- 실제 시간을 기다리지 않고 검증 가능하도록 관리자 테스트 발송 기능을 제공한다.
- 관리자가 특정 아이를 선택하여 미션Ⅰ/미션Ⅱ 알림을 즉시 발송 테스트할 수 있어야 한다.

### 7. Production 적용
- Production은 Asia/Seoul 기준 실제 미션 운영 시간을 적용한다.
- 운영 환경에서 스케줄러 및 푸시 발송이 정상 동작해야 한다.

## 구현 전 분석 항목
구현 전에 아래 항목을 확인한다.

- 현재 PWA Push Notification 구조
- Service Worker 구성
- 아이 계정 인증 및 세션 구조
- 미션 완료 상태 조회 방식
- Dev / Production 환경 차이
- 기존 Cron 또는 Edge Function 구조

## 데이터 보호 조건
- 기존 사용자 데이터 삭제 금지
- 기존 미션 기록 변경 금지
- 기존 리포트 및 집계 데이터 영향 금지
- 롤백 가능한 방식으로 구현

## 완료 조건
- Dev 관리자 즉시 발송 테스트 PASS
- Production 시간 기준 발송 구조 검증 PASS
- 아이 계정만 알림 수신 PASS
- 완료 미션 사용자 알림 제외 PASS
- 클릭 시 해당 미션 화면 이동 PASS
