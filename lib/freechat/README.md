# Freechat Reaction Seed

자유대화의 공감 반응을 관리하는 데이터 저장소입니다.

## 개요
- 이 디렉토리의 `reactionSeed.json` 파일은 생성형 LLM이나 음성 모델을 거치지 않고 사용자(아이)의 발화에 빠르게 공감하기 위한 정적 반응 문구 모음입니다.
- **이 파일의 JSON 내용만 편집하거나 추가하면 코드 수정이나 배포 재빌드 없이 시스템에 즉시 반영됩니다.**

## 스키마 정보 (`reactionSeed.json`)
각 반응 데이터는 다음 필드를 가진 JSON 객체입니다:
- `id`: 고유 식별자 문자열 (예: `g01-01`, `g30-10`)
- `situation_group`: 1~30 사이의 정수 (상황 그룹 번호)
- `emotion`: 반응의 주 감정 키워드
- `intensity`: 감정 강도 (`low`, `medium`, `high`)
- `topic`: 짧은 한글 키워드로 된 대분류 주제
- `keywords`: 아이의 발화를 해당 그룹으로 분류하기 위해 사용되는 트리거 단어 배열 (3~6개)
- `review_status`: 검수 상태 (이 파일 내의 문구는 항상 `"reviewed"`로 고정)
- `text`: 케이가 실제로 할 반응 문구 (질문형, 상세 조언, 훈계, 단정 등을 제외한 짧은 경청/공감 문장)
