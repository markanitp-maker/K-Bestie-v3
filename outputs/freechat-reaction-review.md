# 자유대화 규칙기반 반응 300개 — 검수 보고서 (v2, intensity 재분류 반영)

- 소스: `lib/freechat/reactionSeed.json`
- 총 300개 (30그룹 × 10개), `lib/freechat/reactionEngine.test.ts` 15/15 통과 확인됨(제가 직접 재실행 검증)

## v1 → v2 변경 이력
- **v1(최초)**: intensity 필드가 300개 전부 "medium"으로 고정되어 실질적 구분이 없었음(품질 이슈로 지적)
- **v2(이번 라운드)**: 의미 기준으로 low/medium/high 재분류 완료. 반응엔진(`pickReaction`)이 감지된 입력강도와 가장 가까운 intensity를 우선 선택하도록 실제 연동됨(`detectInputIntensity` 신규). ASR 신뢰도가 낮으면 강제로 low 폴백. 그룹17(놀림·괴롭힘·따돌림) 문구 2개(`g17-05`, `g17-08`)는 high 반응의 자연스러움을 위해 톤만 미세 조정(과장/진단/편들기 없음, 차분한 경청 반응 유지).

## intensity 분포 (수정 후)
| intensity | 개수 |
|---|---|
| low | 56 |
| medium | 230 |
| high | 14 |

균등 배분이 아니라 그룹 성격에 따라 자연 분포함(그룹5/6/24/29/30은 전부 low, 그룹8/10/12/15/17/19/27은 각 2개만 high, 나머지는 medium 위주). 그룹별 정확한 분포는 아래 표 각 섹션 제목에 병기.

## 자동검증 통과 현황 (15개 테스트, 전부 PASS)
| 검증 항목 | 결과 |
|---|---|
| 총 개수 300개 | ✅ 통과 |
| 그룹당 정확히 10개 | ✅ 통과 (30그룹 전부) |
| intensity 유효 enum(low/medium/high) 300개 전수 | ✅ 통과 |
| intensity 분포 비균등(자연분포) 확인 | ✅ 통과 |
| 그룹별 intensity 분포 산출 | ✅ 통과 (`lib/freechat/reactionSeed-full-audit.json` 저장) |
| 텍스트 전체 중복 없음 | ✅ 통과 (0건) |
| 그룹 내 최소 유사도(5글자 접두어 3개 이상 반복 금지) | ✅ 통과 |
| 질문부호/질문형 어미 금지 | ✅ 통과 (0건) |
| 조언/명령/판단/진단/부모비난 금칙어 검사 | ✅ 통과 (0건 — 정규식이 실제로 300개 순회하며 검사하는지 코드 직접 확인함) |
| 분류 대표입력 테스트(30그룹 전부) | ✅ 통과 |
| 최근 30개 반복 방지 | ✅ 통과 |
| detectInputIntensity/pickReaction 강도매칭 폴백 | ✅ 통과 |

## 참고 사항
- 그룹 내 10개 문구의 `keywords`는 각 문구별이 아니라 그룹 전체에 동일하게 반복 부여되어 있습니다(분류는 그룹 단위 매칭이라 의도된 설계입니다).
- ASR 신뢰도는 `app/api/mission/stt` → `useVoiceChat` → `app/chat/page.tsx` → `app/api/chat/messages` → `reactionEngine`까지 엔드투엔드로 실연동 완료(confidence < 0.5면 그룹30 + low 강제).
